# Шрифты дисциплины

## Haipapikuseru Rehyper — пиксельный шрифт заголовков

Файлы в этой папке:

    Haipapikuseru.woff2   32 КБ — им и грузится страница
    Haipapikuseru.otf    399 КБ — исходник, запасной формат

Источник: https://fonts-online.ru/fonts/haipapikuseru-finale
Лицензия: GNU GPL 3.0. В Google Fonts шрифта нет, поэтому он лежит файлом.

Покрытие проверено по таблице cmap: кириллица, латиница, цифры
и пунктуация `« » — – … · №` — все глифы на месте.

### Метрики: почему кегли вдвое меньше обычных

    unitsPerEm   640
    capHeight    896  = 1.40 em   (у обычного гротеска ≈ 0.70 em)
    строка hhea  1.80 em

Прописная буква вдвое выше кегля, а строка занимает 1.8 em. Поэтому
во всех правилах, где используется `var(--display)` или `var(--pixel)`:

- **размер шрифта уполовинен** относительно того, что поставили бы
  для гротеска: `h1` — 38px вместо 74px, мелкие подписи — 6px;
- **интерлиньяж удвоен** (около 1.9–2.2), иначе строки наезжают друг
  на друга.

Если будете менять кегль — меняйте обе величины сразу.

### Пересобрать woff2 из otf

    pip install fonttools brotli
    python3 -c "from fontTools.ttLib import TTFont; f=TTFont('Haipapikuseru.otf'); f.flavor='woff2'; f.save('Haipapikuseru.woff2')"

## Что чем набирается

- заголовки, названия узлов схемы и мелкие подписи — Haipapikuseru,
  запасной Handjet из Google Fonts;
- основной текст — IBM Plex Sans;
- **всё числовое и элементы интерфейса — JetBrains Mono.** Числа туда
  уведены потому, что у запасного Handjet перечёркнутый ноль и «90»
  читается как «98». Кнопки навигации — потому что стрелки в пиксельном
  шрифте вылезают из кнопки.

Подключение — блок `@font-face` в начале `../styles.css` и такой же
в инлайновых стилях `../index.html` (у страницы-меню свои стили).
