# Aggregation Pipeline: $addFields, $set и $unset

#### $addFields: Добавляет новые поля в документы, не изменяя существующие.

Эта стадия позволяет добавлять новые поля в документы, не изменяя существующие. Она особенно полезна, когда нужно расширить документы дополнительными данными или вычисляемыми полями, сохранив при этом исходную структуру.

Что делает $addFields?

Добавляет новые поля в каждый документ.

Существующие поля остаются без изменений.

Если новое поле имеет то же имя, что и существующее, оно перезаписывает старое значение.

Синтаксис:

```python
{ "$addFields": { <newField>: <expression>, ... } }
```

<newField> — имя нового поля.

<expression> — выражение, которое вычисляет значение нового поля.

Примеры использования $addFields:

Исходные данные:

```python
[
    {
        "_id": 1,
        "name": "Alice",
        "age": 25,
        "salary": 50000
    },
    {
        "_id": 2,
        "name": "Bob",
        "age": 30,
        "salary": 60000
    }
]
```

Пример 1: Добавление простого поля

Пайплайн:

```python
pipeline = [
    {
        "$addFields": {
            "department": "HR"  # Добавить новое поле department
        }
    }
]
```

Результат:

```python
[
    {
        "_id": 1,
        "name": "Alice",
        "age": 25,
        "salary": 50000,
        "department": "HR"
    },
    {
        "_id": 2,
        "name": "Bob",
        "age": 30,
        "salary": 60000,
        "department": "HR"
    }
]
```

В каждый документ добавлено новое поле department со значением "HR".

Пример 2: Добавление вычисляемого поля

Пайплайн:

```python
pipeline = [
    {
        "$addFields": {
            "annual_salary": { "$multiply": ["$salary", 12] }  # Новое поле
        }
    }
]
```

Результат:

```python
[
    {
        "_id": 1,
        "name": "Alice",
        "age": 25,
        "salary": 50000,
        "annual_salary": 600000
    },
    {
        "_id": 2,
        "name": "Bob",
        "age": 30,
        "salary": 60000,
        "annual_salary": 720000
    }
]
```

Добавлено новое поле annual_salary, которое равно salary * 12.

Пример 3: Добавление поля на основе условия

Пайплайн:

```python
pipeline = [
    {
        "$addFields": {
            "status": {
                "$cond": {
                    "if": { "$gte": ["$salary", 55000] },
                    "then": "High",
                    "else": "Low"
                }
            }
        }
    }
]
```

Результат:

```python
[
    {
        "_id": 1,
        "name": "Alice",
        "age": 25,
        "salary": 50000,
        "status": "Low"
    },
    {
        "_id": 2,
        "name": "Bob",
        "age": 30,
        "salary": 60000,
        "status": "High"
    }
]
```

Добавлено новое поле status, которое зависит от значения salary.

Пример 4: Добавление вложенного поля

Пайплайн:

```python
pipeline = [
    {
        "$addFields": {
            "address": {
                "city": "New York",
                "zip": "10001"
            }
        }
    }
]
```

Результат:

```python
[
    {
        "_id": 1,
        "name": "Alice",
        "age": 25,
        "salary": 50000,
        "address": {
            "city": "New York",
            "zip": "10001"
        }
    },
    {
        "_id": 2,
        "name": "Bob",
        "age": 30,
        "salary": 60000,
        "address": {
            "city": "New York",
            "zip": "10001"
        }
    }
]
```

В каждый документ добавлен вложенный объект address.

Пример 5: Добавление поля на основе существующих данных

Пайплайн:

```python
pipeline = [
    {
        "$addFields": {
            "info": { "$concat": ["$name", " - ", "$department"] }
        }
    }
]
```

Результат:

```python
[
    {
        "_id": 1,
        "name": "Alice",
        "age": 25,
        "salary": 50000,
        "info": "Alice - HR"
    },
    {
        "_id": 2,
        "name": "Bob",
        "age": 30,
        "salary": 60000,
        "info": "Bob - IT"
    }
]
```

Добавлено новое поле info, которое объединяет name и department.

Когда использовать $addFields:

Для добавления вычисляемых полей:

Когда нужно добавить данные, которые зависят от существующих полей.

Для расширения документов:

Когда нужно добавить новые поля, не изменяя существующие.

Для условного добавления данных:

Когда нужно добавить поля на основе условий.

Важные моменты:

Сохранение существующих полей:

$addFields не удаляет и не изменяет существующие поля (если только новое поле не имеет то же имя).

Перезапись полей:

Если новое поле имеет то же имя, что и существующее, старое значение будет перезаписано.

Использование выражений:

Можно использовать любые выражения MongoDB, такие как $concat, $multiply, $cond и т.д.

Сравнение с $project:

$project:

Позволяет выбирать, какие поля включать или исключать.

Может изменять структуру документа.

$addFields:

Добавляет новые поля, сохраняя все существующие.

Не изменяет структуру документа.

#### $set: Аналог $addFields, добавляет или изменяет поля в документах.

#### $unset: Удаляет указанные поля из документов.

Что делает $set?

Добавляет новые поля в документы или обновляет существующие.

Если поле уже существует, его значение перезаписывается.

Если поле не существует, оно добавляется.

Синтаксис:

```python
{ "$set": { <field>: <value>, ... } }
```

<field> — имя поля, которое нужно добавить или обновить.

<value> — значение поля.

Примеры использования $set:

Исходные данные:

```python
[
    {
        "_id": 1,
        "name": "Alice",
        "age": 25
    },
    {
        "_id": 2,
        "name": "Bob",
        "age": 30
    }
]
```

Пример 1: Добавление нового поля

Пайплайн:

```python
pipeline = [
    {
        "$set": {
            "department": "HR"  # Добавить новое поле department
        }
    }
]
```

Результат:

```python
[
    {
        "_id": 1,
        "name": "Alice",
        "age": 25,
        "department": "HR"
    },
    {
        "_id": 2,
        "name": "Bob",
        "age": 30,
        "department": "HR"
    }
]
```

В каждый документ добавлено новое поле department.

Пример 2: Обновление существующего поля

Пайплайн:

```python
pipeline = [
    {
        "$set": {
            "age": { "$add": ["$age", 1] }  # Увеличить возраст на 1
        }
    }
]
```

Результат:

```python
[
    {
        "_id": 1,
        "name": "Alice",
        "age": 26
    },
    {
        "_id": 2,
        "name": "Bob",
        "age": 31
    }
]
```

Поле age увеличено на 1 для каждого документа.

Пример 3: Добавление вложенного поля

Пайплайн:

```python
pipeline = [
    {
        "$set": {
            "address": {
                "city": "New York",
                "zip": "10001"
            }
        }
    }
]
```

Результат:

```python
[
    {
        "_id": 1,
        "name": "Alice",
        "age": 25,
        "address": {
            "city": "New York",
            "zip": "10001"
        }
    },
    {
        "_id": 2,
        "name": "Bob",
        "age": 30,
        "address": {
            "city": "New York",
            "zip": "10001"
        }
    }
]
```

В каждый документ добавлен вложенный объект address.

Что делает $unset?

Удаляет указанные поля из документов.

Если поле не существует, операция игнорируется.

Синтаксис:

```python
{ "$unset": { <field>: "", ... } }
```

<field> — имя поля, которое нужно удалить.

Примеры использования $unset:

Исходные данные:

```python
[
    {
        "_id": 1,
        "name": "Alice",
        "age": 25,
        "department": "HR"
    },
    {
        "_id": 2,
        "name": "Bob",
        "age": 30,
        "department": "IT"
    }
]
```

Пример 1: Удаление одного поля

Пайплайн:

```python
pipeline = [
    {
        "$unset": "department"  # Удалить поле department
    }
]
```

Результат:

```python
[
    {
        "_id": 1,
        "name": "Alice",
        "age": 25
    },
    {
        "_id": 2,
        "name": "Bob",
        "age": 30
    }
]
```

Поле department удалено из всех документов.

Пример 2: Удаление нескольких полей

Пайплайн:

```python
pipeline = [
    {
        "$unset": ["age", "department"]  # Удалить поля age и department
    }
]
```

Результат:

```python
[
    {
        "_id": 1,
        "name": "Alice"
    },
    {
        "_id": 2,
        "name": "Bob"
    }
]
```

Поля age и department удалены из всех документов.

Пример 3: Удаление вложенного поля

Исходные данные:

```python
[
    {
        "_id": 1,
        "name": "Alice",
        "age": 25,
        "address": {
            "city": "New York",
            "zip": "10001"
        }
    }
]
```

Пайплайн:

```python
pipeline = [
    {
        "$unset": "address.city"  # Удалить вложенное поле city
    }
]
```

Результат:

```python
[
    {
        "_id": 1,
        "name": "Alice",
        "age": 25,
        "address": {
            "zip": "10001"
        }
    }
]
```

Вложенное поле city удалено из объекта address.

Когда использовать

$set:

Когда нужно добавить новые поля или обновить существующие.

Например, для добавления вычисляемых данных или обновления значений.

$unset:

Когда нужно удалить ненужные поля.

Например, для очистки документов от лишних данных.

Сравнение с $addFields:

$addFields:

Только добавляет новые поля, не изменяя существующие (если только новое поле не имеет то же имя).

$set:

Добавляет новые поля или обновляет существующие.

$unset:

Удаляет указанные поля.
