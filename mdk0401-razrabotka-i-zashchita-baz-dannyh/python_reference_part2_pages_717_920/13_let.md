# Локальные переменные в агрегации: $let

#### $let: Введение локальных переменных

Оператор $let используется для объявления локальных переменных внутри выражения и последующего их использования. Это позволяет избегать повторяющихся вычислений и делает выражения более читаемыми и оптимальными.

Синтаксис:

```python
{
  "$let": {
    "vars": {
      "<переменная1>": <выражение1>,
      "<переменная2>": <выражение2>
    },
    "in": <выражение, где используются переменные>
  }
}
```

Пример 1: Вычисление средней оценки

```python
{
  "_id": 1,
  "name": "Анна",
  "scores": [90, 85, 100]
}
```

Запрос:

```python
db.students.aggregate([
  {
    $project: {
      name: 1,
      average: {
        $let: {
          vars: {
            total: { $sum: "$scores" },
            count: { $size: "$scores" }
          },
          in: { $divide: ["$$total", "$$count"] }
        }
      }
    }
  }
])
```

Результат:

```python
{
  "_id": 1,
  "name": "Анна",
  "average": 91.666
}

```

Пример 2. Вычисление цены со скидкой

Данные:

```python
{
  "_id": 1,
  "price": 1000,
  "discountPercent": 20
}
```

Агрегация:

```python
{
  $project: {
    finalPrice: {
      $let: {
        vars: {
          discount: { $multiply: ["$price", { $divide: ["$discountPercent", 100] }] }
        },
        in: { $subtract: ["$price", "$$discount"] }
      }
    }
  }
}
```

Результат:

```python
{ "finalPrice": 800 }

```

Пример 3. Проверка длины массива и его использование

Данные:

```python
{
  "_id": 1,
  "tags": ["mongodb", "nosql", "database"]
}
```

Агрегация:

```python
{
  $project: {
    shortTagList: {
      $let: {
        vars: { tagCount: { $size: "$tags" } },
        in: {
          $cond: {
            if: { $lte: ["$$tagCount", 2] },
            then: "$tags",
            else: { $slice: ["$tags", 2] }
          }
        }
      }
    }
  }
}

```

Пример 4. Использование внутри $cond

```python
{
  $project: {
    performance: {
      $let: {
        vars: {
          ratio: { $divide: ["$score", "$maxScore"] }
        },
        in: {
          $cond: [
            { $gte: ["$$ratio", 0.9] }, "Отлично",
            { $gte: ["$$ratio", 0.75] }, "Хорошо",
            "Удовлетворительно"
          ]
        }
      }
    }
  }
}
```

Когда использовать $let:

Когда одно и то же выражение повторяется несколько раз

Когда нужно улучшить читаемость вложенных выражений

При сложных условиях и вычислениях, зависящих от промежуточных значений
