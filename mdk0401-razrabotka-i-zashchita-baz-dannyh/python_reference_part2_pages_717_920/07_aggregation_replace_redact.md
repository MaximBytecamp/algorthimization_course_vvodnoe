# Aggregation Pipeline: $replaceRoot, $replaceWith и $redact

#### $replaceRoot: Заменяет документ на указанное вложенное поле.

#### $replaceWith: Аналог $replaceRoot, заменяет документ на указанное значение.

Что делает $replaceRoot?

Заменяет корневой документ на указанное вложенное поле.

Если указанное поле отсутствует или не является объектом, возникает ошибка.

Синтаксис:

```python
{ "$replaceRoot": { "newRoot": <expression> } }
```

<expression> — выражение, которое возвращает объект, заменяющий корневой документ.

Примеры использования $replaceRoot:

Исходные данные:

```python
[
    {
        "_id": 1,
        "name": "Alice",
        "age": 25,
        "address": {
            "city": "New York",
            "zip": "10001"
        }
    },
    {
        "_id": 2,
        "name": "Bob",
        "age": 30,
        "address": {
            "city": "San Francisco",
            "zip": "94105"
        }
    }
]
```

Пример 1: Замена на вложенный объект

Пайплайн:

```python
pipeline = [
    {
        "$replaceRoot": {
            "newRoot": "$address"  # Заменить документ на вложенный объект address
        }
    }
]
```

Результат:

```python
[
    {
        "city": "New York",
        "zip": "10001"
    },
    {
        "city": "San Francisco",
        "zip": "94105"
    }
]
```

Каждый документ заменён на свой вложенный объект address.

Пример 2: Замена на вычисляемый объект

Пайплайн:

```python
pipeline = [
    {
        "$replaceRoot": {
            "newRoot": {
                "full_name": "$name",
                "city": "$address.city"
            }
        }
    }
]
```

Результат:

```python
[
    {
        "full_name": "Alice",
        "city": "New York"
    },
    {
        "full_name": "Bob",
        "city": "San Francisco"
    }
]
```

Каждый документ заменён на новый объект, содержащий поля full_name и city.

-----------------------------------------------------------------------------------------------

Что делает $replaceWith?

Аналог $replaceRoot, но с более простым синтаксисом.

Заменяет корневой документ на указанное значение.

Может использоваться для замены на вложенные поля, массивы или вычисляемые значения.

Синтаксис:

```python
{ "$replaceWith": <expression> }
```

<expression> — выражение, которое возвращает значение, заменяющее корневой документ.

Примеры использования $replaceWith:

Исходные данные:

```python
[
    {
        "_id": 1,
        "name": "Alice",
        "age": 25,
        "address": {
            "city": "New York",
            "zip": "10001"
        }
    },
    {
        "_id": 2,
        "name": "Bob",
        "age": 30,
        "address": {
            "city": "San Francisco",
            "zip": "94105"
        }
    }
]
```

Пример 1: Замена на вложенный объект

Пайплайн:

```python
pipeline = [
    {
        "$replaceWith": "$address"  # Заменить документ на вложенный объект address
    }
]
```

Результат:

```python
[
    {
        "city": "New York",
        "zip": "10001"
    },
    {
        "city": "San Francisco",
        "zip": "94105"
    }
]
```

Каждый документ заменён на свой вложенный объект address.

Пример 2: Замена на вычисляемый объект

Пайплайн:

```python
pipeline = [
    {
        "$replaceWith": {
            "full_name": "$name",
            "city": "$address.city"
        }
    }
]
```

Результат:

```python
[
    {
        "full_name": "Alice",
        "city": "New York"
    },
    {
        "full_name": "Bob",
        "city": "San Francisco"
    }
]
```

Каждый документ заменён на новый объект, содержащий поля full_name и city.

Пример 3: Замена на массив

Пайплайн:

```python
pipeline = [
    {
        "$replaceWith": {
            "info": ["$name", "$address.city"]
        }
    }
]
```

Результат:

```python
[
    {
        "info": ["Alice", "New York"]
    },
    {
        "info": ["Bob", "San Francisco"]
    }
]
```

Каждый документ заменён на объект, содержащий массив info.

Когда использовать

replaceRoot и replaceWith:

Для изменения структуры документа:

Когда нужно заменить весь документ на вложенный объект или массив.

Для создания новых документов:

Когда нужно сформировать новый документ на основе существующих данных.

Для упрощения данных:

Когда нужно извлечь только определенные данные и отказаться от остальных.

Важные моменты:

Ошибки:

Если указанное поле отсутствует или не является объектом (для $replaceRoot), MongoDB выдаст ошибку.

$replaceWith более гибкий, так как может работать с любыми значениями.

Сравнение с $project:

$project позволяет выбирать, какие поля включать или исключать, но не заменяет весь документ.

replaceRoot и replaceWith полностью заменяют документ.

#### $redact: Условно удаляет поля или документы на основе выражения.

Что делает $redact?

Условно удаляет поля или документы на основе выражения.

Использует три режима:

$$KEEP — сохранить документ или поле.

$$PRUNE — удалить документ или поле.

$$DESCEND — продолжить проверку вложенных полей.

Синтаксис:

```python
{ "$redact": { "$cond": { "if": <условие>, "then": <действие>, "else": <действие> } } }
```

<условие> — выражение, которое возвращает true или false.

<действие> — одно из значений: $$KEEP, $$PRUNE, $$DESCEND.

Примеры использования $redact:

Исходные данные:

```python
[
    {
        "_id": 1,
        "name": "Alice",
        "age": 25,
        "salary": 50000,
        "address": {
            "city": "New York",
            "zip": "10001"
        }
    },
    {
        "_id": 2,
        "name": "Bob",
        "age": 30,
        "salary": 60000,
        "address": {
            "city": "San Francisco",
            "zip": "94105"
        }
    },
    {
        "_id": 3,
        "name": "Charlie",
        "age": 35,
        "salary": 70000,
        "address": {
            "city": "Chicago",
            "zip": "60601"
        }
    }
]
```

Пример 1: Удаление документов на основе условия

Пайплайн:

```python
pipeline = [
    {
        "$redact": {
            "$cond": {
                "if": { "$gte": ["$salary", 60000] },  # Условие: salary >= 60000
                "then": "$$KEEP",  # Сохранить, если условие истинно
                "else": "$$PRUNE"  # Удалить, если условие ложно
            }
        }
    }
]
```

Результат:

```python
[
    {
        "_id": 2,
        "name": "Bob",
        "age": 30,
        "salary": 60000,
        "address": {
            "city": "San Francisco",
            "zip": "94105"
        }
    },
    {
        "_id": 3,
        "name": "Charlie",
        "age": 35,
        "salary": 70000,
        "address": {
            "city": "Chicago",
            "zip": "60601"
        }
    }
]
```

Документ с _id: 1 удалён, так как его salary (50000) меньше 60000.

Документы с _id: 2 и _id: 3 сохранены, так как их salary больше или равно 60000.

Пример 2: Удаление вложенных полей на основе условия

Пайплайн:

```python
pipeline = [
    {
        "$redact": {
            "$cond": {
                "if": { "$gte": ["$salary", 60000] },  # Условие: salary >= 60000
                "then": "$$DESCEND",  # Продолжить проверку вложенных полей
                "else": "$$PRUNE"  # Удалить, если условие ложно
            }
        }
    }
]
```

Результат:

```python
[
    {
        "_id": 2,
        "name": "Bob",
        "age": 30,
        "salary": 60000,
        "address": {
            "city": "San Francisco",
            "zip": "94105"
        }
    },
    {
        "_id": 3,
        "name": "Charlie",
        "age": 35,
        "salary": 70000,
        "address": {
            "city": "Chicago",
            "zip": "60601"
        }
    }
]
```

Документ с _id: 1 удалён, так как его salary (50000) меньше 60000.

Вложенные поля в документах с _id: 2 и _id: 3 сохранены, так как их salary больше или равно 60000.

Что делает $$DESCEND?

Когда вы используете $$DESCEND в выражении $redact, MongoDB рекурсивно проходит по всем вложенным документам и массивам в документе, применяя к ним те же правила фильтрации, которые вы указали на верхнем уровне. Это позволяет вам "спускаться" вглубь структуры документа и применять логику фильтрации на каждом уровне вложенности.

Пример использования $$DESCEND в $redact

Предположим, у вас есть документ в MongoDB, который выглядит следующим образом:

```python
{
  "_id": 1,
  "name": "Alice",
  "age": 25,
  "address": {
    "street": "123 Main St",
    "city": "Wonderland"
  },
  "contacts": [
    {
      "type": "email",
      "value": "alice@example.com"
    },
    {
      "type": "phone",
      "value": "123-456-7890"
    }
  ]
}
```

Вы хотите отфильтровать документ так, чтобы остались только поля, которые не являются контактной информацией (то есть, вы хотите удалить весь массив contacts).

Вы можете использовать $redact с $$DESCEND, чтобы рекурсивно пройти по документу и удалить ненужные данные:

```python
pipeline = [
    {
        "$redact": {
            "$cond": {
                "if": { "$eq": ["$type", "phone"] },
                "then": "$$PRUNE",
                "else": "$$DESCEND"
            }
        }
    }
]
result = db.collection.aggregate(pipeline)
```

В этом примере:

$$PRUNE удаляет текущий документ или массив, если условие выполнено.

$$DESCEND позволяет MongoDB продолжить рекурсивный обход вложенных документов и массивов, если условие не выполнено.

Пример 3: Условное удаление вложенных полей

Пайплайн:

```python
pipeline = [
    {
        "$redact": {
            "$cond": {
                "if": { "$eq": ["$city", "New York"] },  # Условие: city == "New York"
                "then": "$$PRUNE",  # Удалить, если условие истинно
                "else": "$$KEEP"  # Сохранить, если условие ложно
            }
        }
    }
]
```

Результат:

```python
[
    {
        "_id": 1,
        "name": "Alice",
        "age": 25,
        "salary": 50000,
        "address": {
            "zip": "10001"
        }
    },
    {
        "_id": 2,
        "name": "Bob",
        "age": 30,
        "salary": 60000,
        "address": {
            "city": "San Francisco",
            "zip": "94105"
        }
    },
    {
        "_id": 3,
        "name": "Charlie",
        "age": 35,
        "salary": 70000,
        "address": {
            "city": "Chicago",
            "zip": "60601"
        }
    }
]
```

Поле city удалено из документа с _id: 1, так как его значение равно "New York".

Остальные документы и их вложенные поля сохранены.

Когда использовать $redact:

Для условного удаления документов:

Когда нужно оставить только те документы, которые соответствуют определенным условиям.

Для условного удаления полей:

Когда нужно удалить определённые поля на основе условий.

Для работы с вложенными данными:

Когда нужно рекурсивно проверять и удалять вложенные поля.

Важные моменты:

Режимы работы:

$$KEEP — сохранить документ или поле.

$$PRUNE — удалить документ или поле.

$$DESCEND — продолжить проверку вложенных полей.

Рекурсивная проверка:

$redact рекурсивно проверяет вложенные поля, если используется режим $$DESCEND.

Ошибки:

Если условие возвращает недопустимое значение (например, не $$KEEP, $$PRUNE или $$DESCEND), MongoDB выдаст ошибку.
