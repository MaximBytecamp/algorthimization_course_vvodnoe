# Aggregation Pipeline: $match и $project

### КАТЕГОРИИ СТАДИЙ АГРЕГАЦИИ MONGODB.

Агрегационные пайплайны (aggregation pipelines) в MongoDB — это мощный инструмент для обработки и анализа данных, который позволяет выполнять сложные операции над коллекциями документов. Они представляют собой последовательность этапов (stages), через которые проходят документы.

Каждый этап выполняет определённую операцию, например фильтрацию, преобразование или группировку данных. Результат одного этапа передается на вход следующему, что позволяет строить цепочки обработки данных.

Основные концепции агрегационных пайплайнов:

Этапы (Stages):

Каждый этап выполняет определенную операцию над документами.

Примеры этапов: $match, $project, $group, $sort, $addFields и другие.

Документы проходят через этапы последовательно.

Документы на входе и выходе:

На вход каждого этапа подаются документы, которые прошли предыдущие этапы.

Этап может изменить документы, добавить новые, удалить или оставить их без изменений.

Гибкость:

Пайплайны могут быть простыми (например, только фильтрация) или сложными (с множеством этапов).

Позволяют выполнять операции, которые сложно или невозможно сделать с помощью обычных запросов find.

Производительность:

Агрегационные пайплайны выполняются на стороне сервера MongoDB, что делает их эффективными для обработки больших объёмов данных.

1. Стадии фильтрации и преобразования

Эти стадии используются для фильтрации, изменения структуры документов или добавления новых полей.

#### $match: Фильтрует документы, передавая только те, которые соответствуют указанному условию.

Она позволяет фильтровать документы, передавая только те, которые соответствуют указанному условию. По сути, это аналог SQL-запроса WHERE.

Фильтрует документы, оставляя только те, которые соответствуют заданному условию.

Условия могут быть простыми (например, { field: value }) или сложными (с использованием операторов, таких как $gt, $in, $regex и т.д.).

$match работает так же, как метод find() в MongoDB, но используется внутри агрегационных пайплайнов.

Синтаксис:

```python
{ "$match": { <условие> } }
```

<условие> — это объект, который определяет критерии фильтрации.

Примеры условий:

Простое условие:

```python
{ "$match": { "department": "HR" } }
```

Оставляет только документы, где поле department равно "HR".

Сравнение чисел:

```python
{ "$match": { "age": { "$gt": 30 } } }
```

Оставляет документы, где поле age больше 30.

Логические операторы:

```python
{ "$match": { "$and": [{ "age": { "$gt": 25 } }, { "department": "HR" }] } }
```

Оставляет документы, где age больше 25 и department равен "HR".

Регулярные выражения:

```python
{ "$match": { "name": { "$regex": "^A" } } }
```

Оставляет документы, где поле name начинается с буквы A.

Как работает $match в пайплайне:

$match обычно используется в начале пайплайна, чтобы уменьшить количество документов, которые будут обрабатываться на следующих этапах. Это повышает производительность, так как MongoDB обрабатывает меньше данных.

Пример использования $match:

Исходные данные:

```python
[
    {
        "_id": 1,
        "name": "Alice",
        "age": 25,
        "department": "HR",
        "salary": 50000
    },
    {
        "_id": 2,
        "name": "Bob",
        "age": 30,
        "department": "IT",
        "salary": 60000
    },
    {
        "_id": 3,
        "name": "Charlie",
        "age": 35,
        "department": "HR",
        "salary": 70000
    }]
```

Пайплайн:

```python
pipeline = [
    { "$match": { "department": "HR" } }
]
```

Результат:

```python
[
    {
        "_id": 1,
        "name": "Alice",
        "age": 25,
        "department": "HR",
        "salary": 50000
    },
    {
        "_id": 3,
        "name": "Charlie",
        "age": 35,
        "department": "HR",
        "salary": 70000
    }]
```

Документ с _id: 2 (Bob) не вошел в результрующий список, так как он работает в отделе IT, а не HR.

Пример с несколькими условиями:

Пайплайн:

```python
pipeline = [
    { "$match": { "department": "HR", "age": { "$gt": 30 } } }]
```

Результат:

```python
[
    {
        "_id": 3,
        "name": "Charlie",
        "age": 35,
        "department": "HR",
        "salary": 70000
    }]
```

Оставлен только документ с _id: 3, так как он соответствует обоим условиям:

department равен "HR".

age больше 30.

Когда использовать $match:

В начале пайплайна:

Чтобы уменьшить количество документов для обработки на следующих этапах.

Это повышает производительность.

Для фильтрации данных:

Когда нужно выбрать только определенные документы, соответствующие условию.

В комбинации с другими стадиями:

Например, после $match можно использовать $group, $sort или $project.

$match может использовать индексы для ускорения выполнения запроса. Если условие в $match соответствует индексу, MongoDB выполнит запрос быстрее.

#### $project: Выбирает, какие поля включать или исключать из документов. Также позволяет создавать вычисляемые поля.

Это одна из самых полезных стадий в агрегационных пайплайнах MongoDB. Она позволяет:

Выбирать, какие поля включать или исключать из документов.

Создавать новые (вычисляемые) поля на основе существующих.

Переименовывать поля.

Изменять структуру документа.

Что делает $project?

Позволяет контролировать, какие поля будут в итоговом документе.

Можно включать или исключать поля, указывая 1 (включить) или 0 (исключить).

Позволяет создавать новые поля с помощью выражений (например, конкатенация строк, арифметические операции и т.д.).

Синтаксис:

```python
{ "$project": { <field>: <value>, ... } }
```

<field> — имя поля, которое нужно включить, исключить или создать.

<value>:

1 — включить поле.

0 — исключить поле.

Выражение — создать новое поле.

Примеры использования $project:

Исходные данные:

```python
[
    {
        "_id": 1,
        "name": "Alice",
        "age": 25,
        "department": "HR",
        "salary": 50000,
        "address": {
            "city": "New York",
            "zip": "10001"
        }
    },
    {
        "_id": 2,
        "name": "Bob",
        "age": 30,
        "department": "IT",
        "salary": 60000,
        "address": {
            "city": "San Francisco",
            "zip": "94105"
        }
    }
]
```

Пример 1: Включение и исключение полей

Пайплайн:

```python
pipeline = [
    {
        "$project": {
            "name": 1,       # Включить поле name
            "department": 1, # Включить поле department
            "_id": 0         # Исключить поле _id
        }
    }
]
```

Результат:

```python
[
    {
        "name": "Alice",
        "department": "HR"
    },
    {
        "name": "Bob",
        "department": "IT"
    }
]
```

Поля name и department включены.

Поле _id исключено.

Пример 2: Создание вычисляемого поля

Пайплайн:

```python
pipeline = [
    {
        "$project": {
            "name": 1,
            "annual_salary": { "$multiply": ["$salary", 12] },  # Новое поле
            "_id": 0
        }
    }
]
```

Результат:

```python
[
    {
        "name": "Alice",
        "annual_salary": 600000
    },
    {
        "name": "Bob",
        "annual_salary": 720000
    }
]
```

Создано новое поле annual_salary, которое равно salary * 12.

Пример 3: Работа с вложенными полями

Пайплайн:

```python
pipeline = [
    {
        "$project": {
            "name": 1,
            "city": "$address.city",  # Включить вложенное поле
            "_id": 0
        }
    }
]
```

Результат:

```python
[
    {
        "name": "Alice",
        "city": "New York"
    },
    {
        "name": "Bob",
        "city": "San Francisco"
    }
]
```

Поле city извлечено из вложенного объекта address.

Пример 4: Переименование полей

Пайплайн:

```python
pipeline = [
    {
        "$project": {
            "full_name": "$name",  # Переименовать name в full_name
            "department": 1,
            "_id": 0
        }
    }
]
```

Результат:

```python
[
    {
        "full_name": "Alice",
        "department": "HR"
    },
    {
        "full_name": "Bob",
        "department": "IT"
    }
]
```

Поле name переименовано в full_name.

Пример 5: Условное создание поля

Пайплайн:

```python
pipeline = [
    {
        "$project": {
            "name": 1,
            "status": {
                "$cond": {
                    "if": { "$gte": ["$salary", 55000] },
                    "then": "High",
                    "else": "Low"
                }
            },
            "_id": 0
        }
    }
]
```

Результат:

```python
[
    {
        "name": "Alice",
        "status": "Low"
    },
    {
        "name": "Bob",
        "status": "High"
    }
]
```

Создано новое поле status, которое зависит от значения salary.

Пример 6: Конкатенация строк

Пайплайн:

```python
pipeline = [
    {
        "$project": {
            "full_name": { "$concat": ["$name", " - ", "$department"] },
            "_id": 0
        }
    }
]
```

Результат:

```python
[
    {
        "full_name": "Alice - HR"
    },
    {
        "full_name": "Bob - IT"
    }
]
```

Создано новое поле full_name, которое объединяет name и department.

Когда использовать $project:

Для уменьшения размера документов:

Когда нужно передать только определенные поля клиенту.

Для создания вычисляемых полей:

Когда нужно добавить новые данные на основе существующих.

Для изменения структуры документа:

Когда нужно переименовать поля или извлечь вложенные данные.

Важные моменты:

Исключение полей:

Если указать 0 для поля, оно будет исключено из документа.

Нельзя одновременно включать и исключать поля (кроме _id).

Производительность:

Использование $project может уменьшить объем данных, передаваемых между стадиями пайплайна, что повышает производительность.

Вложенные поля:

Можно извлекать или создавать вложенные поля с помощью точечной нотации (например, "$address.city").
