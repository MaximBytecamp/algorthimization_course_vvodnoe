# Aggregation Pipeline: $unwind и аккумуляторы массивов

#### $unwind: Разделяет массив на отдельные документы для каждого элемента массива.

$unwind — один из ключевых операторов в агрегационных пайплайнах MongoDB. Он позволяет "развернуть" массив, создав отдельный документ для каждого элемента. Это особенно полезно для анализа данных, фильтрации, группировки и других операций, требующих работы с элементами массивов по отдельности.

Базовый синтаксис

```python
{ $unwind: <путь_к_полю_с_массивом> }
```

или с дополнительными параметрами:

```python
{
  $unwind: {
    path: <путь_к_полю>,
    includeArrayIndex: <строка>,  // добавляет индекс элемента
    preserveNullAndEmptyArrays: <boolean>  // сохранять ли документы без массива
  }
}
```

Пример 1: Простое разворачивание

Исходный документ:

```python
{
  "_id": 1,
  "name": "Product A",
  "tags": ["sale", "new", "popular"]
}
```

Запрос:

```python
db.products.aggregate([ { $unwind: "$tags" } ])
```

Результат:

```python
[
  { "_id": 1, "name": "Product A", "tags": "sale" },
  { "_id": 1, "name": "Product A", "tags": "new" },
  { "_id": 1, "name": "Product A", "tags": "popular" }
]
```

→ Каждый элемент массива tags стал отдельным документом.

Пример 2: Добавление индекса элемента (includeArrayIndex)

Запрос:

```python
db.products.aggregate([
  { $unwind: { path: "$tags", includeArrayIndex: "arrayIndex" } }
])
```

Результат:

```python
[
  { "_id": 1, "name": "Product A", "tags": "sale", "arrayIndex": 0 },
  { "_id": 1, "name": "Product A", "tags": "new", "arrayIndex": 1 },
  { "_id": 1, "name": "Product A", "tags": "popular", "arrayIndex": 2 }
]
```

→ Поле arrayIndex показывает позицию элемента в исходном массиве.

Пример 3: Обработка отсутствующих/пустых массивов (preserveNullAndEmptyArrays)

Исходные документы:

```python
[
  { "_id": 1, "name": "Product A", "tags": ["sale", "new"] },
  { "_id": 2, "name": "Product B", "tags": [] },  // пустой массив
  { "_id": 3, "name": "Product C" }  // поле отсутствует
]
```

Без preserveNullAndEmptyArrays (по умолчанию false)

```python
db.products.aggregate([ { $unwind: "$tags" } ])
```

Результат:

```python
[
  { "_id": 1, "name": "Product A", "tags": "sale" },
  { "_id": 1, "name": "Product A", "tags": "new" }
]
```

→ Документы с пустым массивом или без поля исчезают из выдачи.

С preserveNullAndEmptyArrays: true

```python
db.products.aggregate([
  { $unwind: { path: "$tags", preserveNullAndEmptyArrays: true } }
])
```

Результат:

```python
[
  { "_id": 1, "name": "Product A", "tags": "sale" },
  { "_id": 1, "name": "Product A", "tags": "new" },
  { "_id": 2, "name": "Product B" },  // пустой массив → документ остался
  { "_id": 3, "name": "Product C" }   // поле отсутствует → документ остался
]
```

→ Документы без массива сохраняются.

Практическое применение

Сценарий 1: Анализ тегов товаров

Задача: Найти самые популярные теги.
Решение:

```python
db.products.aggregate([
  { $unwind: "$tags" },
  { $group: { _id: "$tags", count: { $sum: 1 } } },
  { $sort: { count: -1 } }
])
```

Вывод:

```python
[
  { "_id": "sale", "count": 15 },
  { "_id": "new", "count": 10 },
  { "_id": "popular", "count": 8 }
]
```

Сценарий 2: Фильтрация по элементам массива

Задача: Найти все товары с тегом "sale".
Решение:

```python
db.products.aggregate([
  { $unwind: "$tags" },
  { $match: { tags: "sale" } }
])
```

Сценарий 3: Обработка вложенных массивов

Исходный документ:

```python
{
  "_id": 1,
  "name": "Order #123",
  "items": [
    { "product": "Laptop", "price": 1000 },
    { "product": "Mouse", "price": 50 }
  ]
}
```

Запрос (развернуть items и посчитать сумму):

```python
db.orders.aggregate([
  { $unwind: "$items" },
  { $group: { _id: "$_id", total: { $sum: "$items.price" } } }
])
```

Результат:

```python
{ "_id": 1, "total": 1050 }
```

Важные замечания

Плюсы:

Позволяет работать с элементами массивов как с отдельными документами.

Часто используется перед $group, $match, $project.

Осторожно:

Может значительно увеличить количество документов (если массив большой).

Если массив пуст или поле отсутствует, документ исчезает (если не использовать preserveNullAndEmptyArrays: true).

Он особенно полезен в аналитических запросах, где нужно:

Разбить массив на отдельные записи.

Группировать данные по элементам массива.

Фильтровать документы по значениям в массиве.

Рекомендуется комбинировать его с другими операторами агрегации ($group, $match, $project)

------------------------------------------------------------------------------------------------

#### $push: Добавляет элемент в массив (используется в $group).

Оператор $push используется в агрегационных пайплайнах (в основном внутри $group) для добавления значений в массив. В отличие от $addToSet, он добавляет дубликаты и сохраняет порядок элементов.

Базовый синтаксис

```python
{
  $group: {
    _id: <группирующее_поле>,
    <новое_поле>: { $push: <выражение> }
  }
}
```

Пример 1: Простое добавление в массив

Исходные данные (orders):

```python
[
  { "_id": 1, "product": "Laptop", "price": 1000 },
  { "_id": 2, "product": "Mouse", "price": 50 },
  { "_id": 3, "product": "Laptop", "price": 1200 }
]
```

Запрос (группировка по продукту с сохранением цен):

```python
db.orders.aggregate([
  {
    $group: {
      _id: "$product",
      prices: { $push: "$price" }  // Добавляем все значения price в массив
    }
  }
])
```

Результат:

```python
[
  { "_id": "Laptop", "prices": [1000, 1200] },
  { "_id": "Mouse", "prices": [50] }
]
```

Пример 2: Добавление вычисляемых значений

Можно пушить не только поля, но и выражения:

```python
db.orders.aggregate([
  {
    $group: {
      _id: "$product",
      priceList: { $push: { price: "$price", tax: { $multiply: ["$price", 0.2] } } }
    }
  }
])
```

Результат:

```python
[
  {
    "_id": "Laptop",
    "priceList": [
      { "price": 1000, "tax": 200 },
      { "price": 1200, "tax": 240 }
    ]
  }
]
```

Пример 3: Комбинация с другими операторами

Добавляем только цены > 500:

```python
db.orders.aggregate([
  { $match: { price: { $gt: 500 } } },  // Сначала фильтруем
  { $group: { _id: "$product", prices: { $push: "$price" } } }
])
```

Отличия от $addToSet

| Оператор | Повторяющиеся значения | Сохраняет порядок | Производительность |
| --- | --- | --- | --- |
| $push | ✅ Да | ✅ Да | Быстрее |
| $addToSet | ❌ Нет (уникальные) | ❌ Нет | Медленнее |

Пример:

// Если есть дубликаты:

```python
{ "_id": 1, "product": "Laptop", "tags": ["sale", "new"] }
{ "_id": 2, "product": "Laptop", "tags": ["sale", "hot"] }

```

// $push: ["sale", "new", "sale", "hot"]

// $addToSet: ["sale", "new", "hot"]

Продвинутые сценарии

Сценарий 1: Построение истории изменений

Исходные данные (product_updates):

```python
[
  { "product": "Laptop", "price": 1000, "date": ISODate("2023-01-01") },
  { "product": "Laptop", "price": 1100, "date": ISODate("2023-02-01") }
]
```

Запрос (группировка по продукту с историей цен):

```python
db.product_updates.aggregate([
  {
    $group: {
      _id: "$product",
      priceHistory: { $push: { price: "$price", date: "$date" } }
    }
  }
])
```

Результат:

```python
{
  "_id": "Laptop",
  "priceHistory": [
    { "price": 1000, "date": ISODate("2023-01-01") },
    { "price": 1100, "date": ISODate("2023-02-01") }
  ]
}
```

Сценарий 2: Сбор данных из связанных документов

Исходные данные (orders + users):

```python
db.orders.aggregate([
  { $lookup: { from: "users", localField: "user_id", foreignField: "_id", as: "user" } },
  { $unwind: "$user" },
  { $group: { _id: "$user.name", orders: { $push: "$product" } } }
])
```

Вывод:

```python
{ "_id": "John", "orders": ["Laptop", "Mouse"] }
```

Ограничения и оптимизация

Производительность:

Избегайте $push в больших группах (может создать огромные массивы).

Для уникальных значений используйте $addToSet.

Размер документа:
MongoDB ограничивает документ 16MB. Если массив становится слишком большим, возникнет ошибка.

Альтернативы:

Для добавления элементов в массив вне агрегации используйте update с $push.

Примеры обновления документов (не агрегация)

Добавление элемента в существующий массив:

```python
db.products.updateOne(
  { _id: 1 },
  { $push: { tags: "limited" } }
)
```

Добавление с условием (только если значения нет):

```python
db.products.updateOne(
  { _id: 1 },
  { $push: { tags: { $each: ["limited"], $ne: "limited" } } }
)
```

$push в агрегациях — мощный инструмент для сборки массивов при группировке.

Основное применение: создание списков, история изменений, сбор связанных данных.

Для уникальных значений используйте $addToSet.

В операциях обновления (update) $push тоже работает, но с дополнительными операторами ($each, $slice и др.).

Пример для запоминания:

```python
// Агрегация
{ $group: { _id: "$category", products: { $push: "$name" } } }

// Обновление
{ $push: { tags: { $each: ["new", "hot"], $slice: -5 } } }  // Хранит только 5 последних тегов
```

#### $addToSet: Добавляет элемент в массив, если его там еще нет (используется в $group).

Оператор $addToSet - это мощный инструмент в агрегационных пайплайнах MongoDB, предназначенный для работы с массивами. Он позволяет добавлять элементы в массив только в том случае, если они еще не присутствуют в нем, тем самым гарантируя уникальность значений.

Основные характеристики

Уникальность: автоматически исключает дубликаты

Гибкость: работает с простыми значениями и сложными объектами

Использование: применяется внутри этапа $group агрегационного пайплайна

Синтаксис

```python
{
  $group: {
    _id: <expression>, // выражение для группировки
    <field>: { $addToSet: <expression> }
  }
}
```

Пример 1: Базовое использование с простыми значениями

Исходные данные (коллекция orders):

```python
[
  { "_id": 1, "product": "Laptop", "tags": ["electronics", "sale"] },
  { "_id": 2, "product": "Laptop", "tags": ["sale", "premium"] },
  { "_id": 3, "product": "Mouse", "tags": ["electronics"] }
]
```

Запрос:

```python
db.orders.aggregate([
  { $unwind: "$tags" },
  {
    $group: {
      _id: "$product",
      uniqueTags: { $addToSet: "$tags" }
    }
  }
])
```

Результат:

```python
[
  { "_id": "Laptop", "uniqueTags": ["electronics", "sale", "premium"] },
  { "_id": "Mouse", "uniqueTags": ["electronics"] }
]
```

Пример 2: Работа с объектами

Исходные данные (коллекция sales):

```python
[
  { "_id": 1, "product": "Laptop", "buyer": { "id": 101, "name": "John" } },
  { "_id": 2, "product": "Laptop", "buyer": { "id": 102, "name": "Alice" } },
  { "_id": 3, "product": "Laptop", "buyer": { "id": 101, "name": "John" } }
]
```

Запрос:

```python
db.sales.aggregate([
  {
    $group: {
      _id: "$product",
      buyers: { $addToSet: "$buyer" }
    }
  }
])
```

Результат:

```python
[
  {
    "_id": "Laptop",
    "buyers": [
      { "id": 101, "name": "John" },
      { "id": 102, "name": "Alice" }
    ]
  }
]
```

Особенности работы

1. Сравнение значений

Примитивные типы (строки, числа) сравниваются по значению

Объекты сравниваются по полному содержимому (все поля должны совпадать)

Массивы сравниваются по элементам и их порядку

2. Производительность

Проверка уникальности требует дополнительных вычислительных ресурсов

Для больших коллекций рекомендуется предварительная фильтрация с помощью $match

3. Ограничения

Максимальный размер документа MongoDB - 16MB (ограничивает размер результирующего массива)

Порядок элементов в результирующем массиве не гарантируется

Продвинутые сценарии использования

Сценарий 1: Комбинация с $unwind и $project

```python
db.orders.aggregate([
  { $unwind: "$items" },
  {
    $project: {
      product: 1,
      category: "$items.category"
    }
  },
  {
    $group: {
      _id: "$product",
      categories: { $addToSet: "$category" }
    }
  }
])
```

Сценарий 2: Условное добавление с $cond

```python
db.sales.aggregate([
  {
    $group: {
      _id: "$region",
      premiumClients: {
        $addToSet: {
          $cond: [
            { $gte: ["$amount", 1000] },
            "$client_id",
            "$$REMOVE"
          ]
        }
      }
    }
  }
])
```

Сценарий 3: Работа с датами

```python
db.events.aggregate([
  {
    $group: {
      _id: "$eventType",
      eventDates: { $addToSet: { $dateToString: { format: "%Y-%m-%d", date: "$date" } } }
    }
  }
])
```

Оптимизация производительности

Предварительная фильтрация:

```python
db.orders.aggregate([
  { $match: { status: "completed" } },
  { $group: { ... } }
])
```

Использование индексов:

Создавайте индексы для полей, используемых в $match и $group

Ограничение размера выборки:

```python
db.orders.aggregate([
  { $limit: 10000 },
  { $group: { ... } }])
```

Альтернативы и сравнение

| Критерий | $addToSet | $push |
| --- | --- | --- |
| Дубликаты | Исключает | Сохраняет |
| Производительн. | Ниже | Выше |
| Порядок | Не гарантирован | Сохраняется |
| Использование | Уникальные коллекции | Полные коллекции |

Альтернативные подходы

Агрегация с $reduce:

```python
{
  $group: {
    _id: "$product",
    uniqueTags: {
      $reduce: {
        input: "$tags",
        initialValue: [],
        in: {
          $cond: [
            { $in: ["$$this", "$$value"] },
            "$$value",
            { $concatArrays: ["$$value", ["$$this"]] }
          ]
        }
      }
    }
  }}
```

Использование $setUnion (MongoDB 4.4+):

```python
{
  $group: {
    _id: "$product",
    uniqueTags: { $setUnion: "$tags" }
  }}
```

Оператор $addToSet является незаменимым инструментом при работе с уникальными значениями в агрегационных запросах MongoDB. Его правильное использование позволяет:

Эффективно собирать уникальные данные

Избегать дублирования информации

Строить сложные аналитические отчеты

Для достижения максимальной производительности рекомендуется:

Фильтровать данные на ранних этапах пайплайна

Использовать индексы для полей группировки

Ограничивать размер обрабатываемых данных

Помните, что $addToSet не гарантирует порядок элементов в результирующем массиве. Если порядок важен, рассмотрите возможность последующей сортировки с помощью $sortArray (MongoDB 5.2+).

------------------------------------------------------------------------------------------------

#### $first: Возвращает первое значение в группе (используется в $group).

#### $last: Возвращает последнее значение в группе (используется в $group).

Операторы $first и $last используются в агрегационных пайплайнах MongoDB внутри этапа $group для получения первого и последнего значения в группе документов соответственно. Эти операторы особенно полезны при анализе временных рядов, обработке упорядоченных данных и создании отчетов.

Основные характеристики

$first

Возвращает первое значение из группы документов

Порядок определяется естественным порядком коллекции или предшествующим этапом $sort

Часто используется для получения начального состояния

$last

Возвращает последнее значение из группы документов

Как и $first, зависит от порядка документов

Полезен для получения конечного состояния

Синтаксис

```python
{
  $group: {
    _id: <expression>, // выражение для группировки
    <field1>: { $first: <expression> },
    <field2>: { $last: <expression> }
  }
}
```

Пример 1: Анализ временных рядов (изменение цен)

Исходные данные (коллекция priceChanges):

```python
[
  { "_id": 1, "product": "Laptop", "date": ISODate("2023-01-01"), "price": 1000 },
  { "_id": 2, "product": "Laptop", "date": ISODate("2023-02-01"), "price": 950 },
  { "_id": 3, "product": "Laptop", "date": ISODate("2023-03-01"), "price": 1100 },
  { "_id": 4, "product": "Phone", "date": ISODate("2023-01-15"), "price": 800 },
  { "_id": 5, "product": "Phone", "date": ISODate("2023-02-15"), "price": 750 }
]
```

Запрос для анализа изменения цен:

```python
db.priceChanges.aggregate([
  { $sort: { product: 1, date: 1 } }, // Сортировка по продукту и дате
  {
    $group: {
      _id: "$product",
      firstPrice: { $first: "$price" }, // Первая цена
      lastPrice: { $last: "$price" },   // Последняя цена
      priceChange: { // Вычисляем разницу
        $subtract: [
          { $last: "$price" },
          { $first: "$price" }
        ]
      },
      dates: { $push: "$date" } // Все даты изменений
    }
  }
])
```

Результат:

```python
[
  {
    "_id": "Laptop",
    "firstPrice": 1000,
    "lastPrice": 1100,
    "priceChange": 100,
    "dates": [
      ISODate("2023-01-01"),
      ISODate("2023-02-01"),
      ISODate("2023-03-01")
    ]
  },
  {
    "_id": "Phone",
    "firstPrice": 800,
    "lastPrice": 750,
    "priceChange": -50,
    "dates": [
      ISODate("2023-01-15"),
      ISODate("2023-02-15")
    ]
  }
]
```

```python
db.userSessions.aggregate([
  { $sort: { userId: 1, sessionId: 1, timestamp: 1 } },
  {
    $group: {
      _id: { userId: "$userId", sessionId: "$sessionId" },
      startTime: { $first: "$timestamp" },
      endTime: { $last: "$timestamp" },
      durationMinutes: {
        $divide: [
          { $subtract: [
            { $last: "$timestamp" },
            { $first: "$timestamp" }
          ]},
          60000 // преобразуем миллисекунды в минуты
        ]
      },
      actions: { $push: "$action" }
    }
  }
])
```

Особенности работы

1. Важность сортировки

$first и $last зависят от порядка документов

Всегда используйте $sort перед $group, если нужен определенный порядок

Без сортировки порядок определяется естественным порядком коллекции (не гарантирован)

2. Производительность

Сортировка больших коллекций может быть ресурсоемкой

Используйте индексы для полей, по которым выполняется сортировка

3. Обработка null и отсутствующих полей

Если поле отсутствует или содержит null, операторы вернут null

Для фильтрации null-значений используйте $ifNull или $cond

Оптимизация производительности

Используйте индексы для полей:

По которым выполняется группировка (_id в $group)

По которым выполняется сортировка ($sort)

Фильтрация на ранних этапах:

```python
db.data.aggregate([
  { $match: { date: { $gte: ISODate("2023-01-01") } } }, // Сначала фильтруем
  { $sort: { ... } },
  { $group: { ... } }
])
```

Ограничение выборки:

```python
db.largeCollection.aggregate([
  { $limit: 100000 }, // Ограничиваем количество обрабатываемых документов
  { $sort: { ... } },
  { $group: { ... } }
])
```

Операторы $first и $last являются мощными инструментами для:

Анализа временных рядов и изменений состояний

Определения начальных и конечных значений в последовательностях

Создания отчетов о динамике показателей

Для эффективного использования:

Всегда применяйте $sort перед $group, если важен порядок документов

Используйте индексы для полей сортировки и группировки

Рассмотрите возможность предварительной фильтрации данных

Эти операторы особенно полезны в сочетании с другими операторами агрегации, такими как $subtract для вычисления разницы между первым и последним значением, или $push для сохранения всей последовательности значений.
