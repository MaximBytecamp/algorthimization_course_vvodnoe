Итоговый артефакт · DATA PLATFORM v1.0

Платформа данных, которую вы соберёте за два семестра

Точка на схеме — одно изменение данных: у заказа сменился статус. Приложение записывает изменение в PostgreSQL и в той же транзакции добавляет строку в таблицу outbox — очередь событий на публикацию. Publisher читает outbox и отправляет событие в RabbitMQ, откуда его независимо забирают два потребителя: первый обновляет документ в MongoDB, второй дописывает строку в ClickHouse. Redis в этой цепочке не участвует: в нём хранится только то, что можно потерять без последствий. Каждый раздел курса отвечает за свой участок схемы.

Источник истины у нас — PostgreSQL

Транзакционным источником истины в курсе служит PostgreSQL: транзакции, роли, построчный доступ, восстановление на момент времени. Его расширения открыты, поэтому на нём удобно разбирать устройство базы изнутри.

psql · platform=# триггер, который сам заполняет outbox
CREATE FUNCTION orders_to_outbox() RETURNS trigger AS $$
BEGIN
  INSERT INTO outbox (aggregate_id, event_type, payload)
  VALUES (NEW.id, 'order.status_changed', to_jsonb(NEW));
  RETURN NEW;
END;
$$ LANGUAGE plpgsql;
CREATE TRIGGER orders_outbox AFTER UPDATE OF status ON orders
  FOR EACH ROW WHEN (OLD.status IS DISTINCT FROM NEW.status)
  EXECUTE FUNCTION orders_to_outbox();

Функция триггера возвращает специальный тип trigger и обращается к изменяемой строке через NEW и OLD. Событие и само изменение попадают в базу одной транзакцией: сохраняются либо оба, либо ни одного. Это та же граница, что разбирается на занятии 16, но здесь строку в outbox записывает сама база, а приложение о ней не знает.

CREATE EXTENSION IF NOT EXISTS pgcrypto;
pgcryptoШифрование и хеширование прямо в базе: crypt(), digest().
pg_stat_statementsСтатистика по запросам: сколько раз выполнялся и сколько времени занял. С неё начинается поиск медленного.
pg_trgmПоиск по неточному совпадению и индекс GIN под него. Индекс бывает не только B-деревом.
PostGISСвои типы, операторы и индексы — расширение приносит в базу целую предметную область.
Своё расширениеНабор функций, типов и операторов ставится одной командой CREATE EXTENSION и так же удаляется.

Значение имеет не перечень модулей, а два свойства базы: систему типов можно дополнить собственными типами, а в определённых точках — триггере, функции, расширении — выполняется ваш код.

Названо ограничениеСтудент указывает, чего решение не покрывает и какой риск остаётся.

Использование ИИ допускается для черновика конфигурации, тестовых данных и разбора ошибки — после собственной попытки. На приёмке студент объясняет каждое принятое решение самостоятельно и предъявляет вывод системы.
