Вот что вы соберёте за два семестра

Бегущая точка — одно изменение: у заказа сменился статус. Приложение пишет его в PostgreSQL и той же транзакцией кладёт строку в outbox. Publisher отправляет событие в RabbitMQ, оттуда два потребителя обновляют MongoDB и ClickHouse. У каждого раздела курса — свой участок этой схемы.

Реляционный контур курса

Источник истины у нас — PostgreSQL

Транзакционный источник истины — PostgreSQL: транзакции, роли, построчный доступ, восстановление на момент времени. У него открытые расширения, поэтому на нём удобно показывать, как база устроена внутри.

psql · platform=# триггер, который сам заполняет outbox
CREATE FUNCTION orders_to_outbox() RETURNS trigger AS $$
BEGIN
  INSERT INTO outbox (aggregate_id, event_type, payload)
  VALUES (NEW.id, 'order.status_changed', to_jsonb(NEW));
  RETURN NEW;
END;
$$ LANGUAGE plpgsql;
CREATE TRIGGER orders_outbox AFTER UPDATE OF status ON orders
  FOR EACH ROW WHEN (OLD.status IS DISTINCT FROM NEW.status)
  EXECUTE FUNCTION orders_to_outbox();

Функция триггера возвращает тип trigger и видит строку через NEW и OLD. Событие и само изменение попадают в базу одной транзакцией. Это граница из занятия 16, только строку пишет сама база, а приложение о ней не знает.

Свои типы и подключаемые модули

psql · platform=# тип и домен вместо текстового поля
-- перечисление: значения проверяет сама база
CREATE TYPE order_status AS ENUM
  ('new', 'paid', 'shipped', 'cancelled');

-- составной тип: поля под одним именем
CREATE TYPE money_amount AS (
  amount  numeric(14,2),
  currency char(3)
);

-- домен: тип с правилом, которое не обойти
CREATE DOMAIN email AS text
  CHECK (VALUE ~ '^[^@\s]+@[^@\s]+\.[^@\s]+$');

CREATE EXTENSION IF NOT EXISTS pgcrypto;
pgcryptoШифрование и хеширование прямо в базе: crypt(), digest().
pg_stat_statementsСтатистика по запросам: сколько раз выполнялся и сколько времени занял. С неё начинается поиск медленного.
pg_trgmПоиск по неточному совпадению и индекс GIN под него. Индекс бывает не только B-деревом.
PostGISСвои типы, операторы и индексы — расширение приносит в базу целую предметную область.
Своё расширениеНабор функций, типов и операторов ставится одной командой CREATE EXTENSION и так же удаляется.

Список модулей тут не главное. Главное — у базы есть система типов, которую можно дополнить своими, и места под ваш код: триггер, функция, расширение.
