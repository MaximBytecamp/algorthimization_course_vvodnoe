На паре решим две задачи о связных списках, дома — оставшиеся две. Подготовим контракты, проверки объектов и объяснение движения ссылок.

§1Стартовый набор

Для практики нужны головы цепочек и ссылки на исходные объекты. Список значений в условии обозначает порядок узлов. В функцию передаётся голова цепочки Node.

Скачайте стартовый набор lesson_22.zip. Он содержит Node, четыре незавершённые функции, проверки и памятку. Готовых решений в архиве нет.

ФайлНазначение
solution.pyNode и заготовки reverse, merge, middle, has_cycle.
check.pyПроверки выбранных функций: значения, порядок объектов и поля next.
README.mdКонтракты, команды запуска, требования к сдаче.

Распакуйте архив в отдельную папку и откройте её в редакторе. Для работы нужен Python 3.10 или новее; внешние пакеты не требуются.

В этой команде проверяются только reverse и middle. Без имён функций запустятся все четыре набора, включая ещё не написанные функции. Незавершённая заготовка выдаёт NotImplementedError.

Команда выбирает проверку по имени функции. Выберите свои две задачи по таблице следующего раздела.

§2Две задачи на паре

По КТП на паре решаются две задачи из четырёх. Работайте в отдельном файле или в песочнице: до кода сформулируйте контракт и нарисуйте небольшой вход.

ШагЧто должно получиться
1. ВыборДве разные функции и их контракты.
2. ПримерыОжидаемые объекты и next, включая 0/1 узел и нечётную длину.
3. ПланРабочие ссылки, изменение одного шага, причина остановки.
4. Код и запускФункция и фактический результат проверок.
5. ОбъяснениеГде изменяется поле, где переменная; время и дополнительная память.

Для has_cycle добавьте самоссылку и цикл после незамкнутого начала. Для merge проверьте пустую сторону и равные значения. Сначала выберите два блока; код других задач пока можно оставить заготовкой.

Песочницы используют общий Python-тренажёр книги. Первый запуск скачивает Python с cdn.jsdelivr.net. Код сохраняется в этом браузере до очистки хранилища; для сдачи сохраните файл отдельно.

Проверки читают результат ограниченным числом переходов. Лишний узел или случайный цикл в результате reverse/merge вызовет ошибку вместо бесконечного чтения. Следующий раздел задаёт самостоятельную работу без готового решения.

§3Домашнее задание

Дома решите две оставшиеся задачи из четырёх, которые не выбрали на паре. Используйте тот же набор файлов. Если все четыре уже готовы, повторите две с чистой заготовки и проговорите решение вслух.

Что подготовитьТребование
КонтрактВход, форма ответа, допустимость цикла, разрешение менять next.
Собственные данныеДля каждой функции минимум один новый пример, отсутствующий в таблицах этой главы.
Проверка объектовДля reverse/merge — исходные узлы в результате; для middle — конкретный узел; для has_cycle — булево значение и сохранность связей.
РазборПервое изменение ссылок и состояние после полной итерации.
СложностьВремя и дополнительная память с объяснением числа переходов.

§4Порядок сдачи

Преподавателю нужны код и воспроизводимая проверка. Одного снимка зелёного индикатора недостаточно для проверки идентичности и объяснения работы ссылок.

  1. Сдайте solution.py и короткий отчёт с названиями двух задач пары и двух домашних.
  2. Для каждой функции запишите контракт, входы, ожидаемый ответ и фактический вывод check.py.
  3. Приложите одну таблицу движения ссылок и оценку сложности.
  4. Отметьте, какие дополнительные проверки написали сами.
КритерийПризнак готовности
КорректностьВсе проверки выбранных функций прошли; нет лишних узлов.
Сохранность данныхЗначения и идентичность соответствуют контракту; next изменяется только где разрешено.
ОбъяснениеПоказана сохранённая ссылка на остаток и причина завершения.
СамостоятельностьЕсть собственный пример и объяснение найденной ошибки.

Автоматические тесты проверяют ограниченный набор входов и не оценивают качество объяснения. После сдачи проведите мок-интервью: задача выбирается до просмотра подсказок.
