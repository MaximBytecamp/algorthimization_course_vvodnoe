§1Что дано и что вернуть

В цепочке вагонов номер вагона и сцепка выполняют разные роли. Номер обозначает конкретный вагон, сцепка задаёт следующего соседа. У связного списка тоже есть значение и ссылка на продолжение.

Вход задачи — ссылка head на первый объект Node. У каждого узла есть value и next. Пустой вход задаётся значением None. Для двух списков передают две головы: left и right.

Слово «список» само по себе ещё не определяет структуру. Запись [7, 7] может обозначать список Python или краткое перечисление значений цепочки. Уточним представление и проверим его на двух узлах.

Оба значения равны 7. Проверка is показывает, что это разные объекты. Проследим поля в таблице: обозначения A и B относятся к конкретным объектам.

ОбъектvaluenextВнешняя ссылка
A7Bhead → A
B7Noneb → B

Путь от головы — A → B → None. Повтор значения здесь допустим; цикла нет. Поэтому при выборе алгоритма учитывают поля next и требуемый результат. Сопоставим четыре возможных условия.

§2Четыре условия задачи

При сборке поезда можно поменять порядок вагонов, объединить составы или найти средний вагон. Это разные операции над похожими данными. В задачах на связный список выбор тоже начинается с требуемого действия.

Разворот меняет направления next. Слияние связывает узлы двух упорядоченных цепочек в одну. Поиск середины возвращает узел в центральной позиции. Обнаружение цикла проверяет, приводит ли движение по next к повторному посещению объекта.

Переключайте условия ниже. В каждом варианте указаны исходные поля, результат и ограничение алгоритма. Стрелка в строке пути означает переход по next; буква обозначает объект.

Выбор по условиючетыре задачи занятия 22

Разворот связей

Условие: вернуть голову цепочки в обратном порядке. Сохранить объекты и значения, изменить их связи.

СостояниеПоля nextПуть от головы
ДоA.next = B; B.next = C; C.next = NoneA42 → B17 → C30 → None
ПослеC.next = B; B.next = A; A.next = NoneC30 → B17 → A42 → None

Что вернуть: ссылку на C. Здесь C30 означает объект C со значением 30. Печать значений в обратном порядке оставила бы исходные поля без изменений. Для этого контракта нужен разворот next.

До кода: разрешено ли менять связи? Конечна ли цепочка? Требуется вся цепочка или только её часть?

22.2 Разворот списка →

Слияние по возрастанию

Условие: соединить две уже упорядоченные цепочки. Переставлять существующие узлы, сохранить оба узла со значением 4.

СостояниеПоля nextПути
ДоA.next = B; B.next = None; C.next = D; D.next = Noneleft: A1 → B4 → None
right: C2 → D4 → None
ПослеA.next = C; C.next = B; B.next = D; D.next = NoneA1 → C2 → B4 → D4 → None

Что вернуть: ссылку на A. На каждом шаге сравнивают первые значения остатков. Их порядок позволяет выбрать меньший узел. При равенстве вариант модуля берёт узел из левой цепочки.

До кода: обе ли цепочки отсортированы? Разрешено ли менять next? Есть ли общие объекты? Общий узел нарушает условия этого слияния.

22.3 Слияние списков →

Поиск центральной позиции

Условие: вернуть средний узел конечной цепочки за O(1) дополнительной памяти. Для чётной длины выбрать правый из двух центральных узлов.

ЦепочкаСредние позицииРезультат
A10 → B20 → C30 → D40 → NoneB и CC
A10 → B20 → C30 → NoneBB

Что вернуть: ссылку на узел, все поля next сохранить. Подход fast/slow означает два указателя: медленный проходит одну ссылку, быстрый — две. Когда быстрый достигает конца цепочки, медленный находится в середине.

До кода: какая середина нужна при чётной длине? Может ли вход содержать цикл? У цикла нет конечной длины цепочки для этого определения середины.

22.4 Середина: два указателя →

Проверка повторного посещения

Условие: определить, можно ли снова попасть в уже посещённый объект, переходя по next. Связи менять запрещено, дополнительная память ограничена O(1).

ВходПоле последнего созданного узлаРезультат
A7 → B7 → C9 → NoneC.next = NoneFalse
A7 → B7 → C9 → B7 → …C.next = BTrue

Что вернуть: True или False. Во второй строке B посещается повторно: замкнут путь B → C → B. Два указателя разной скорости обнаруживают цикл при встрече в одном объекте.

До кода: нужен только факт цикла или его входной узел? Здесь решается только проверка наличия. Совпадение значений A и B циклом не считается.

22.5 Как обнаружить цикл →

В развороте и слиянии результат образуется изменением связей. Середина и проверка цикла оставляют поля исходными. У последних двух алгоритмов одинаковый приём fast/slow, но разные условия остановки и ответы. Проверим также границы выбора.

§3Когда алгоритм не подходит

Маршрут поезда выбирают по станции назначения и состоянию пути. Названия «середина» или «слияние» тоже требуют уточнений: дополнительные ограничения могут изменить решение.

Условия применимости — требования к входу и разрешённым действиям. Например, слияние из этого модуля использует уже отсортированные остатки. Проверим несколько условий, при которых выбранного алгоритма недостаточно.

Условие задачиЧто мешает применениюЧто уточнить
Вернуть значения в обратном порядке без изменения входаРазворот next изменяет исходную цепочкуМожно собрать значения отдельно; нужна ли память O(n)?
Соединить неотсортированные цепочки по возрастаниюМеньшая голова ещё не означает меньший оставшийся элементСначала требуется сортировка или другой алгоритм
Найти середину произвольного списка PythonУ list есть длина и доступ по индексуДля непустого list правая середина имеет индекс len(items) // 2
Найти узел входа в циклБулев ответ has_cycle не содержит ссылку на входТребуется отдельный алгоритм; в занятие 22 он не входит
Проверить повторяющиеся значенияЗначения могут совпадать у разных объектов конечной цепочкиНужна проверка значений; сначала гарантировать завершение обхода

Таблица отделяет требуемое действие от похожих формулировок. После выбора алгоритма остаются детали контракта: разрешение менять поля, правило равенства и границы входа. Эти детали можно получить вопросами до кода.

§4Вопросы до кода

Перед соединением двух составов проверяют порядок вагонов и отсутствие общей сцепленной части. Для слияния списков похожие уточнения определяют допустимый вход.

Контракт функции — договор о входах, результате и разрешённых изменениях. В блоке ниже исходное условие неполно. Упорядоченность по неубыванию означает, что каждое следующее значение не меньше предыдущего. Нажимайте вопросы: слева появятся уточнения, справа — ответы и последствия для решения.

    §5Контракт и проверки

    В заказе на перевозку фиксируют результат до отправления: какие вагоны должны прибыть и в каком порядке. У функции такую роль выполняет контракт. По нему можно проверить результат независимо от внутреннего кода.

    В таблице собраны принятые в модуле договорённости. «Узел» в столбце ответа означает ссылку на существующий объект. Для пустого входа такой ссылки нет, поэтому результат — None.

    ФункцияДопустимый входОтвет и измененияПервые проверки
    reverse(head)Конечная цепочкаНовая голова; next меняются, объекты сохраняются0 и 1 узел; 3 узла; двойной разворот возвращает исходные связи
    merge(left, right)Конечные упорядоченные цепочки без общих узловГолова общей цепочки; next меняютсяОба пусты; один пуст; равные значения в разных узлах
    middle(head)Конечная цепочкаСредний узел или None; при чётной длине правый; next сохраняются0, 1, 3 и 4 узла
    has_cycle(head)Цепочка с циклом или без негоTrue или False; next сохраняютсяПустой вход; самоссылка; цикл после начала; равные значения без цикла

    Цикл — допустимый вход только для has_cycle среди этих четырёх контрактов. Обычный обход до None на цикле не завершится. Поэтому циклические примеры проверяют алгоритмом обнаружения или ограниченным числом переходов.

    Проверьте себяУсловие: «Дана голова конечной цепочки. Верните правый центральный узел, связи сохраняйте». Какой план соответствует контракту?

    • Разворот изменит связи и вернёт крайний узел исходной цепочки.

    • Это поиск середины. Для A → B → C → D → None результатом будет объект C; поля сохранятся.

    • Контракт требует ссылку на центральный узел. Совпадение значений не определяет его позицию.

    Перед кодом сформулируйте результат, ограничения входа и разрешённые изменения. Затем назовите, какое поле или рабочая ссылка меняется на каждом шаге. Начнём с разворота всей конечной цепочки.
