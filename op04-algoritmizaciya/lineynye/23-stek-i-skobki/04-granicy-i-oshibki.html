§1Матрица границ

Перед сборкой всей конструкции проверяют отдельное крепление. Короткий контрпример тоже выделяет одну причину ошибки. Контрпример — вход, на котором заявленное решение даёт неверный результат.

Ошибка бывает на входе, во время прохода и после последнего шага. Поэтому одной проверки пустоты перед pop недостаточно. Начнём с последней проверки скобок.

§2Забытый остаток скобок

Если после упаковки осталась открытая коробка, работа не завершена. Ошибочная функция ниже возвращает True после прохода независимо от остатка. На входе (() совпавшая пара снимется, одна ( останется.

После символаСтекВывод
([ ( ]Есть незакрытая скобка
(([ (, ( ]Два открытия
(()[ ( ]Нужен False

Таблица показывает остаток после каждого префикса строки ((). После последнего символа стек остаётся непустым.

Исправьте завершающий return в песочнице. Тесты включают незакрытое открытие, раннее закрытие и пересечение типов.

Сверить исправление

Последняя строка должна быть return not stack. Она проверяет отсутствие незакрытых скобок.

Следующая ошибка тоже связана с содержимым одного элемента. Для отмены элементом должно быть целое добавление.

§3Символ вместо действия

Если наклейка содержит два символа, снять один символ означает частично повредить наклейку. В контракте undo требуется удалить добавление целиком. Переменная text без истории теряет границы добавлений.

ДействияОшибочная строкаПравильный результат
add ab → undoaпустая строка
add a → add пусто → undoпустая строкаa

Замените хранение цельной строки стеком фрагментов. Пустая строка является действием: отмена должна снять её, сохранив предыдущее добавление.

Сверить исправление

В числовой задаче содержимое уже выбрано правильно. Ошибка может скрываться в порядке снятия или арифметике.

§4Ошибки вычислителя

Карточки 8 и 3 различимы по месту в выражении. Присваивание left = stack.pop() меняет их роли. Сложение и умножение перестановку скрывают; вычитание и деление обнаруживают.

Ошибочная строка или шагКонтрпримерИсправление

value = left // right-7 3 / → -3Модуль частного и отдельный знак
int(left / right)Числа с десятками цифрНе переводить через float
Вернуть stack[-1] без проверки1 2 → 2Требовать len(stack) == 1

При ошибке входной список tokens остаётся прежним: функция меняет только свой локальный stack. Уже выполненные арифметические операции наружу не записываются.
