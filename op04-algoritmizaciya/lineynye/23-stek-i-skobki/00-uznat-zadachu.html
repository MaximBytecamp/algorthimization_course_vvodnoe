23.1

Как узнать задачу на стек

В этой главе разобраны признаки стека в условии задачи. Сопоставим скобки, вычисления и отмену действий, затем уточним контракты до кода.

В этой главе
  1. Последнее незавершённое действие
  2. Когда требуется другая структура
  3. Вопросы до алгоритма

§1Последнее незавершённое действие

Стопку тарелок разбирают сверху. Первой снимают ту тарелку, которую положили последней. Такой порядок называют LIFO: Last In, First Out, «последним пришёл — первым вышел». Стек хранит элементы с этим порядком доступа.

В задаче на стек остаются незавершённые действия. Новое действие временно откладывает предыдущее. После завершения внутреннего действия обработка возвращается к внешнему.

СитуацияЧто лежит в стекеЧто снимается первым
{[()]}Открывающие скобкиПоследняя незакрытая скобка
2 3 + 4 *Вычисленные значенияПоследнее значение: правый операнд
Добавить «при», добавить «вет», отменитьФрагменты текстаПоследний добавленный фрагмент

Во всех трёх строках нужен доступ к последнему элементу. Содержимое стека различается: скобки, числа или фрагменты текста. Теперь проверим, где этот порядок не подходит.

§2Когда требуется другая структура

У кассы первым обслуживают пришедшего раньше. Это очередь: здесь требуется первый элемент. Для проверки, встречалось ли имя, подходит множество. Порядок добавления в такой проверке не определяет ответ.

После add A, add B, undo какой фрагмент останется?

  • Отмена снимает последнее добавление B; A остаётся.
  • Сверьте порядок обработки и состояние вершины. Отмена снимает последнее добавление B; A остаётся.
  • Сверьте порядок обработки и состояние вершины. Отмена снимает последнее добавление B; A остаётся.

Выбор структуры опирается на требуемую операцию. До реализации нужно также определить вход и поведение на границах.

§3Вопросы до алгоритма

Как перед сборкой мебели уточняют комплект деталей, перед алгоритмом уточняют формат входа. Контракт — описание допустимого входа и требуемого результата. Он отделяет ошибку алгоритма от данных вне задачи.

Уточнить контракт

Строка содержит только ()[]{}. Вернуть bool; пустая строка правильная. Вход не изменяется.

    Уточнить контракт

    Вход — список строк: записи целых чисел, принимаемые int(token), и операции + - * /. Деление усекается к нулю. Ошибки формы и токенов дают ValueError; деление на ноль — ZeroDivisionError. Вход не изменяется.

      Уточнить контракт

      Список действий состоит только из ('add', строка) и ('undo',). Отмена снимает последнее неотменённое добавление целиком. При пустой истории ничего не происходит. Вернуть итоговую строку; вход не изменяется. Повтор отменённого действия не предусмотрен.

        Для скобок пустой вход даёт True. Для выражения пустой вход ошибочен. Для истории пустой вход даёт пустой текст. Одинаковая граница требует разных результатов по контракту.

        Разбор на примере стопки

        Стек похож на стопку незаконченных дел. Скобка — обещание закрыть пару. Число — уже вычисленная часть выражения. Фрагмент — добавление, которое ещё можно отменить. Что есть что: верх стопки — stack[-1], положить — append, снять — pop.

        Контракты заданы. Можно разобрать операции стека и их стоимость на списке Python.
