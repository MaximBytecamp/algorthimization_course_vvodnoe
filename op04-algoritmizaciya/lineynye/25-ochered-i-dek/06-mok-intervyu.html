Мок-интервью по очереди и деку

Три билета помогают проверить порядок решения: контракт, примеры, инвариант, код и стоимость. Потоковый билет развивает базовый максимум окна.

В этой главе
  1. Порядок тренировки
  2. Обратная связь по процессу

§1Порядок тренировки

Выберите билет на 25 минут. Этапы открываются последовательно; для повторения можно раскрыть все. Таймер общий для текущей тренировки. Сброс этапов и сброс кода в песочнице — разные действия.

Это открытая тренировка занятия 25. Контрольное мок-интервью № 26 использует отдельные задачи и здесь не проводится.

Ожидающие находятся в deque по приходу. Run снимает из начала, close снимает весь остаток. Закрытие проверяется до обработки следующей команды.

Сверить стоимость

При m командах время O(m): каждая задача добавляется и снимается не больше одного раза. Ожидание занимает O(q); с журналом результата общая память до O(m).

Сверить план

Дек хранит пары индекс/значение. Возраст проверяется по индексу; сила по значению. Полное окно выдаётся через yield, весь вход и ответ не накапливаются.

Таблица показывает эталонные пары после добавления. Значение хранится вместе с индексом, поэтому полного массива не требуется.
