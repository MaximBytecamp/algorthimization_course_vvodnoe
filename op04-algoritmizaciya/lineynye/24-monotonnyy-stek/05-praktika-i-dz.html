Практика и домашнее задание

В этой главе собраны две задачи на паре и домашняя работа. Для каждой функции заданы контракт и проверки.

В этой главе

  2. Две обязательные функции
  3. Домашняя задача
  4. Сдача

§1Работа на паре

Сначала письменно назовите для каждой позиции кандидата, момент выдачи ответа и условие снятия. Затем реализуйте две функции и проверьте границы.

ЭтапВремяРезультат

Температуры25 минутРазность индексов
Объяснение10 минутИнвариант и O(n)

Скачайте стартовый архив lesson_24.zip: solution.py с тремя обязательными заглушками и дополнительной largest_rectangle, check.py и README. Выполните python check.py для трёх обязательных функций. Команда python check.py --extra добавляет гистограмму. До реализации ожидается NotImplementedError.

Сначала решите next_greater, затем замените записываемое значение на разность индексов для температур.

§2Две обязательные функции

В стартовом архиве есть заглушки next_greater(nums) и warmer_days(temps). Обе функции возвращают новый список и не меняют вход.

Входnext_greaterwarmer_days

Песочница загружает Python через Pyodide по кнопке. Для первой загрузки нужна сеть. Код сохраняется локально в браузере. Итоговую работу сохраните отдельным файлом.

Обе функции готовы после тестов на равенства и пустой вход. Дома измените направление сравнения.

§3Домашняя задача

Реализуйте next_smaller(nums): для каждой позиции верните первый строго меньший элемент справа, иначе -1. Добавьте тесты на пустой, возрастающий, убывающий массив и равные значения. Дополнительно решите площадь гистограммы.

next_smaller: входОжидаемый ответ
[][]
[1, 2, 3][-1, -1, -1]
[3, 2, 1][2, 1, -1]
[2, 2][-1, -1]
[4, 2, 3, 1][2, 1, 1, -1]

Контракт next_smaller допускает целые числа любого знака. Отсутствие меньшего обозначается -1. Исходный список сохраняется. Для гистограммы отдельно проверьте нулевые высоты и равные столбцы.

Сохраните результаты проверок вместе с объяснением снятий.

§4Сдача

Сдайте solution.py, check.py и короткую трассу для [2, 1, 3, 2]. Объясните, почему каждый индекс попадает в стек и выходит не более одного раза. Оценка: контракт — 2, корректность — 4, границы — 2, объяснение стоимости — 2.
