24.1

Как узнать задачу на монотонный стек

В этой главе разобраны признаки задач на монотонный стек. Уточним направление поиска и смысл ближайшего элемента.

В этой главе
  1. Первый подходящий элемент справа
  2. Что делает стек монотонным
  3. Контракт до кода

Как в ряду зданий, для каждого дома можно искать первое более высокое здание справа. Ответом будет первое здание, которое выше исходного. Максимум всей улицы может оказаться дальше.

§1Первый подходящий элемент справа

В задаче требуется ближайший подходящий сосед справа или слева: первый больший, первый меньший, температура, которая станет выше. Наивный путь перебирает все пары. Монотонный стек хранит позиции без найденного ответа.

Идём слева направоСравниваем новый элемент с вершиной стека.
Записываем ответыЕсли ответ найден, кандидат больше не нужен.
Кладём текущийОн сам становится кандидатом для будущего.

Первый больший справа завершает поиск для снятой позиции. Более позднее число уже дальше. Поэтому снятый индекс больше не нужен. Разберём порядок оставшихся значений.

ПозицияВход [3, 2, 4]Первый больший справа
034
124
24-1

Для двух первых позиций ответ даёт один элемент 4. Сохраним обе позиции до его появления и разберём порядок стека.

§2Что делает стек монотонным

Монотонность — сохранение одного направления изменения значений: они не возрастают или не убывают. Для ближайшего большего справа стек держит значения в невозрастающем порядке. Когда приходит число 7, все вершины меньше 7 получают ответ 7 и снимаются.

В трассе дно стека слева, вершина справа. На входе [3, 2, 4] четвёрка снимает два индекса. Для них ответ 4 уже найден. Такое правило позволяет проверять только вершину. Теперь зададим, какие ответы требуется записывать.

§3Контракт до кода

ВопросРешение
Что вернуть?Для каждого элемента первый больший справа, иначе -1.
Равные значения?«Больший» означает строго >, равные не снимают кандидата.
Сложность?Каждый индекс кладём и снимаем не более раза: O(n).
Проверьте себя

Для [2, 1, 3] ответ для 1?

  • 3 — первый больший элемент справа.
  • 2 слева, а нужен сосед справа.
  • Справа есть 3.

Возвращаем значения, поэтому -1 может совпасть с настоящим большим элементом на отрицательном входе. Если нужно различать эти случаи, контракт меняют на индексы с -1 или на None.

Контракт фиксирует результат. Осталось показать запись ответа при снятии индекса.
