24.2

Следующий больший элемент

Реализуем шаблон: один проход, стек нерешённых индексов и ответы при снятии.

В этой главе
  1. Следующий больший справа
  2. Суммарная стоимость операций
  3. Индексы и повторяющиеся значения

На табло очереди у каждой заявки есть номер. Для записи результата по каждой заявке нужен её номер. Так же индекс массива указывает ячейку ответа.

Контракт next_greater. Вход — список целых чисел, включая отрицательные. Для каждой позиции вернуть значение первого строго большего справа или -1. Пустой вход даёт []. Вход сохраняется.

§1Следующий больший справа

Для каждого числа нужно вернуть первое число справа, которое строго больше него. Стек хранит индексы ещё не решённых элементов. Пока значение по индексу на вершине меньше текущего числа, текущий элемент становится её ответом.

Инвариант. После обработки позиции в стеке остаются только индексы без ответа, а их значения идут от дна к вершине в невозрастающем порядке.

Индексы нужны, потому что результат записывается в конкретную позицию. Сам алгоритм не меняет исходный список.

enumerate даёт пару: индекс i и значение value. Выражение stack[-1] читает индекс на вершине. nums[stack[-1]] получает сравниваемое число. pop возвращает индекс для записи в answer. После while текущий индекс добавляется через append.

МоментИндексы в стекеЗначенияОтвет
до прохода[][][-1, -1, -1]
после 2[0][2][-1, -1, -1]
после 1[0, 1][2, 1][-1, -1, -1]
после 3[2][3][3, 3, -1]

Число 3 снимает оба индекса. Раньше между каждым из них и 3 большего значения не было. Поэтому записанный ответ ближайший. Порядок в стеке восстановлен; оценим число снятий.

§2Суммарная стоимость операций

Внутренний while снимает индексы без повторного добавления уже снятых. Он один раз попадает в стек и один раз выходит. Число добавлений и снятий не больше 2n. Итоговая стоимость — O(n), память — O(n).

За весь проход каждый индекс добавляется один раз. Снятых индексов не больше n. Эта суммарная оценка называется амортизированной: отдельный шаг может снять много элементов, но серия из n шагов стоит O(n).

ВходДобавленияСнятияОстаток
[1, 2, 3, 4]431
[4, 3, 2, 1]404
[3, 2, 1, 4]431

В последней строке один шаг снимает три индекса. Суммарная оценка остаётся линейной. Равные значения требуют отдельной проверки условия.

§3Индексы и повторяющиеся значения

Одинаковые числа занимают разные позиции. Индекс позволяет записать ответ для каждого в нужную ячейку. Строгое сравнение оставляет равные кандидаты в стеке.

ВходОтветПочему
[2, 2, 3][3, 3, -1]Оба 2 ждут один 3
[3, 3][-1, -1]Равный не является большим

Значения [2, 2, 3] дают два отдельных ответа 3. Знак < сохраняет равные двойки до появления тройки. Для задачи «больше или равно» условие меняется на <=.

Сравнение с полным перебором

Для каждой позиции перебор просматривает элементы справа до подходящего. На убывающем входе проверяются n(n−1)/2 пар: O(n²) времени. Дополнительная память без ответа — O(1). Моностек использует O(n) дополнительной памяти и O(n) времени.

Если ответом должно стать расстояние до найденного числа, индексы дают его разностью.
