# Interview canvas

Заполняется до того, как написана первая строка кода.

**1. Условие своими словами**
> Вход: … Выход: … Что считается верным ответом: …

**2. Уточняющие вопросы**
- Максимальный размер входа?
- Диапазон значений, отрицательные числа?
- Возможны ли дубликаты?
- Данные отсортированы?
- Что вернуть, если ответа нет?

**3. Примеры**

| Вход | Ожидаемый выход | Зачем этот случай |
|---|---|---|
| | | обычный |
| `[]` | | пустой ввод |
| `[x]` | | один элемент |
| | | дубликаты / нет ответа |

**4. Brute force**
> Как решаем перебором и сколько это стоит.

**5. Оптимизация**
> Что пересчитывается зря, какую структуру берём взамен, новая стоимость.

**6. Проверка**
- [ ] прошёл код по шагам на своём примере
- [ ] проверил границы
- [ ] назвал время и память
