# Заметка о сложности · максимум последовательности

**Задача.** Вход — список целых чисел. Выход — наибольшее число или `None`,
если список пуст.

**Подход.** Один проход слева направо: храним лучшее из просмотренного
и сравниваем с очередным элементом. Дополнительных структур не нужно.

**Инвариант.** Перед каждой итерацией в `best` лежит максимум уже
просмотренной части. Список закончился — просмотрено всё, значит в `best`
максимум всей последовательности.

| | Оценка | Откуда |
|---|---|---|
| Время `T(n)` | `O(n)` | одно сравнение на элемент, элементов n |
| Память `S(n)` | `O(1)` | храним одну переменную независимо от n |

**Худший случай.** Любой вход: проход всегда полный, ранний выход невозможен —
максимум может оказаться последним элементом.

**Ограничения.** Подходит для любого n, который помещается в память.

**Что пробовали до этого.** `sorted(numbers)[-1]` даёт тот же ответ, но это
`O(n log n)` по времени и `O(n)` по памяти: сортировка делает лишнюю работу,
ведь порядок остальных элементов нам не нужен.
