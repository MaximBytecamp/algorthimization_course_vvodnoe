# Паспорт воспроизводимого эксперимента

Справка занятия 4. Остаётся у вас после курса: по ней собирается любой
замер, а не только сегодняшний. Слева — поле паспорта, справа — что в нём
пишут и что происходит, если поле оставить пустым.

## 1. Одиннадцать полей паспорта

| Поле | Что пишем | Если поле пустое |
|---|---|---|
| Вопрос | одно предложение, на которое отвечает замер | измеряется всё подряд, вывод не следует из чисел |
| Гипотеза | ожидаемый результат до запуска, с числом | любой результат объявляется «ожидаемым» |
| Что сравниваем | какие реализации и в каких версиях | через месяц непонятно, что было измерено |
| Данные | как получены, каким seed, какого размера | другой человек получит другие числа |
| Граница | какие строки внутри измеряемого участка | в число попадает подготовка данных |
| Часы | `perf_counter` или `process_time`, разрешение | нельзя понять, засчитано ли ожидание |
| Прогрев | сколько вызовов до серии | первое значение завышено, серия смещена |
| Повторы | сколько и почему столько | один запуск не отличается от помехи |
| Агрегат | минимум, медиана или оба, и почему | среднее по трём запускам с выбросом |
| Среда | версия Python, ОС, процессор, питание, нагрузка | числа несравнимы с числами соседа |
| Ограничения | чего этот замер не показывает | вывод распространяется на то, что не измерялось |

## 2. Чек-лист измерительного контура

Проходится по своему коду перед тем, как записать первое число.

- [ ] данные созданы **до** отсчёта и одинаковы для всех решений;
- [ ] внутри границы только исследуемая операция: ни генерации, ни печати,
      ни копирования, ни проверки результата;
- [ ] взяты монотонные часы: `time.perf_counter`, а не `time.time`;
- [ ] перед серией сделан прогрев, и его значение в серию не попало;
- [ ] повторов не меньше семи, все сырые значения сохранены;
- [ ] в выводе есть и минимум, и медиана, и разброс `max / min`;
- [ ] размеров входа не меньше четырёх и они растут кратно;
- [ ] память измерена отдельным запуском, не одновременно со временем;
- [ ] названа среда: версия Python, машина, режим питания;
- [ ] назван размер входа, при котором вывод перестаёт действовать.

## 3. Как звучит вывод

Вывод — проверяемое утверждение с границами применимости, а не оценка
«быстро» или «медленно». Форма из четырёх частей:

> На **[какие данные и размеры]** решение **[какое]** оказалось
> **[во сколько раз]** быстрее по **[какая метрика]**;
> измерено **[как: часы, прогрев, повторы, агрегат]**;
> вывод не распространяется на **[что не измерялось]**.

Пример, собранный по этой форме из чисел `results_time.csv`:

> На пакетах из 250–8000 идентификаторов сверка через множество оказалась
> от 56 до 1105 раз быстрее сверки перебором по списку по минимуму серии
> из семи повторов; измерено `perf_counter` с прогревом, генерация данных
> вынесена за границу; вывод не распространяется на пакеты меньше 250
> элементов, на данные с другим распределением совпадений и на машины
> с другим объёмом кэша.

## 4. Чего замер не докажет никогда

- **Асимптотику.** Эксперимент показывает поведение на измеренных размерах.
  `O(n)` — утверждение обо всех n, а измерено шесть точек.
- **Причину.** Числа показывают, что разница есть; почему она такая —
  отвечает разбор кода, а не секундомер.
- **Скорость на чужой машине.** Другой процессор, другой объём кэша,
  другая версия интерпретатора — другие числа при том же порядке роста.
- **Что оптимизация нужна.** Замер отвечает «сколько», решение об изменении
  кода принимается по требованию к системе, а не по красоте графика.
