# Отчёт о замере (для приёмки)

Работа другой группы. На занятии этот отчёт проверяется по чек-листу
из `METHOD.md`, раздел 2. Задача — назвать дефекты методики и сказать,
какие из выводов после их исправления перестанут держаться.

---

**Вопрос.** Какое решение быстрее.

**Методика.** Запустили оба решения, засекли время встроенным
секундомером телефона, взяли среднее из двух запусков. Данные для
каждого решения сгенерировали заново, чтобы замер был честным.
Измеряли на n = 100, чтобы дождаться результата.

**Среда.** Ноутбук, Python.

**Результаты.**

| решение | запуск 1, с | запуск 2, с | среднее, с |
|---|---:|---:|---:|
| список | 0.4 | 0.9 | 0.65 |
| множество | 0.3 | 0.5 | 0.40 |

**Вывод.** Множество быстрее списка примерно в полтора раза. Разница
небольшая, поэтому в проекте можно оставить список: он проще читается.
На больших данных всё будет так же.

---

## Что требуется от приёмки

1. Назвать дефекты контура: сколько их и в каком поле паспорта каждый.
2. Сказать, какой из дефектов сильнее всего повлиял на число.
3. Переписать вывод так, чтобы он следовал из данных, которые есть.
4. Указать, какой замер нужно провести, чтобы исходный вывод проверить.
