# Замеры времени

Здесь живут воспроизводимые эксперименты: скрипт, таблица результатов и
короткий вывод по каждому.

```bash
source .venv/bin/activate
python benchmarks/bench.py
python benchmarks/bench.py --sizes 1000 5000 20000 --repeats 7
```

Скрипт кладёт результаты в `results.csv`. Дальше — ваш текст.

## Методика

- данные генерируются **до** измерения и одинаковы для всех решений;
- перед серией идёт прогрев;
- берём медиану серии, а не один запуск;
- фоновые задачи на компьютере влияют на результат — если числа скачут,
  увеличьте число повторов.

## Что записывать в вывод

1. Какие решения сравнивали и на каких размерах входа.
2. Как росло время: во сколько раз при удвоении n.
3. Сходится ли это с теоретической оценкой.
4. Что удивило и чем это можно объяснить.

> **Важно.** Замер не доказывает сложность. `O(n)` — про порядок роста числа
> операций, а не про секунды. Один запуск на маленьком наборе не доказывает
> вообще ничего: на нём разница может утонуть в шуме.
