# Замеры времени и памяти · материалы занятия 4

Занятие 3 считало операции: число сравнений одинаково на любой машине.
Здесь измеряются секунды и байты, а они зависят от процессора, версии
интерпретатора, фоновой нагрузки и того, где проведена граница замера.
Поэтому вокруг числа строится контур, а рядом с числом — паспорт.

## Что где лежит

| Файл | Что делает | Когда открывается |
|---|---|---|
| `lab.py` | измерительный контур целиком: граница, прогрев, серия, агрегаты, CSV | демонстрация и лаборатория |
| `contour.py` | тот же контур бланком, с TODO | практика «настроить контур» |
| `test_lesson_04.py` | автопроверка бланка: прогрев, граница, сырые значения | после `contour.py` |
| `clocks.py` | четыре часов Python: разрешение, wall clock против CPU time | разбор метрик |
| `memory_probe.py` | пиковая память через `tracemalloc`, ступени множества | блок памяти |
| `broken_bench.py` | чужой замер с пятью дефектами, который печатает неверный вывод | практика «найти дефект» |
| `peer_review_report.md` | чужой отчёт о замере | приёмка |
| `METHOD.md` | паспорт эксперимента и чек-лист контура | справка, остаётся после курса |
| `results_time.csv` | сырые результаты серий: минимум, медиана, разброс, множители | заполняется запуском |
| `results_memory.csv` | пиковая память двух решений по размерам входа | заполняется запуском |

## Запуск

```bash
source .venv/bin/activate

python benchmarks/lab.py                     # серия по шести размерам входа
python benchmarks/lab.py --raw 2000          # сырые значения одной серии
python benchmarks/lab.py --boundary 4000     # цена каждой части участка
python benchmarks/clocks.py                  # часы: прошедшее и процессорное время
python benchmarks/memory_probe.py            # пиковая память, ступени множества
python benchmarks/broken_bench.py            # замер с дефектами: что он печатает

pytest course-materials/benchmarks/test_lesson_04.py -q
```

## Рабочая задача

Пакет входящих идентификаторов сверяется с реестром известных. Два
корректных решения, разная стоимость одной проверки:

- `match_list` — `x in known`, где `known` список: линейный просмотр;
- `match_set` — `x in known`, где `known` множество: адрес считается
  по значению.

Оба возвращают одинаковый ответ. Занятие 3 назвало их классы, занятие 4
измеряет, во что эти классы обходятся на настоящих данных.

## Артефакт студента

```text
benchmarks/
├── contour.py       заполненный бланк контура
├── results_time.csv сырые серии со своими числами
├── chart.svg        график «размер входа — время»
└── README.md        паспорт эксперимента по METHOD.md
```

Один итоговый коэффициент без сырых значений не принимается: по нему
нельзя проверить ни границу, ни повторы, ни агрегат.
