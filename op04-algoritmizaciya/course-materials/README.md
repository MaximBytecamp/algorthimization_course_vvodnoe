# Материалы преподавателя

То, что не входит в стартовый пакет студента, но выдаётся по ходу дисциплины.
Стартовый пакет намеренно оставлен минимальным: README, пример и папка
занятия. Всё остальное появляется в репозитории студента тогда, когда тема
до него дошла.

| Папка | Что это | Когда выдавать |
|---|---|---|
| `example/` | решённая задача-образец с тестами и заметкой о сложности — как должна выглядеть папка занятия | занятие 7, когда начинается оформление решений |
| `conftest.py` | сброс кэша модуля `solution`, чтобы `pytest` из корня брал файл соседней папки | когда в репозитории станет больше одной папки занятия, то есть с занятия 2 |
| `templates/` | шаблоны: solution, тесты, complexity note, interview canvas, отчёт по mock, бланк ДЗ | canvas — занятие 2, complexity note — занятие 3, отчёт по mock — занятие 16 |
| `complexity/` | занятие 3: счётчик операций, 12 фрагментов для разметки, бланк ответов с автопроверкой по отпечаткам и задание на выбор решения под ограничения | занятие 3, «временная сложность и O-нотация» |
| `benchmarks/` | измерительный контур `lab.py`, бланк `contour.py` с автопроверкой, замер с пятью дефектами, паспорт эксперимента `METHOD.md`, два CSV | занятие 4, «практические замеры времени и памяти» |
| `diagnostics/` | форма отчёта по входной диагностике, карта дефицитов и `task_lesson_01/` — условие задачи с заготовкой `solution.py` и тестами | занятие 1, выдаётся на паре: студент копирует файлы к себе в `lesson_01/` |
| `mocks/` | таблица шести секций и форма interview report | занятие 16, перед первым mock |
| `docs/` | `GIT_WORKFLOW.md` — ветки, коммиты, что писать в PR, как формулировать замечание; `RULES.md` — сроки, критерии, политика по ИИ | по мере необходимости; краткая версия уже есть в README студента |
| `scripts/setup.sh`, `Makefile` | автоматическая установка окружения и создание папки занятия | если группа справляется с командами — можно не давать вовсе |
| `.github/workflows/tests.yml` | CI: pytest на каждый push и Pull Request | когда дойдёте до автопроверок |
| `pytest.ini` | конфигурация запуска, если папок станет много | по мере роста репозитория |

## Как добавлять студенту

Просто копированием нужного файла в его репозиторий — merge из шаблона не
нужен, история у каждого своя.

```bash
cp course-materials/templates/interview_canvas.md <репозиторий>/lesson_02/
```
