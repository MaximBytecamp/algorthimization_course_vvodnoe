# Сложность: материалы занятия 3

Выдаётся на паре «Временная сложность и O-нотация». Студент копирует папку
к себе в `lesson_03/` и работает в своей ветке.

| Файл | Что это |
|---|---|
| `opcount.py` | счётчик сравнений: пять классов сложности на одних и тех же входах. Запускается на паре, с него начинается тема |
| `fragments.py` | двенадцать рабочих функций из разных предметных областей — материал для разметки |
| `answers.py` | бланк ответов: время, память и худший случай для двух фрагментов |
| `test_lesson_03.py` | автопроверка ответов по отпечаткам: верные оценки в тестах не лежат |
| `limits.md` | обратная задача — по ограничению из условия назвать подходящий класс решения |
| `turnstiles.py` | короткая практика на шесть минут: ускорить рабочее решение, не меняя ответа, и доказать это счётчиком |
| `acceptance_vetclinic.py` | приёмка: незнакомый код, четыре вопроса — время, память, худший случай и строка со скрытой стоимостью |

## Порядок работы на паре

```bash
python course-materials/complexity/opcount.py
python course-materials/complexity/opcount.py --sizes 8 16 32 64 128 1024
pytest course-materials/complexity/test_lesson_03.py -q
```

Сначала счётчик: студент видит, что при удвоении входа один столбец растёт
вдвое, другой вчетверо, а третий прибавляет две операции. Затем разметка
двенадцати фрагментов с автопроверкой. Затем `limits.md` и две заметки
о сложности по шаблону `templates/complexity.md`.

## Почему здесь нет замеров времени

`opcount.py` считает операции и не вызывает `time.perf_counter()`. Секунды
появляются на занятии 4, в `benchmarks/`. Разделение намеренное: на этом
занятии оценка выводится из кода и не зависит от того, у кого какой ноутбук.

## Как устроена автопроверка

В тесте лежат не ответы, а `sha256` от нормализованной записи вместе с именем
фрагмента — по шестнадцати символам оценку не восстановить, и одинаковые
ответы не выглядят одинаково. Запись приводится к общему виду: регистр,
пробелы, `n²` и `n^2` считаются одним и тем же. Записи с константами
(`O(2n)`, `O(n/2)`) отклоняются с объяснением, а не молча.

Если понадобится изменить набор фрагментов, отпечатки пересчитываются так:

```python
hashlib.sha256(f"{key}|t|{normalize(answer)}".encode()).hexdigest()[:16]   # время
hashlib.sha256(f"{key}|s|{normalize(answer)}".encode()).hexdigest()[:16]   # память
```
