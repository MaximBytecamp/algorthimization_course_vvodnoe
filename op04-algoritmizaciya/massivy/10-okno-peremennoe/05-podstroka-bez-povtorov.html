Подстрока без повторов
и частотная карта

В этой главе решается вторая задача КТП занятия 10 — найти самую длинную подстроку без повторяющихся символов. Схема прохода та же, что в главе 10.3, меняется состояние окна: вместо одного числа — словарь, в котором для каждого символа записано, сколько раз он встречается в окне. Сначала — решение перебором, затем частотная карта и условие допустимости на ней. Проход нужно сделать руками, собрать цикл из строк и написать функцию в песочнице. Затем разобраны две ошибки сжатия с прогонами, вариант решения с позициями символов и задача о числе подотрезков без повторов из статьи Яндекса.

§1Условие задачи

Условие уточнено в главе 10.2, здесь оно записано в окончательном виде. В примерах главы используются строки из таблицы той же главы.

longest_unique(text)задача 2 занятия 10 · подстрока без повторов

text — строка из любых символов, может быть пустой. Вернуть длину самой длинной подстроки, в которой все символы разные. Регистр различается: 'a' и 'A' — разные символы. Пробел — обычный символ. Для пустой строки вернуть 0.

Пример: text = 'abcabcbb'. Ответ 3: подстрока 'abc'. Подстроки длины 4 без повторов в этой строке нет: в ней всего три разных символа.

Это задача на самый длинный отрезок. Условие допустимости — «в окне нет двух одинаковых символов». Расширение окна может его нарушить, сжатие — восстановить, как с лимитом суммы в главе 10.3. Отличие в том, что по одному числу это условие не проверить.

§2Решение перебором

Прямое решение — для каждого начала l удлинять подстроку вправо, пока не встретится символ, который в ней уже есть. Символы текущей подстроки хранятся в множестве seen: проверка «есть ли символ в множестве» стоит O(1). Когда найден повтор, внутренний цикл прерывается оператором break: более длинные подстроки с тем же началом содержат тот же повтор.

Прогон на строке 'pwwkew', ответ 3. В прогоне строка передана списком символов, чтобы каждый символ стоял в своей ячейке; код работает и со строкой.

На шаге 13 найден первый повтор, и на шаге 16 множество собирается заново для начала l = 1. В этом потеря перебора: при переходе к следующему началу всё, что известно о подстроке, выбрасывается. Подстрока без повторов не длиннее числа разных символов m, поэтому внутренний цикл делает не больше m + 1 шагов, а всё решение — O(n·m). Для строки из латинских букв это немного, но в строке из миллиона разных символов Юникода m сравнимо с n, и время приближается к O(n²).

§3Частотная карта

Чтобы не собирать сведения о подстроке заново, их нужно обновлять при каждом сдвиге границы: добавлять пришедший символ и убирать ушедший. Сравнение из жизни: кладовщик ведёт карточку учёта, где для каждого товара записано, сколько штук сейчас лежит на полке. Привезли коробку — число в строке этого товара увеличилось на 1, забрали — уменьшилось на 1. Полку он при этом не пересчитывает.

Частотная картаfrequency map · словарь «значение → количество»

Словарь, в котором ключ — значение из окна, а значение по ключу — сколько раз оно встречается в окне. Для окна 'abca' карта равна {'a': 2, 'b': 1, 'c': 1}. Карта — состояние окна, такое же, как сумма в главах 10.3 и 10.4, только состоит из нескольких счётчиков.

При расширении счётчик пришедшего символа увеличивается на 1, при сжатии счётчик ушедшего уменьшается на 1. Обе операции со словарём стоят O(1) в среднем, поэтому сдвиг границы остаётся дешёвым.

Python в этой строке: count[ch] = count.get(ch, 0) + 1

Обращение count[ch] к ключу, которого в словаре нет, заканчивается исключением KeyError. Метод get(ключ, значение) возвращает значение по ключу, а если ключа нет — второй аргумент. Поэтому строка работает и для символа, который встретился впервые: get возвращает 0, к нему прибавляется 1. Уменьшать счётчик через get не нужно: уходящий символ был в окне, значит ключ в словаре есть.

>>> count = {}
>>> count.get("a", 0)
0
>>> count["a"] = count.get("a", 0) + 1
>>> count["a"] = count.get("a", 0) + 1
>>> count["b"] = count.get("b", 0) + 1
>>> count
{'a': 2, 'b': 1}
>>> count["a"] -= 1
>>> count
{'a': 1, 'b': 1}
>>> count["z"]
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
KeyError: 'z'

Теперь условие допустимости записывается через карту: окно без повторов — это окно, в карте которого все счётчики не больше 1. Проверять все счётчики на каждом шаге не нужно. До расширения окно было допустимым, в нём все счётчики равны 0 или 1. Расширение меняет один счётчик — пришедшего символа ch. Значит, нарушить условие может только он, и проверка сводится к одному сравнению: count[ch] > 1.

В таблице три задачи модуля записаны по одной схеме. Строки расширения, сжатия и условия цикла меняются вместе с состоянием окна, остальное в решениях одинаково.

В этой задаче символ в допустимом окне встречается не больше одного раза, поэтому состояние окна можно хранить и в множестве: пришедший символ уже в множестве — значит, появился повтор. Словарь со счётчиками нужен, когда символу разрешено встречаться несколько раз, как в LeetCode 2958, где каждое значение допускается не больше k раз. В КТП состояние этого занятия названо частотной картой, поэтому решение главы написано на словаре: оно без изменений переносится на такие задачи.

§6Код и пошаговый прогон

Прогон на примере из §1. Частотная карта показана в таблице переменных, строка count. В прогоне стоит проследить за тремя местами. На шаге 18 записан ответ 3 для окна 'abc'. На шагах 22–25 в окно пришла вторая a, и одно сжатие убирает повтор. На шагах 46–52 пришла b, а первым в окне стоит a: цикл while выполняется дважды, сначала уходит a, затем b.

На шаге 47 счётчик символа a становится равным 0, и ключ остаётся в словаре. На ответ это не влияет: условие цикла читает только счётчик пришедшего символа. Ключи с нулём занимают память, но их не больше, чем разных символов в строке. При желании такой ключ удаляют строкой del count[text[l]].

Инвариантокно с частотной картой

После цикла while на шаге с индексом r: для каждого символа count хранит число его вхождений в окно с l по r, все счётчики не больше 1, и это окно — самая длинная подстрока без повторов с концом в r.

Сохранение: расширение увеличивает счётчик пришедшего символа, каждое сжатие уменьшает счётчик ушедшего перед сдвигом l, поэтому карта соответствует окну. Цикл заканчивается при count[ch] ≤ 1, остальные счётчики не росли. Начала левее l отброшены по правилу главы 10.3: подстрока с таким началом и концом в r или правее содержит уже найденный повтор.

Оценка времени та же, что в главах 10.3 и 10.4: каждая граница проходит строку один раз, сдвигов не больше 2·n, каждый стоит одну операцию со словарём. Память — O(m): в карте не больше ключей, чем разных символов в строке. Вызовы ниже — классы входа из контроля КТП и уточнения из главы 10.2.

Для пустой строки цикл for не выполняется ни разу, и функция возвращает начальное значение best = 0. Отдельной проверки для этого случая в коде нет.

§7Две ошибки сжатия

Обе ошибки находятся в цикле сжатия, и обе не дают исключения: функция возвращает число больше верного. Первая — оператор if на месте while. В КТП контроль занятия требует, чтобы кандидат объяснял условие while, и этот пример показывает, что цикл нельзя заменить одной проверкой. Обе версии запущены на строке 'abba', верный ответ — 2.

§8Вариант с позициями символов

У задачи есть второе распространённое решение. В словаре вместо счётчика хранят позицию, на которой символ встретился в последний раз. Когда приходит символ, который уже есть в окне, левую границу переносят сразу за его прошлое вхождение — одним присваиванием, без цикла while.

Словарь last хранит позиции всех встреченных символов, в том числе тех, что из окна уже ушли: записи при сжатии не удаляются. Поэтому в условии две проверки. Первая — символ встречался. Вторая — его прошлая позиция не левее начала окна. Если вторую проверку пропустить, левая граница может сдвинуться назад. В главе 10.2 для этого случая записан пример 'abba', верный ответ — 2.

Оба решения работают за O(n). Вариант с позициями короче на одну строку и не содержит вложенного цикла. Вариант с частотной картой следует общей схеме модуля и переносится на задачи, где символу разрешено встречаться несколько раз. На интервью подходит любой из них, если кандидат объясняет, что хранит словарь и почему левая граница не сдвигается назад.

§9Число подотрезков без повторов

В главе 10.1 процитирована задача из статьи журнала Яндекс Образования: «дан массив чисел, требуется найти число подмассивов, в которых значения всех чисел различны». Она решается той же функцией с изменением в одной строке. После цикла while окно с l по r — самый длинный отрезок без повторов с концом в r. Любой отрезок с тем же концом и началом от l до r лежит внутри него и тоже не содержит повторов. Таких начал r − l + 1. Отрезки с началом левее l содержат повтор. Значит, на каждом шаге к ответу прибавляется длина окна.

В списке [1, 2, 1, 3] десять подотрезков. Два из них содержат повтор единицы: [1, 2, 1] и весь список. Остаются восемь. В списке [5, 5, 5] без повторов только три отрезка из одного элемента, в списке [1, 2, 3] — все шесть. Функция сверена с перебором всех подотрезков на 5 000 случайных списков.

§10Проверьте себя

Вопрос 1Окно 'cab', карта {'c': 1, 'a': 1, 'b': 1}. Приходит символ a. Каким будет окно после цикла while?

  • После ухода c окно равно 'aba', и счётчик a всё ещё 2. Цикл продолжается, пока повтор не исчезнет.

  • Верно. Цикл выполняется дважды: после ухода c счётчик a равен 2, после ухода первой a — 1.

  • Окно сжимается по одному символу и останавливается, как только счётчик a стал равен 1. Символ b при этом остаётся в окне.

Вопрос 2Почему в условии цикла достаточно проверить счётчик одного символа — count[ch]?

  • В словаре есть счётчики всех символов окна. Проверять их не нужно по другой причине: расширение их не меняло.

  • На следующих шагах проверяется счётчик нового пришедшего символа. Остальные проверять не нужно: расширение их не меняло.

  • Верно. По инварианту перед расширением все счётчики не больше 1. Расширение увеличивает только count[ch], поэтому превысить 1 может только он.

Вопрос 3Что вернёт longest_unique('aAa') и почему?

  • Верно. Подстроки 'aA' и 'Aa' без повторов, а вся строка содержит строчную a дважды.

  • По контракту регистр различается: 'a' и 'A' — два разных ключа словаря. Строка к одному регистру не приводится.

  • Повтором считается любой одинаковый символ в окне, соседство не требуется. В окне 'aAa' счётчик 'a' равен 2.
