§2Порядок работы на паре

Работа идёт в папке lesson_10 на своём компьютере, нужен Python с pytest. Если Python ещё не настроен, начните с песочниц в главах 10.3–10.5: там те же функции пишутся прямо на странице и проверяются похожими тестами. Сдаётся всё равно solution.py с зелёным pytest.

  1. Скопируйте папку lesson_10 в portfolio/lesson_10/ личного репозитория и выполните python -m pytest tests.py -v. Все 39 тестов должны упасть: так проверяется, что pytest нашёл файлы и запустил тесты.
  2. До кода откройте initial_attempt.txt и запишите вопросы к условиям задач 1 и 2 и примеры с ответами: «отрезка нет», сумма точно равна s, пустая строка, повторы. Образец — глава 10.2.
  3. Напишите longest_within. Проверка: python -m pytest tests.py -k within.
  4. Напишите shortest_window. Проверка: -k shortest, затем тесты границ: -k "bad_s or shortest_edges". Если тест падает, найдите симптом в сводке главы 10.9, §1.
  5. Напишите longest_unique: -k unique.
  6. Запустите замер: python bench.py > bench_results.txt. Он идёт около 25 секунд.
  7. Заполните complexity_note.md для трёх обязательных функций.
  8. Если осталось время — total_fruit, -k fruit.
  9. Если и это готово — extra.py: единицы с заменой нулей, единицы после удаления, число подотрезков без повторов. Проверка: python -m pytest tests_extra.py -v.
На полях: когда можно открыть главы

Код функций есть в главах модуля. На контроле занятия условие while и состояние окна объясняются своими словами, поэтому сначала пишется своя версия по схеме из главы 10.3, не открывая код. Если тест падает, откройте пошаговый прогон нужной главы и сравните шаги со своим кодом.

§4Вопросы для контроля

В КТП контроль занятия записан так: «Кандидат объясняет условие while и состояние окна. Проверяются дубликаты и пустая строка». Ниже эти требования разложены на вопросы и на то, что должно прозвучать в ответе. Главы в правом столбце — где это разобрано.

ВопросЧто должно прозвучать в ответеГде разобрано
Что хранится в состоянии окна и как оно меняется?Сумма или частотная карта для окна с l по r; при расширении добавляется пришедший элемент, при сжатии убирается ушедший до сдвига l10.3, §4; 10.5, §3
Почему у цикла такое условие?Самый короткий отрезок — сжимаем, пока окно подходит; самый длинный — пока окно недопустимо. В задаче о подстроке достаточно проверить счётчик пришедшего символа10.4, §2; 10.5, §3
Зачем здесь цикл while?Одного сжатия может не хватить: на 'abba' версия с if возвращает 310.5, §7
Почему вложенный while не даёт O(n²)?l только растёт и не обгоняет r, сдвигов не больше 2n; свои числа из замера10.3, §5; 10.7
Какие тесты проверяют дубликаты и пустую строку?Все символы одинаковые, повтор рядом, повтор символа вне окна, пробел; пустая строка — 010.6, §5
Что функция делает, если отрезка нет, и при неверном пороге?Отрезка нет — 0, это обычный ответ; порог меньше 1 — ValueError10.6, §4

§5Шпаргалка по модулю

Самый длинный отрезокl = 0 for r in range(len(nums)): добавить nums[r] в состояние while окно недопустимо: убрать nums[l] из состояния l += 1 best = max(best, r - l + 1)

Ответ записывается после цикла: там окно допустимо. O(n).

Самый короткий отрезокfor r in range(len(nums)): total += nums[r] while total >= s: записать длину r - l + 1 total -= nums[l] l += 1

Ответ записывается внутри цикла: после цикла окно уже не подходит. best = 0 значит «отрезка нет».

Частотная картаcount[ch] = count.get(ch, 0) + 1 while count[ch] > 1: count[text[l]] -= 1 l += 1

Уменьшается счётчик символа на левой границе. Если условие считает ключи, len(count), ключ со счётчиком 0 удаляют.

Признаки в условии

«подряд», «подмассив», «подстрока» и ограничение на содержимое без числа k: «сумма не меньше S», «без повторов», «не больше k нулей», «не больше двух видов».

Вопросы до кода

Бывают ли отрицательные числа. Что вернуть, если отрезка нет. Подходит ли сумма точно на пороге. Различается ли регистр, считается ли пробел символом. Может ли вход быть пустым.

Когда окно не подходит

Отрицательные числа: по сумме нельзя решить, какую границу сдвигать. Подпоследовательность: элементы не подряд. Длина задана числом: окно фиксированной длины, модуль 9.

Сложность и замер

Перебор — O(n²) в худшем случае, когда отрезка нет; на коротких ответах O(n·L). Окно — O(n) на любых данных. На 8000 элементах перебор медленнее в 4000 раз.

Типичные ошибки

Запись не в том месте относительно while. > вместо >=. if вместо while. l += 1 до вычитания. count[ch] -= 1. Нет проверки s < 1. Нет del при len(count).

§9Что дальше

Перед занятием 11 задачи модуля можно прорешать в формате собеседования: в главе 10.11 задачи на окно переменного размера идут по этапам секции с секундомером.

Префиксная сумма решает такие задачи иначе: сумма любого отрезка [l, r) вычисляется одной разностью двух заранее посчитанных чисел, и знак элементов на это не влияет.
