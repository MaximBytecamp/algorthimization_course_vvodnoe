§1Частотная карта как состояние окна

Задача: дана строка, нужно вернуть длину самой длинной подстроки, в которой все символы разные. Для 'abcabcbb' ответ 3 — подстрока 'abc'. По одному числу, как сумма в главе 10.2, проверить «нет повторов» нельзя: нужно знать, сколько раз каждый символ встречается в окне.

Для этого служит частотная карта — словарь, в котором ключ — символ окна, а значение — сколько раз он в окне встречается. Для окна 'abca' карта равна {'a': 2, 'b': 1, 'c': 1}. Сравнение из жизни: кладовщик ведёт карточку учёта, где для каждого товара записано, сколько штук лежит на полке. Привезли коробку — число увеличилось на 1, забрали — уменьшилось. Полку он при этом не пересчитывает. Так и здесь: при расширении счётчик пришедшего символа увеличивается на 1, при сжатии счётчик ушедшего уменьшается, и каждая операция стоит O(1).

Python в этой строке: count[ch] = count.get(ch, 0) + 1

Обращение к ключу, которого в словаре нет, заканчивается исключением KeyError. Метод get(ключ, 0) в этом случае возвращает 0, поэтому строка работает и для символа, который встретился впервые.

>>> count = {}
>>> count.get("a", 0)
0
>>> count["a"] = count.get("a", 0) + 1
>>> count["a"] = count.get("a", 0) + 1
>>> count["b"] = count.get("b", 0) + 1
>>> count
{'a': 2, 'b': 1}

Проверять все счётчики на каждом шаге не нужно. До расширения в окне не было повторов. Расширение меняет один счётчик — пришедшего символа ch. Значит, нарушить условие может только он, и проверка сводится к одному сравнению: count[ch] > 1.

§2Самый длинный отрезок: когда сжимать и когда записывать

В главе 10.2 искали самый короткий отрезок. Подходящее окно там сжимали, чтобы проверить окно короче, и длину записывали перед каждым сжатием. Здесь ищется самый длинный отрезок, и роли меняются: расширение может сделать окно недопустимым — появился повтор, — а сжатие возвращает его в допустимое состояние. Поэтому окно сжимают, пока оно недопустимо, а длину записывают после цикла: только там окно без повторов.

Сделайте проход сами на строке 'pwwkew'. Под лентой показана частотная карта окна.

После прихода второй w одного сжатия не хватает: сначала уходит p, и повтор остаётся. Окно становится допустимым только после ухода первой w. Ответ — 3, подстрока 'wke'.

При сжатии уменьшается счётчик символа на левой границе, text[l]: из окна уходит символ, который стоит слева, даже если повторяется другой. §5Та же схема: две корзины

В задаче LeetCode 904 сборщик идёт вдоль ряда деревьев с двумя корзинами, в каждой — фрукты одного вида, и срывает по фрукту с каждого дерева подряд. Нужно найти наибольшее число фруктов. После пересказа это самый длинный отрезок, в котором не больше двух разных чисел. Схема та же, меняется условие цикла: число разных видов — это число ключей карты, len(count) > 2.

Из-за этого появляется отличие от longest_unique: раз условие считает ключи, ключ ушедшего вида нужно удалять, когда его счётчик стал 0. Иначе len(count) учитывает виды, которых в окне уже нет. Ниже обе версии на [1, 2, 3, 2, 2], верный ответ 4.
