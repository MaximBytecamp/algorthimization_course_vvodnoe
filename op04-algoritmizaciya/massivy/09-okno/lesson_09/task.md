## Задачи

0. **Сумма каждого окна.** `window_sums_slices(nums, k)` — срезами, `window_sums(nums, k)` — сдвигом окна.
   Вернуть список из `n − k + 1` сумм. `1 <= k <= len(nums)`, иначе `ValueError`.
1. **Лучший отрезок длины k.** `best_window(nums, k)` → `(start, total)`: начало окна с наибольшей суммой
   и сумма. Числа бывают отрицательными, при равных суммах — самое левое окно, неверный `k` — `ValueError`.
2. **События во временном окне.** `max_events(times, w)`: моменты по возрастанию, окно `[s, s + w)`,
   вернуть наибольшее число событий в одном окне. Пустой список — 0, `w <= 0` — `ValueError`.
3. **Расширение: гласные в окне** (LeetCode 1456). `max_vowels(s, k)`.

Обязательны задачи 0–2, задача 3 — после них. Кто закончил всё, берёт `extra.py`: три задачи с LeetCode и 15 тестов.

## Порядок работы

1. Скопировать папку в `portfolio/lesson_09/` личного репозитория, выполнить `python -m pytest tests.py -v`.
   Все 34 теста падают.
2. До кода записать в `initial_attempt.txt` вопросы к условию задачи 1 и пять примеров с ответами,
   среди них `k = 1`, `k = n` и неверный `k`.
3. Решить `window_sums_slices` и `window_sums`, запустить `python -m pytest tests.py -k sums`.
4. Решить `best_window` (`-k best`), затем тесты границ: `-k "bad_k or k_is"`.
5. Решить `max_events` (`-k events`).
6. Запустить `python bench.py > bench_results.txt`.
7. Заполнить `complexity_note.md`.

## Ограничения

- В `window_sums`, `best_window`, `max_events` нет срезов внутри цикла и вызовов `sum` в цикле.
- ИИ и поиск решений — только после первой собственной версии и зелёных тестов.
