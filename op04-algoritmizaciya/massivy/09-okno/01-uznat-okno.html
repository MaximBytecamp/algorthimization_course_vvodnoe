9.1

Окно фиксированной длины:
как узнать задачу

Скользящее окно — приём для задач об отрезках подряд: ответ для следующего отрезка получают из ответа для предыдущего, учитывая только вошедший и вышедший элементы. В этом модуле длина окна задана числом k. В главе разобрано, как работает сдвиг окна, как узнать такую задачу по условию и что спросить у интервьюера до кода.

В этой главе
  1. Окно и его сдвиг
  2. Как узнать задачу по условию
  3. Вопросы до кода

§1Окно и его сдвиг

Подотрезок — несколько элементов списка подряд, в Python это срез a[l:r] из занятия 7. Пример задачи на подотрезок: сайт считает посетителей каждый час, нужно найти 3 часа подряд, за которые посетителей было больше всего.

Прямое решение — для каждого начала взять срез из трёх элементов и сложить. Но соседние срезы почти совпадают. Сравнение из жизни: поезд едет вдоль ряда столбов, в окне вагона всегда видно три столба. Когда поезд проезжает на один столб вперёд, справа появляется новый столб, а слева один исчезает. Два столба посередине остаются, их не нужно разглядывать заново.

В коде это записывается так. Окно — подотрезок nums[l:r] длины k. Сдвиг окна — переход на одну позицию вправо: в окно входит элемент справа, из него выходит элемент слева. Сумма окна хранится в переменной и при сдвиге исправляется: минус ушедший элемент, плюс пришедший. Такую переменную называют состоянием окна. Сдвиг стоит O(1), а весь проход — O(n) при любом k.

Кнопка «сдвинуть окно» в блоке ниже делает один сдвиг и показывает, как пересчитывается сумма. Под лентой два счётчика: сколько обращений к элементам нужно, если считать сумму каждого окна заново, и сколько — при сдвиге.

На семи значениях разница небольшая: 15 обращений против 11. С ростом списка она растёт. Пересчёт с нуля читает k элементов для каждого из n − k + 1 окон, это O(n·k). При n = 100 000 и k = 100 это 9,99 миллиона обращений против 199 900 у сдвига.

§2Как узнать задачу по условию

Окно фиксированной длины узнают по сочетанию признаков. Участок идёт подряд: «подряд», «подмассив», «подстрока». Длина участка задана числом: «длины k», «за любые 3 часа», «за неделю». Для каждого такого участка считается одна и та же величина — сумма, среднее, число гласных, — и её можно исправить по ушедшему и пришедшему элементу.

ЗадачаЧто считается в окне
Лучший отрезок длины k · задача 1 КТПСумма; нужна наибольшая
LeetCode 643 · наибольшее среднееСумма; среднее — сумма, делённая на k
LeetCode 1456 · гласные в подстрокеСчётчик гласных
События во временном окне · задача 2 КТПЧисло событий за w секунд

Окно фиксированной длины не подходит в трёх случаях. Если длина не задана и вместо неё стоит условие на содержимое — «сумма не меньше S», «без повторов», — это окно переменного размера, модуль 10. Если элементы можно брать не подряд — «любые k чисел», — окно не нужно: для наибольшей суммы достаточно выбрать k наибольших чисел. Если в окне нужен максимум, его нельзя исправить по ушедшему элементу: когда уходит сам максимум, новый неизвестен без просмотра окна. Для этого нужен дек, занятие 25.

§3Вопросы до кода

Первая задача КТП — найти лучший отрезок длины k. Задайте вопросы интервьюеру: после каждого появляются ответ и то, что он меняет в решении.

Лучший отрезок длины k
условие от интервьюера

«Дан список чисел — посещения сайта по часам — и число k. Найдите k часов подряд, за которые посетителей было больше всего».

уточнено

    Два ответа меняют код сильнее остальных. Ответ про отрицательные числа меняет начальное значение лучшей суммы. Ответ про k задаёт поведение на неверном входе: контроль занятия по КТП прямо требует «тесты k=0/1/n и неверного k». После вопросов условие записывается как контракт.
