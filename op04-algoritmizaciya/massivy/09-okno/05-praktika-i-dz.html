§2Порядок работы на паре

Работа идёт в папке lesson_09 на своём компьютере, нужен Python с pytest. Если Python ещё не настроен, начните с песочниц в главах 9.2–9.4: там те же функции пишутся прямо на странице и проверяются похожими тестами. Сдаётся всё равно solution.py с зелёным pytest.

  1. Скопируйте папку lesson_09 в portfolio/lesson_09/ личного репозитория и выполните python -m pytest tests.py -v. Все 34 теста должны упасть: так проверяется, что pytest нашёл файлы и запустил тесты.
  2. До кода откройте initial_attempt.txt и запишите три вопроса к условию задачи 1. Затем — пять примеров с ответами, среди них k = 1, k = n и неверный k. Образец — глава 9.1, §3.
  3. Напишите window_sums_slices, затем window_sums. Проверка: python -m pytest tests.py -k sums.
  4. Напишите best_window. Проверка: -k best, затем тесты границ: -k "bad_k or k_is". Если тест границы падает, найдите симптом в сводке главы 9.4, §2.
  5. Напишите max_events: -k events.
  6. Запустите замер: python bench.py > bench_results.txt. Он идёт около 35 секунд.
  7. Заполните complexity_note.md для четырёх обязательных функций.
  8. Если осталось время — max_vowels, -k vowels.
  9. Если и это готово — extra.py: перекраска блоков, подстроки из трёх разных букв, сердитый продавец. Проверка: python -m pytest tests_extra.py -v.
