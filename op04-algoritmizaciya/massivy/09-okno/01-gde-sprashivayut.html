§1Задачи на подотрезок на секции

Подотрезок массива — несколько элементов, которые стоят подряд: a[2], a[3], a[4]. В Python это срез a[2:5] из занятия 7. Задачи на подотрезки встречаются на алгоритмической секции с первого этапа. В журнале Яндекс Образования, в статье об алгоритмических собеседованиях, обе типичные задачи секции — про подотрезки.

«Типичный пример первой задачи: в массиве из чисел нужно найти наибольший неубывающий подотрезок, то есть такой подотрезок из чисел, где каждое следующее число больше или равно предыдущему».

Журнал Яндекс Образования · education.yandex.ru

«Типичный пример второй задачи: дан массив чисел, требуется найти число подмассивов, в которых значения всех чисел различны».

Там же

У массива из n элементов около n²/2 подотрезков, поэтому перебрать их все и для каждого посчитать ответ заново — это O(n²) или дольше. Скользящее окно проходит подотрезки по порядку и пересчитывает ответ по изменению: что вошло в подотрезок и что из него вышло. Первую задачу из цитаты решают одним проходом с текущей длиной подотрезка. Вторую — окном переменной длины со словарём, это тема занятия 10. Окно фиксированной длины, тема этого модуля, — самая простая форма приёма: длина подотрезка задана, и при каждом сдвиге в окно входит ровно один элемент и ровно один выходит.

§4Где приём работает в программах

Окно фиксированной длины встречается везде, где по ряду значений считают показатель за последние k значений или за последние N секунд.

Где встречается
  • Скользящее среднее. В аналитике и на графиках курсов валют сглаживают ряд: каждую точку заменяют средним последних k значений. В библиотеке pandas для этого есть метод rolling(k), пример ниже.
  • Последние k событий. В стандартной библиотеке Python очередь collections.deque(maxlen=k) хранит не больше k элементов: при добавлении нового самый старый удаляется. Так хранят, например, последние строки журнала.
  • Счётчики за последние N секунд. «Сколько запросов пришло за последнюю минуту», «сколько ошибок за последние пять минут» — в мониторинге и при ограничении частоты запросов. С каждым новым моментом времени в окно входят новые события и из него выходят устаревшие. Это задача о событиях во временном окне, глава 9.5.

Число посетителей сайта по часам, сумма за каждые три часа подряд. Первые два значения — nan: для них трёх значений ещё нет.

В обоих примерах окно длины 3 сдвигается на одну позицию: справа добавляется новое значение, слева уходит самое старое. В модуле этот сдвиг пишется вручную на обычном списке, без библиотек: так видно, сколько работы стоит каждый сдвиг.

§5Окно и его сдвиг

Перед определениями — пример из жизни, на котором видно, как работает сдвиг окна.

Для наглядности
Окно вагона

Поезд едет вдоль ряда столбов, в окне вагона всегда видно три столба. Когда поезд проезжает на один столб вперёд, справа в окне появляется новый столб, а слева один исчезает. Два столба посередине остаются, их не нужно разглядывать заново.

Что это в коде

Ряд столбов — список, окно — три соседних элемента a[l:l + 3]. Сдвиг окна — l += 1. Чтобы узнать сумму в новом окне, достаточно вычесть ушедший элемент и прибавить пришедший.

Где сравнение неточноПоезд едет непрерывно, а окно в алгоритме сдвигается ровно на один элемент за шаг. И окно не останавливается раньше времени: алгоритм проходит все окна от первого до последнего.

Теперь то же самое точными словами.

Окноwindow · полуинтервал [l, r)

Подотрезок списка, который задаётся двумя индексами: l — первый элемент окна, r — первый элемент за окном. В окно входят a[l], a[l + 1], …, a[r − 1], это срез a[l:r]. Длина окна — r − l: при записи полуинтервалом, как в занятии 7, длина считается без + 1.

Скользящее окно фиксированного размераfixed-size sliding window

Техника прохода, в которой окно длины k стоит сначала на a[0:k], а затем сдвигается на одну позицию вправо, пока не дойдёт до конца списка. Всего окон n − k + 1. При каждом сдвиге в окно входит один элемент справа и один выходит слева.

Ответ для окна — сумма, число гласных, количество событий — хранится в переменной, её называют состоянием окна. При сдвиге состояние не считают заново, а исправляют по двум элементам, которые изменились. Поэтому сдвиг стоит O(1), а весь проход — O(n).

Блок ниже показывает окно над списком посещений из §4. Кнопка «сдвинуть окно» делает один сдвиг и показывает, как пересчитывается сумма. Длину окна можно менять. Под лентой два счётчика обращений к элементам списка: сколько их было бы, если считать сумму каждого окна заново, и сколько нужно при сдвиге.

На семи значениях с k = 3 разница небольшая: 15 обращений против 11. Она растёт с длиной окна. Пересчёт с нуля читает k элементов для каждого из n − k + 1 окон, сдвиг — k элементов для первого окна и по два для каждого следующего.

nkПересчёт с нуля: (n − k + 1)·kСдвиг окна: k + 2·(n − k)

1 000 0001 000999 001 0001 999 000

Пересчёт с нуля стоит O(n·k): при k, сравнимом с n, это O(n²). Сдвиг окна стоит O(n) при любом k. Подробно оба способа и замер разобраны в главах 9.3 и 9.7.

§6Окно и два указателя

Границы окна l и r — это два указателя из модуля 8. Оба идут слева направо и назад не возвращаются, как указатели чтения и записи. Отличие в том, что расстояние между ними постоянно: r − l = k на каждом шаге. Поэтому оба указателя сдвигаются вместе, и в коде часто хранят только один из них.

§9Проверьте себя

Вопрос 1Почему сдвиг окна стоит O(1), хотя в окне k элементов?

  • sum(a[l:l + k]) создаёт срез и складывает все k элементов, это O(k). Выигрыш даёт отказ от пересчёта всей суммы.

  • Верно. Один элемент уходит слева, один приходит справа, остальные k − 1 остаются. Сумму исправляют вычитанием и сложением.

  • В окно входят все k элементов, и все они входят в сумму. Но при сдвиге меняются только два из них.

Вопрос 2Сколько окон длины 4 в списке из 10 элементов?

  • Последнее окно начинается с индекса 6: a[6:10]. Окна, которое начиналось бы с индекса 7, нет — ему не хватает элементов.

  • Это n − k. Окна начинаются с индексов 0, 1, …, 6 — это семь значений.

  • Верно: n − k + 1 = 10 − 4 + 1. Правило «элементов n, окон длины k — n − k + 1» из занятия 7.

Вопрос 3Какая форма окна подходит для задачи «найти самую длинную подстроку без повторяющихся символов»?

  • Верно. Длина окна в условии не названа, она определяется требованием «без повторов». Это LeetCode 3, занятие 10.

  • Для каждого k нужен свой проход, всего O(n²). Окно переменной длины решает задачу за один проход.

  • Указатели навстречу сравнивают элементы с разных концов. Подстрока — это участок подряд, его проходят указатели в одну сторону.
