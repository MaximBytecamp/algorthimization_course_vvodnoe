В этой главе

  2. Сводка ошибок по симптомам

§1Граничные значения k

При k = 1 окно — один элемент, и сдвигов больше всего. При k = n окно одно, и цикл не выполняется ни разу. Эти два значения проверяют, что код верен и при максимальном числе сдвигов, и без них. Значения k = 0, отрицательное k и k > n, а также пустой список — неверный вход: окна такой длины нет.

На неверный вход функция бросает ValueError. Без проверки она вернула бы правдоподобный ответ для окна, которого нет, и ошибка ушла бы дальше по программе. Ниже — версии без проверки и с ошибками на единицу.

best_window с одной изменённой строкойпереключите вкладку

Вход — [1, 2], k = 0. Верный ответ — ValueError.

(0, 0)Срез nums[:0] пустой, его сумма 0, и на каждом шаге прибавляется и вычитается один и тот же элемент. Ответ выглядит обычным.

Вход — [1, 2], k = 3. Верный ответ — ValueError.

(0, 3)Срез за границей списка ошибки не даёт: nums[:3] возвращает весь список. Функция возвращает сумму «окна длины 3» в списке из двух элементов.

Проверка k >= len(nums). Вход — [4, 1, 2], k = 3: окно одно, верный ответ (0, 7).

ValueErrorОшибка на единицу в проверке: функция отказывается работать на допустимом k = n.

Верная версия на [4, 1, 2], k = 3.

(0, 7)Цикл range(3, 3) пуст: сдвигов нет, окно одно.

§4Review обновления окна

По КТП решение сдаётся Pull Request, и проверяющий читает код окна по строкам. Ниже — что он проверяет. Этот же порядок годится для объяснения решения интервьюеру.

  1. Вход проверен до работы с окнами. Неверный k даёт ValueError, граница k = n пропускается.
  2. Первое окно посчитано целиком и учтено в ответе. Цикл начинается с range(k, len(nums)).
  3. Ушедший элемент — nums[r − k]. Сдвиг выполняется до сравнения с лучшим.
  4. Знак сравнения совпадает с условием. > — самое левое из равных окон.
  5. Есть тесты k = 1, k = n и неверного k. И тест, который сравнивает ответ с перебором срезов.
