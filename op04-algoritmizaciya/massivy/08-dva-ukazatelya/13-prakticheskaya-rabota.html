§2Часть 1. Сложность четырёх функций

Четыре функции решают одну задачу: найти в списке a два разных элемента с суммой target. Функции А, Б и В возвращают индексы пары, функция Г — значения. Функция Б рассчитана на отсортированный список, остальные работают с любым.

Время оценивается по числу повторений циклов при длине списка n: один проход — O(n), проход внутри прохода — O(n²), вызов встроенной сортировки — O(n log n). Дополнительная память — это структуры, размер которых растёт с n: новый список или словарь. Несколько отдельных переменных — O(1). Перетащите к каждой функции оценку времени и оценку памяти. Одна метка ставится в несколько мест.

Метки сложности

O(1)O(n)O(n log n)O(n²)

§3Часть 2. Функция под входные данные

Каждая карточка описывает входные данные и ограничения. Поставьте карточку к функции, которую нужно выбрать. Функция подходит, если выполняет все требования карточки и укладывается в лимит времени 1 секунда. Если подходят несколько, выбирается более быстрая, при одинаковом времени — с меньшей памятью.

Ориентир по времени

Python выполняет около 10⁷ простых операций в секунду. Перебор пар при n = 10⁴ делает около 5 · 10⁷ проверок — несколько секунд. При n = 10⁶ сортировка стоит около 2 · 10⁷ операций, но sorted написан на C и выполняется за доли секунды.

Карточки с входными данными

§5Часть 4. Строка с ошибкой

В каждой функции одна ошибка. Указан вызов, ожидаемый ответ и то, что функция возвращает на самом деле. Пройдите код по шагам на этом входе, щёлкните строку, из-за которой ответ неверный, и нажмите «Проверить строку». После проверки показываются разбор и исправленная строка.

Функция 1 · remove_valueФункция удаляет из nums все элементы, равные val, в том же списке, сохраняя порядок, и возвращает новую длину.
Вызов remove_value([3, 1, 3, 2], 3): ожидается функция возвращает 2, список [1, 2], а получается функция возвращает 4, список [3, 1, 3, 2].

def remove_value(nums, val):    w = 0    for r in range(len(nums)):        if nums[r] != val:            nums[w] = nums[r]        w += 1    del nums[w:]    return w
w += 1 стоит на уровне if, поэтому w растёт на каждом шаге вместе с r, и ни один элемент не пропускается. Строка должна быть внутри if:
        if nums[r] != val:
            nums[w] = nums[r]
            w += 1

Функция 2 · common_sortedФункция получает два строго возрастающих списка и возвращает список общих элементов по возрастанию за O(n + m).
Вызов common_sorted([1, 4], [2, 4]): ожидается [4], а получается [].

def common_sorted(a, b):    i = j = 0    res = []    while i < len(a) and j < len(b):        if a[i] == b[j]:            res.append(a[i])            i += 1            j += 1        elif a[i] < b[j]:            j += 1        else:            i += 1    return res
Когда a[i] < b[j], сдвигаться должен указатель на меньшее число — i. Здесь сдвигается j, и b[j] становится ещё больше. Ветки нужно поменять местами (засчитывается любая из двух строк):
        elif a[i] < b[j]:
            i += 1
        else:
            j += 1

Функция 3 · best_pair_underЦены отсортированы по возрастанию. Функция возвращает наибольшую сумму цен двух разных товаров, не превышающую бюджет, или −1.
Вызов best_pair_under([1, 4, 5, 9], 10): ожидается 10 (1 + 9), а получается 9.

def best_pair_under(prices, budget):    i, j = 0, len(prices) - 1    best = -1    while i < j:        s = prices[i] + prices[j]        if s <= budget:            best = s            i += 1        else:            j -= 1    return best
Каждая подходящая сумма записывается в best без сравнения с прежней. Сначала найдено 1 + 9 = 10, затем 4 + 5 = 9, и 9 затирает 10. Нужно оставить большую:
            best = max(best, s)

§7Часть 6. Слияние без повторов

В этой части функция пишется самостоятельно. Какую форму техники применить и какую сложность получить, нужно определить по условию, как в частях 2 и 3.

merge_unique(a, b)часть 6

Два склада присылают списки артикулов, которые есть в наличии. Каждый список отсортирован по неубыванию, внутри списка артикулы могут повторяться. Функция возвращает новый список всех различных артикулов из обоих списков по возрастанию, каждый артикул один раз.

Ограничения: время O(n + m), где n и m — длины списков; sorted, list.sort, set и dict не использовать; входные списки не менять.

Python в этой строке: res[-1] и пустой список

Индекс -1 обращается к последнему элементу списка. У пустого списка последнего элемента нет, и res[-1] падает с IndexError. Поэтому сначала проверяют, что список не пустой: not res истинно для пустого списка. В выражении not res or res[-1] != x вторая часть вычисляется, только если первая ложна, то есть список не пустой.

>>> res = [1, 3]
>>> res[-1]
3
>>> res = []
>>> not res or res[-1] != 5
True
