§2Порядок работы на паре

Работа идёт в папке lesson_08 на своём компьютере, нужен Python с pytest. Если Python ещё не настроен, начните с песочниц в главах 8.2 и 8.3: там те же функции пишутся прямо на странице и проверяются похожими тестами. Сдать при этом нужно solution.py с зелёным pytest.

  1. Скопируйте папку lesson_08 в portfolio/lesson_08/ личного репозитория и выполните python -m pytest tests.py -v. Все 37 тестов должны упасть с NotImplementedError : так проверяется, что pytest нашёл файлы и запустил тесты.
  2. До кода откройте initial_attempt.txt и запишите три вопроса к условию задачи 1 и пять примеров с ответами. Образец — глава 8.1, §3.
  3. Напишите pair_sum_brute. Запустите python -m pytest tests.py -k pair: тесты для перебора должны пройти, для указателей — ещё падать.
  4. Напишите pair_sum. Если какой-то тест падает, найдите симптом в сводке главы 8.4, §3: там указано, какую строку проверить.
  5. Напишите dedup_sorted и проверьте: -k dedup. Затем compress: -k compress.
  6. Запустите замер: python bench.py > bench_results.txt. Он идёт около 20 секунд.
  7. Заполните в complexity_note.md разделы для трёх обязательных функций.
  8. Если осталось время — move_zeros, -k zeros.
  9. Если и это готово — extra.py: наибольший объём воды, палиндром с пропуском знаков, тройки с нулевой суммой. Проверка: python -m pytest tests_extra.py -v.
