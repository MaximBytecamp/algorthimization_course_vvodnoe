# Карточка изменения условия

Выдаётся после того, как задача 3 прошла публичные тесты. На изменение — 5–15 минут.

## Новое требование

Модерации нужно сохранить удалённые комментарии: по ним разбирают жалобы.
Удалять ничего нельзя. Напишите в `solution.py` функцию

```python
def split_spam(comments: list[str]) -> int:
    ...
```

Функция переставляет элементы **в том же списке** так, чтобы:

- сначала шли обычные комментарии в исходном порядке;
- за ними — весь спам, в любом порядке;
- длина списка не изменилась.

Функция возвращает число обычных комментариев. Время O(n), дополнительная память O(1).

| До | Ответ | После |
|---|---|---|
| `["1", "http://x", "2", "http://y", "3"]` | `3` | `["1", "2", "3", …два спама…]` |

## Что сделать

1. Записать, чем новый инвариант отличается от инварианта `remove_spam`:
   что теперь лежит в зоне между указателями `w` и `r`.
2. Добавить в `tests.py` не меньше трёх тестов: без спама, весь спам, спам в начале и в конце.
   Проверять первые `k` элементов на равенство, остальные — через `all(is_spam(x) for x in comments[k:])`.
3. Прогнать весь набор тестов, включая старые.
4. Дописать в `complexity_note.md` строку про `split_spam`.
