# Карточка изменения условия · C#

Выдаётся после того, как задача 3 прошла публичные тесты. На изменение — 5–15 минут.

## Новое требование

Модерации нужно сохранить удалённые комментарии: по ним разбирают жалобы.
Удалять ничего нельзя. Добавьте в `Solution.cs` метод

```csharp
public static int SplitSpam(List<string> comments)
```

Метод переставляет элементы **в том же списке** так, чтобы:

- сначала шли обычные комментарии в исходном порядке;
- за ними — весь спам, в любом порядке;
- длина списка не изменилась.

Метод возвращает число обычных комментариев. Время O(n), дополнительная память O(1).

| До | Ответ | После |
|---|---|---|
| `{ "1", "http://x", "2", "http://y", "3" }` | `3` | `{ "1", "2", "3", …два спама… }` |

## Что сделать

1. Записать, чем новый инвариант отличается от инварианта `RemoveSpam`:
   что теперь лежит в зоне между указателями `w` и `r`.
2. Добавить в `Tests.cs` не меньше трёх тестов: без спама, весь спам, спам в начале и в конце.
   Проверять первые `k` элементов на равенство, остальные — через
   `comments.Skip(k).All(Solution.IsSpam)`.
3. Прогнать весь набор тестов, включая старые: `dotnet run`.
4. Дописать в `complexity_note.md` строку про `SplitSpam`.
