# lesson_07 · стартовый набор на C#

Материалы к занятию 7 ОП.04 «Массив: индексы, проходы, границы» для группы, которая
пишет на C#. Задачи и тесты те же, что в Python-наборе `lesson_07/`.

| Файл | Что в нём |
|---|---|
| `task.md` | условия трёх задач, примеры и ограничения |
| `Solution.cs` | сигнатуры методов с контрактами, тела не написаны |
| `Tests.cs` | 27 публичных тестов и место для своих |
| `Program.cs` | запуск тестов с фильтром по имени, без внешних пакетов |
| `Lesson07.csproj` | консольный проект .NET 8, запускается на .NET 8 и новее |
| `complexity_note.md` | шаблон заметки об инвариантах и сложности |
| `change_card.md` | карточка изменения условия, выдаётся после зелёных тестов задачи 3 |
| `homework_07.md` | домашнее задание |
| `Bugs07.cs` | три метода с ошибкой на границе для домашнего задания |

## Как начать

```bash
cp -r lesson_07_cs ~/algo-portfolio/portfolio/lesson_07
cd ~/algo-portfolio/portfolio/lesson_07
dotnet run
```

До первого решения все тесты падают с `NotImplementedException`: так и должно быть.
Решайте по одному методу и запускайте только его тесты:

```bash
dotnet run -- streak
dotnet run -- reverse
dotnet run -- remove
```

Внешних пакетов нет: интернет нужен только для первой сборки, если у .NET SDK
нет пакета ссылочных сборок для net8.0.
