# Замеры времени и памяти алгоритмов в Python

Python 3.10 или новее, сторонних зависимостей нет.
Распакуйте всю папку algorithm_measurements. Откройте терминал в этой папке.

```sh
python3 02_first_measurement.py
python3 03_growth_experiment.py
python3 04_constant_access.py
python3 05_linear_search.py
python3 06_quadratic.py
python3 07_list_vs_set.py
python3 10_final_experiment.py
python3 11_sum_comparison.py
python3 12_memory_comparison.py
python3 13_list_generator.py
python3 14_repeated_runs.py
```

В Windows можно заменить python3 на py. Файлы 01, 08 и 09 определяют функции
и сами не печатают результаты. measurements.py — общий модуль, держите его рядом.
Примеры из исходного задания сохранены; добавлены импорты и точки запуска.
Файлы 11–14 дополняют основной комплект практиками из слайдов 9, 23, 31 и 32.

Сначала запишите прогноз в презентации. Запустите скрипт на своём компьютере.
Перенесите секунды/пиковую память в пустые таблицы, сравните коэффициенты роста.
Все числа зависят от вашей машины; эталонных секунд нет. Время и память
измеряются отдельными вызовами: tracemalloc сам влияет на производительность.
Для очень быстрых операций накладные расходы таймера существенны; медиана
одиночных вызовов не устраняет их. Для углублённого замера используйте серии
операций через timeit, деля общее время на число операций.

В исходном коде память подписана MB: при делении на 1024**2 это MiB.
tracemalloc показывает отслеживаемые выделения Python, не весь RSS процесса.
Оценки сложности используют учебную модель постоянной стоимости арифметики
и фиксированного размера чисел. Python int может расти по числу бит.
Поиск в set имеет ожидаемую O(1), в худшем случае O(n).
Дополнительная память операции поиска O(1); сам set занимает O(n).
