07 · асимптотика

Константы и точка пересечения

Асимптотически лучше — не обязательно быстрее на малом входе

РЕШЕНИЕ AT₁(n) = 1000n

Линейный рост, но дорогая операция на каждом элементе.

РЕШЕНИЕ BT₂(n) = n²

Квадратичный рост, зато маленькая константа.

Выбор зависит от реального диапазона `n`, лимитов и цены памяти.

In-place

Меньше памяти — ценой изменения входного объекта

Контракт

Посчитать, сколько входящих ID уже известно системе

На входе два набора одинакового порядка размера: реестр `haystack` и пакет `needles`. Для каждого входящего ID нужен ответ о принадлежности реестру.

input
haystack: n
needles: n

output
count: int
37 · условие

Реализация A

Линейный поиск внутри линейного прохода

Оператор `x in list` в худшем случае просматривает список. Мы вызываем его для каждого элемента `needles`.

n · O(n) = O(n²)
algorithms.pylist
def count_in_list(haystack, needles):
    seen = list(haystack)
    return sum(
        1 for x in needles
        if x in seen
    )
38 · list

Реализация B

Хеш-таблица переносит цену в память

Множество строится за линейное время. Проверка принадлежности имеет ожидаемую стоимость `O(1)`, поэтому весь проход — `O(n)` в среднем.

O(n) + n · O(1) = O(n)
algorithms.pyset
def count_in_set(haystack, needles):
    seen = set(haystack)
    return sum(
        1 for x in needles
        if x in seen
    )
