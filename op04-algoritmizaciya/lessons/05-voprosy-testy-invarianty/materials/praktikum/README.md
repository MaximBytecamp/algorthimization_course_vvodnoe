# Практикум 5.7. Выбор алгоритма под ограничения

## Что в архиве

- `zadacha_a_kth.py` — десять реализаций задачи «k-й по величине элемент».
- `zadacha_b_poisk.py` — десять реализаций задачи «есть ли значение в списке».
- `test_variantov.py` — проверка, что варианты дают одинаковые ответы,
  пока соблюдены их требования к входу.
- `zamer.py` — замер выбранных вариантов на своей машине.
- `blank.md` — бланк: вопросы, карта вариантов, заказы, проверка.

## Порядок работы

1. Прочитайте условие задачи и запишите в бланк не меньше пяти вопросов,
   ответы на которые меняют выбор решения. Файл с вариантами пока не открывайте.
2. Откройте файл задачи и заполните карту вариантов: время, дополнительная
   память, требования к входу. Всё это есть в докстроке каждой функции.
3. Для каждого заказа из бланка выберите один вариант и запишите, почему
   именно он, а не соседний по таблице.
4. Назовите варианты, которые не подойдут ни одному заказу, и условия,
   при которых они были бы уместны.
5. Запустите проверку: `python3 -m unittest -v test_variantov.py`.
   Все тесты проходят — значит, дело не в правильности, а в ограничениях.
6. По желанию запустите `python3 zamer.py` и посмотрите на рост времени
   своими числами.

Участник 1 берёт задачу A, участник 2 — задачу B, затем меняются.

## Запуск

Нужен Python 3.10 или новее, сторонние библиотеки не требуются.

```
cd praktikum
python3 zadacha_a_kth.py
python3 zadacha_b_poisk.py
python3 -m unittest -v test_variantov.py
python3 zamer.py
```

В Windows вместо `python3` используйте `py`.
