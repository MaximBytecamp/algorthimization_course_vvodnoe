Границы чисел и переполнение

Диапазон числовых типов

Переполнение (overflow) возникает, когда результат не помещается в диапазон числового типа фиксированной разрядности. Точный диапазон знакового 32-битного целого: от −2³¹ до 2³¹ − 1, то есть от −2 147 483 648 до 2 147 483 647.

ЗначениеПомещается в signed int32?
2 000 000 000Да
2 000 000 000 + 2 000 000 000Нет: сумма 4 000 000 000
−2 147 483 648Да: нижняя граница
2 147 483 648Нет: на единицу выше верхней

Что происходит при переполнении, зависит от языка. В Java значение «заворачивается» и может стать отрицательным, в других языках выбрасывается исключение, а в C и C++ переполнение знаковых целых — неопределённое поведение. Поэтому заранее проверяют, помещается ли результат в тип.

Проверка диапазона в коде

Проверку удобно оформить функцией fits_int32: она возвращает True, если значение помещается в signed int32.

Перед кодом · кейсСумма элементов

Ситуация«Посчитайте сумму элементов массива». На Python это одна строка с sum, поэтому уточняют не алгоритм, а размер чисел.

Что спросить и что изменится от ответа
  1. Какой диапазон у элементов?Вместе с длиной массива диапазон даёт границу суммы: длина × наибольший модуль элемента.
  2. Сколько элементов бывает?Сто тысяч элементов по 10⁹ дают 10¹⁴. Такая сумма не помещается в int32.
  3. В каком типе хранится результат?В Python int растёт сам. В Java, C++, Go или в столбце базы данных тип фиксирован, и переполнение возможно.
  4. Нужна точная сумма или остаток от деления?В олимпиадных задачах часто просят сумму по модулю 10⁹ + 7. Тогда остаток берут на каждом шаге, и числа остаются маленькими.

ДоговорилисьСумма передаётся в поле int32. Код ниже проверяет, помещаются ли туда слагаемые и результат.

Каждое слагаемое помещается в int32, а их сумма уже нет. Python при этом вычислил 4000000000 точно: ограничение сработает только там, где результат попытаются записать в поле типа int32.

Что происходит с int в Python

Обычные целые int в Python имеют произвольную точность: по мере роста числа увеличивается его представление в памяти. Поэтому показанная сумма вычисляется точно. У этого есть цена: большое число занимает больше памяти, и операции с ним выполняются медленнее.

Граница снова появляется при передаче результата системе с фиксированным типом — например, внешнему формату с полем int32. Проверять нужно именно диапазон принимающей стороны, даже если Python вычислил сумму без ошибки.

Сумма находится от −10¹⁴ до 10¹⁴. Signed int32 недостаточно; signed int64 вмещает этот диапазон. Тест [10**9] * 100_000 должен дать 10**14. На Python используем обычный int; при передаче во внешнюю систему сверяем её тип.

Сумма квадратов элементов

В списке не более 1000 чисел, каждое по модулю не больше 10⁶. Функция возвращает сумму квадратов. Оцените наибольшее значение и выберите тип для результата.

Открыть разбор

Квадрат одного элемента доходит до 10¹², и он уже не помещается в signed int32 с пределом 2 147 483 647. Вся сумма не больше 1000 × 10¹² = 10¹⁵, а это укладывается в signed int64 с пределом около 9,2 · 10¹⁸.

Границу считают по худшему случаю: наибольший модуль элемента в квадрате, умноженный на длину списка. Проверять нужно и промежуточное значение, и итог: здесь выходит за int32 уже первое слагаемое.
