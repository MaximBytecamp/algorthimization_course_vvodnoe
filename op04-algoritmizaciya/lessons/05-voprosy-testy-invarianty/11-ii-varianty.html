«Одна задача — восемь решений»

Ограничение времени: 2 секунды · Ограничение памяти: 256 МБ · Python 3.12

Как заполнить одну задачу

  1. Отправьте ИИ условие задачи и получите 7–8 вариантов.
  2. В каждой строке таблицы запишите один вариант.
  3. Запустите вариант на данных n = 1 000 и n = 100 000. Запишите время и число проверок.
  4. Запишите оценку времени, дополнительную и пиковую память.
  5. Для каждого сценария выберите одну строку. В столбцах «Большой вход» и «Малый вход» напишите: «подходит — название варианта — причина».

Карточки «Сценарий 1» и «Сценарий 2» — это два разных заказчика. Они не требуют нового кода. По таблице выберите для каждого заказчика лучший уже написанный вариант.

Для замера числа проверок добавьте в код счётчик сравнений или условий. Пиковую память измерьте через tracemalloc.

Запрос к ИИ: «Предложи 8 вариантов решения. Для каждого напиши идею, худшее время, дополнительную память, изменения входных данных и подходящие ограничения. Сначала не пиши код».
