Почему решение сверяют с условием

На прошлой паре мы оценивали, сколько времени и памяти тратит алгоритм. Но быстрый алгоритм полезен, только если он возвращает правильный ответ. Например, поиск максимума с начальным значением best = 0 работает за O(n), а для списка [-7, -3] возвращает 0 — число, которого в списке нет. На этом занятии разбираем, как находить такие ошибки: уточнять условие, подбирать тесты и объяснять, почему цикл даёт верный результат.

Условие «найдите второй по величине элемент» допускает для [10, 10, 5] два ответа: 10, если считать позиции в отсортированном списке, и 5, если считать различные значения. Код для этих трактовок разный, поэтому трактовку выбирают до того, как начинают писать решение.

СитуацияИнтервьюер говорит: «Напишите функцию, которая возвращает второй максимум списка». Больше в условии ничего нет.

Что стоит спросить и что меняет ответ
  1. Второй по позиции после сортировки или второе различное значение?Для [10, 10, 5] это 10 или 5. От ответа зависит, убирать ли дубликаты.
  2. Что вернуть, если различных значений меньше двух?None, исключение или особое значение. Без этого пункта код падает на [10, 10], как показано ниже.
  3. Может ли список быть пустым?Если может, в контракт добавляют ответ для пустого списка, а в тесты — вызов с [].
  4. Можно ли менять исходный список?Если нельзя, numbers.sort() не подходит. sorted() создаёт копию и тратит O(n) памяти.
  5. Сколько элементов бывает?Для тысяч элементов сортировка за O(n log n) подойдёт. Для потока чисел нужен один проход с двумя переменными.

Контракт задачи

Контракт функции — договорённость о том, какие входные данные допустимы, что функция возвращает и как ведёт себя в особых случаях: на пустом списке, при повторах, когда ответа нет. По контракту пишут тесты и проверяют код. Если какой-то пункт не обсудили, поведение в этом случае всё равно задаст код, и узнают о нём уже по неверному ответу.

Что уточняемДоговорённость для практикума
ВходСписок целых чисел; пустой список допустим.
ЗначенияОт −10⁹ до 10⁹, дубликаты и ноль допустимы.
РазмерОт 0 до 100 000 элементов.
ОтветВторое различное по величине значение.
Ответа нетВернуть None, если различных значений меньше двух.
Изменение входаИсходный список сохраняется.

Например, [10, 10, 5] → 5, [10, 10] → None, [-7, -2, -9] → -7. Ответ None означает, что второго различного значения нет. Возвращать вместо него 0 нельзя: 0 может быть настоящим ответом, например для [5, 0].

Ограничения влияют на выбор алгоритма

Ограничения из условия определяют, какой алгоритм можно применить. Если список гарантированно отсортирован, число ищут бинарным поиском за O(log n). Без такой гарантии остаётся линейный поиск за O(n). Сортировать список ради одного поиска невыгодно: сортировка сама занимает O(n log n), это дольше линейного прохода.

Выбор с учётом размера

Для задачи есть решения за O(n²) и за O(n log n). Сравните объём работы при n = 50 и при n = 1 000 000. При каком размере входа решение за O(n²) допустимо?

Открыть разбор

При n = 50 решение за O(n²) делает порядка 2 500 шагов, и простой двойной цикл вполне подходит. При n = 1 000 000 шагов уже порядка 10¹², и нужен алгоритм за O(n log n). O-оценка показывает, как растёт объём работы. Реальное время зависит ещё от стоимости одной операции, поэтому его проверяют замером.
