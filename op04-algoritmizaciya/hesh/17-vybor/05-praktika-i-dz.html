§2Порядок работы на паре

По КТП занятие 17 состоит из теории на 35 минут и практики. Задачи 1 и 2 решаются в формате собеседования: 40 минут на обе, без ИИ и поиска. Работа идёт в папке lesson_17 на своём компьютере, нужен Python с pytest. Если Python ещё не настроен, начните с песочниц в главах 17.2–17.4: там те же функции пишутся прямо на странице. Сдать всё равно нужно solution.py с зелёным pytest.

  1. Скопируйте папку lesson_17 в portfolio/lesson_17/ личного репозитория и выполните python -m pytest tests.py -v. Все 48 тестов должны упасть: так проверяется, что pytest нашёл файлы и запустил тесты.
  2. До кода откройте initial_attempt.txt. Запишите вопросы к условиям задач 1 и 2, перебор с его сложностью и примеры с ответами: пустой список, один элемент, два разных элемента, число, равное половине target, одинаковые числа, несколько пар. Образец вопросов — глава 17.1, §4.
  3. Засеките 40 минут. Напишите has_duplicate и unique_in_order. Проверка: python -m pytest tests.py -k "duplicate or order".
  4. Напишите two_sum: -k sum. Если тест падает, найдите симптом в сводке главы 17.4, §4.
  5. Напишите duplicate_clients: -k clients. Правила ключа — в контракте, глава 17.1, §5.
  6. Запустите замер: python bench.py > bench_results.txt. Он идёт около 10 секунд. Заполните complexity_note.md и объясните решение соседу по схеме из главы 17.4, §6.
  7. Если осталось время — contains_nearby_duplicate, повтор на расстоянии не больше k: -k nearby. Словарь хранит последний индекс каждого числа.
  8. Если и это готово — extra.py: число пар равных элементов, разность двух массивов, разные ли частоты. Проверка: python -m pytest tests_extra.py -v.

3 · Самая длинная подстрока без повторовФункция longest_unique_substring(s), LeetCode 3. Вернуть длину самой длинной подстроки s, в которой ни один символ не повторяется. Символы сравниваются как есть, пробел — тоже символ. Пример: 'abcabcbb' → 3, 'bbbbb' → 1, 'pwwkew' → 3, '' → 0. Время O(n), память O(k), где k — число разных символов. Не меньше шести своих тестов: пустая строка, один символ, строка из одного повторяющегося символа, строка без повторов, 'abba', строка с пробелом.Окно переменной длины — модуль 10 книги о массивах; словарь «символ → последний индекс» — глава 17.3

Тест к bugs_17.py засчитывается, если до исправления он падает, а после — проходит. Тест, который проходит и на ошибочной версии, ошибку не находит.

Задача 3 соединяет две техники. Окно из модуля 10 хранит отрезок строки без повторов, словарь отвечает, встречался ли символ внутри окна и где. Когда правый край приходит к повтору, левый край прыгает за прошлое вхождение символа. Прыгать назад он не должен: на 'abba' вторая a встречалась на индексе 0, а левый край уже стоит на индексе 2. Объяснение этого места — часть заметки.
