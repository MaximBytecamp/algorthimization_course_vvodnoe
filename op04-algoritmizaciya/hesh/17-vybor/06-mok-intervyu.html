§1Как устроен тренажёр

Задача разбита на семь этапов шаблона interview canvas. Сначала открыт только первый; кнопка «Этап пройден» открывает следующий и записывает, сколько минут ушло на этап. Над этапами — полоса с планом: сколько минут отводится на каждый этап, чтобы уложиться в 25.

В каждом этапе сначала работа самостоятельно, потом сверка. Пересказ, перебор, правило шага и эталонный код спрятаны в раскрывающихся блоках, ответы к примерам скрыты до нажатия кнопки. В этапе «Перебор и идея» нужно выбрать технику из шести. Пять из них — формы хеш-структуры: множество уже встреченных, словарь «значение → индекс», словарь групп по построенному ключу, множество, построенное заранее из одного входа, и частотный словарь. Шестая — два указателя по отсортированному списку: одна задача тренажёра решается без хеш-структуры, и это нужно заметить. В последнем этапе эталонное решение проходится по шагам, и интервьюер задаёт вопрос, который меняет условие.

Секундомер запускается кнопкой «Старт» и не ограничивает время. В конце задачи появляется таблица «план — фактически». Кнопка «Открыть все этапы» показывает задачу целиком: так задачу разбирают после попытки или читают как разобранный пример.

В тренажёр не входят задачи дополнительного набора extra.py — LeetCode 1512, 2215, 1207 — и задача домашнего задания LeetCode 3. Их решения здесь были бы подсказкой.

Есть ли повтор
условие от интервьюера

«Дан список. Верните True, если какое-то значение встречается в нём хотя бы дважды.»

уточнено

    Запишите пять входов и ответы к ним, среди них — крайние случаи из уточнений. Ответы скрыты: сначала посчитайте сами, потом откройте и сравните. Ответы получены запуском эталонного решения.

    itemsОтветЧто проверяет
    [1, 2, 3, 1]Trueповтор в конце
    [1, 2, 3, 4]Falseповторов нет
    []Falseпустой список
    [1, 2]Falseдва разных элемента
    ['a', 'b', 'a']Trueстроки

    Сначала называют медленное решение, которое точно верное, и его сложность. Потом ищут быстрое: выбирают форму техники и формулируют правило шага.

    Перебор, который называет кандидат

    Сравнить каждую пару элементов: n(n − 1)/2 сравнений, O(n²).

    ТехникаКакая техника подходит?

    • Верно. Для каждого элемента важно только, встречался ли он левее. Множество уже встреченных берут, когда о каждом элементе нужно знать одно: был ли он левее. Проверка идёт до добавления, ответ находится на первом повторе.

    • Словарь «значение → индекс» берут, когда вместе с ответом «было ли» нужен индекс: пара с суммой, расстояние между повторами.

    • Словарь групп берут, когда ключ строится из записи и под одним ключом собираются несколько элементов: нормализованная почта, отсортированные буквы.

    • Множество, построенное заранее, берут, когда один вход задаёт допустимые значения. Второй вход проверяется по нему, каждый поиск в среднем O(1).

    • Частотный словарь берут, когда ответ зависит от того, сколько раз встречается значение, а не от того, где оно стоит.

    • Два указателя берут, когда список уже отсортирован. Сдвиг левого указателя увеличивает сумму пары, сдвиг правого — уменьшает, память O(1).

    Правило шага
    1. Структура. seen = set() — элементы левее текущего.
    2. Проверка. Если x in seen — return True.
    3. Добавление. Иначе seen.add(x); после цикла return False.

    Сложность называют до кода: интервьюер соглашается с решением раньше, чем на запись потрачено время.

    СложностьСколько стоит быстрое решение?

    • Каждый элемент проверяется и добавляется один раз, в среднем за O(1). Без повторов во множество попадают все n элементов.

    • Каждый элемент проверяется и добавляется один раз, в среднем за O(1). Без повторов во множество попадают все n элементов.

                  Сначала называют медленное решение, которое точно верное, и его сложность. Потом ищут быстрое: выбирают форму техники и формулируют правило шага.

                  Перебор, который называет кандидат

                  Перебрать все пары: O(n²). Или словарь из two_sum: O(n), но память O(n).

                  ТехникаКакая техника подходит?

                  • Словарь «значение → индекс» берут, когда вместе с ответом «было ли» нужен индекс: пара с суммой, расстояние между повторами.

                  • Словарь групп берут, когда ключ строится из записи и под одним ключом собираются несколько элементов: нормализованная почта, отсортированные буквы.

                  • Множество, построенное заранее, берут, когда один вход задаёт допустимые значения. Второй вход проверяется по нему, каждый поиск в среднем O(1).

                  • Частотный словарь берут, когда ответ зависит от того, сколько раз встречается значение, а не от того, где оно стоит.

                  • Верно. Список отсортирован, а память ограничена O(1). Два указателя берут, когда список уже отсортирован. Сдвиг левого указателя увеличивает сумму пары, сдвиг правого — уменьшает, память O(1).

                  • Множество уже встреченных берут, когда о каждом элементе нужно знать одно: был ли он левее. Проверка идёт до добавления, ответ находится на первом повторе.

                  Правило шага
                  1. Указатели. i, j = 0, len(numbers) - 1, цикл while i < j.
                  2. Сумма. Совпала — вернуть [i + 1, j + 1].
                  3. Сдвиг. Сумма меньше — i += 1, больше — j -= 1.

                  Сложность называют до кода: интервьюер соглашается с решением раньше, чем на запись потрачено время.

                  СложностьСколько стоит быстрое решение?

                  • Верно. Каждый шаг сдвигает один из указателей, всего не больше n − 1 шагов. Хранятся только два индекса.
