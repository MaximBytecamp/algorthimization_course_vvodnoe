§1Граничные входы

У задач занятия граничные входы — повтор буквы внутри слова, повтор слова, пустое слово, равные частоты на границе k и k больше числа разных. Ключ из множества и равные частоты разобраны в главах 18.2 и 18.3. Ниже ещё четыре версии, в которых одна строка записана иначе. Каждая работает на обычном входе и ошибается на граничном.

Функции с изменённой строкойпереключите вкладку

В group_anagrams последняя строка — return sorted(groups.values()): группы выглядят «аккуратнее». Вход — «слон», «кот», «нолс», «ток».

У всех четырёх ошибок одна общая черта: на примере из условия LeetCode ответ верный или принят. Ошибки видны только на входах, которые проверяют стабильность и дубликаты, — ровно то, что требует контроль КТП. Поэтому тесты занятия пишутся по списку граничных входов.

Ошибки таблицы делятся на две группы. Первая — ключ: он не хешируемый или одинаков у разных групп. Её находят слова с повторяющимися буквами. Вторая — восстановление ответа: потерян порядок входа, выбрано не то число при равных частотах, возвращены не числа. Её находят входы с равными частотами и тесты, которые сравнивают ответ целиком, без сортировки. Окно ниже проверяет обе группы.

§3Исправьте функции

В окне две функции модуля, в каждой по одной ошибке из таблицы. Сначала запустите тесты и посмотрите, какие падают. Затем по симптому найдите строку и исправьте её.

Обе ошибки в коде выглядят разумно: множество в ключе похоже на «буквы слова», а сравнение по значению — на аккуратную сортировку. Поэтому их находят тестами. Когда тесты зелёные, остаётся объяснить решение.

§4Как объяснить решение

Контроль КТП проверяет три вещи: какой ключ выбран и почему, как устроено восстановление ответа и что происходит при равных частотах и повторах. На собеседовании ответ строится в таком порядке.

  1. Ключ группировки. «Ключ одинаков у всех анаграмм: отсортированные буквы или кортеж из 33 частот. Ключ хешируемый: строка или кортеж, не список». Затем сравнить ключи: O(m log m) против O(m + 33), на коротких словах быстрее сортировка, на длинных — частоты.
  2. Две фазы. «Сначала частотный словарь за O(n), потом восстановление ответа: сортировка d разных чисел или вёдра по частоте. Возвращаю числа, а не частоты».
  3. Стабильность и дубликаты. «Повторы слов остаются в группе, группа — список. Порядок групп и чисел при равной частоте — порядок первого появления: его дают словарь и устойчивая сортировка». Затем назвать граничные тесты.

«Для каждого слова строю ключ — буквы по алфавиту — и кладу слово в группу этого ключа. Словарь хранит порядок вставки, поэтому группы идут как во входе, повторы слов сохраняются. Время O(n · m log m). Для длинных слов ключ из частот быстрее: O(m + 33), по замеру в 2,4 раза на словах из тысячи букв. На пятибуквенных он вдвое медленнее».

Что показываетКлюч группировки, сравнение двух подходов по оценке и по замеру, стабильность.

«Считаю частоты, сортирую d разных чисел по убыванию частоты, беру первые k. При равной частоте устойчивая сортировка оставляет порядок первого появления. Вёдра дают O(n), но в Python они медленнее: миллион пустых списков стоит 100 мс. Тесты: равные частоты на границе k, k больше числа разных, пустой список».

Что показываетВосстановление ответа, правило равных частот, сравнение решений по замеру, граничные тесты.

Эти три шага — тот же порядок, по которому проверяется работа на паре. Её задачи, стартовый набор и домашнее задание — в главе 18.5.
