§1Как устроен тренажёр

Задача разбита на семь этапов шаблона interview canvas. Сначала открыт только первый; кнопка «Этап пройден» открывает следующий и записывает, сколько минут ушло на этап. Над этапами — полоса с планом: сколько минут отводится на каждый этап, чтобы уложиться в 25.

В каждом этапе сначала работа самостоятельно, потом сверка. Пересказ, перебор, правило шага и эталонный код спрятаны в раскрывающихся блоках, ответы к примерам скрыты до нажатия кнопки. В этапе «Перебор и идея» нужно выбрать технику из шести: словарь групп по ключу, частотный словарь с повторным проходом по входу, частоты с сортировкой, частоты пройденной части для подсчёта пар, частоты по значениям с префиксными суммами и две частотные таблицы с делением. Все шесть — формы частотного словаря, и различаются они тем, как из частот восстанавливается ответ. В последнем этапе эталонное решение проходится по шагам, и интервьюер задаёт вопрос, который меняет условие.

Секундомер запускается кнопкой «Старт» и не ограничивает время. В конце задачи появляется таблица «план — фактически». Кнопка «Открыть все этапы» показывает задачу целиком: так задачу разбирают после попытки или читают как разобранный пример.

В тренажёр не входят задачи дополнительного набора extra.py — LeetCode 1394, 1636, 2085 — и задача домашнего задания LeetCode 692. Их решения здесь были бы подсказкой.

    ТехникаКакая техника подходит?

    • Частотный словарь с повторным проходом берут, когда ответ зависит и от частоты, и от позиции: «k-й элемент, встретившийся один раз». Первый проход считает, второй идёт по входу в его порядке.

    • Сортировку частот берут, когда ответ — элементы, упорядоченные по частоте. Сортируются только d разных значений, устойчивость сохраняет порядок первого появления.

    • Словарь частот пройденной части берут, когда считают пары i < j: для каждого x прибавляют, сколько подходящих значений уже встретилось левее. Это приём пары с суммой из модуля 17.

    • Частоты по значениям с префиксными суммами берут, когда значения — небольшие целые, а для каждого нужно знать, сколько значений меньше. Префиксные суммы — модуль 11 книги о массивах.

    • Две частотные таблицы берут, когда из одного набора букв собирают другой. Число копий — наименьшее отношение «есть / нужно» по буквам образца.

    2. Группа. При первом появлении ключа — пустой список, затем append(w).
    3. Ответ. list(groups.values()) — группы в порядке появления.

                  Перебор, который называет кандидат

                  Для каждого адреса искать его домен среди уже собранных групп перебором: O(n · d).

                  ТехникаКакая техника подходит?

                  • Частотный словарь с повторным проходом берут, когда ответ зависит и от частоты, и от позиции: «k-й элемент, встретившийся один раз». Первый проход считает, второй идёт по входу в его порядке.

                  • Сортировку частот берут, когда ответ — элементы, упорядоченные по частоте. Сортируются только d разных значений, устойчивость сохраняет порядок первого появления.

                  • Словарь частот пройденной части берут, когда считают пары i < j: для каждого x прибавляют, сколько подходящих значений уже встретилось левее. Это приём пары с суммой из модуля 17.

                  • Частоты по значениям с префиксными суммами берут, когда значения — небольшие целые, а для каждого нужно знать, сколько значений меньше. Префиксные суммы — модуль 11 книги о массивах.

                  • Две частотные таблицы берут, когда из одного набора букв собирают другой. Число копий — наименьшее отношение «есть / нужно» по буквам образца.

                  • Верно. Адреса с одним признаком — доменом — нужно собрать вместе. Словарь групп берут, когда элементы с одним признаком нужно собрать вместе. Признак — ключ: отсортированные буквы, домен почты. Ключ хешируемый, группа — список.

                  Правило шага
                  1. Очистка. e = e.strip(); без @ — пропустить.
                  2. Ключ. domain = e.rpartition('@')[2].casefold().
                  3. Группа. При первом появлении домена — пустой список, затем append(e).

                  Сложность называют до кода: интервьюер соглашается с решением раньше, чем на запись потрачено время.

                  Вопрос интервьюераИнтервьюер спрашивает: «Почему rpartition, а не split('@')[1]?»

                  • Оба метода проходят строку за O(длины). Разница в ответе на адресе с двумя @.

                  • split работает с любыми строками. Ошибка — в выборе части при двух @.

                  • Верно. Для 'a@b@c.ru' split('@')[1] даёт 'b', а домен — 'c.ru'.
