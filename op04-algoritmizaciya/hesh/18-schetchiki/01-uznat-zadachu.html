Счётчики и группировка:
как узнать задачу

Задачи занятия 18 — сгруппировать анаграммы и найти самые частые элементы. В обеих словарь не отвечает «было ли», как в модуле 17, а накапливает результат: число вхождений или список элементов. В главе разобраны два готовых инструмента для этого — Counter и defaultdict, признаки задачи, вопросы до кода и контракты функций модуля.

§1Словарь, который накапливает

Почтальон раскладывает письма по ячейкам с номерами домов. Он не ищет, было ли письмо в этот дом раньше. Он кладёт письмо в нужную ячейку, и к концу смены в каждой ячейке лежит стопка писем одного дома. Если вместо писем класть в ячейку счётные палочки, к концу смены будет видно, сколько писем пришло в каждый дом.

Словарь в задачах модуля работает так же. Ключ — номер ячейки, значение — то, что в ней накопилось. Если значение — число вхождений, это частотный словарь, или счётчик, он знаком по модулю 13 книги о строках. Если значение — список элементов с одним ключом, это группировка. Ключ, по которому элементы попадают в одну ячейку, называют ключом группировки.

ЧислоСколько раз встретился ключ{'болт': 3, 'гайка': 2} — продажи по товарам
СписокВсе элементы с этим ключом{'иклост': ['листок', 'слиток']} — слова из одних букв

В обоих случаях первое появление ключа требует отдельного действия: счётчик надо начать с нуля, список — создать пустым. В модуле 17 для этого писали if key not in groups: groups[key] = []. В модуле collections есть два типа, которые делают это сами.

§2Counter и defaultdict

Counter — словарь для подсчёта. Он строится из последовательности за один проход и для отсутствующего ключа возвращает 0. Метод most_common(k) отдаёт k самых частых пар «ключ — частота». defaultdict — словарь, который при обращении к отсутствующему ключу сам создаёт для него значение. Какое значение создать, задаёт аргумент: defaultdict(list) создаёт пустой список, defaultdict(int) — ноль.

В цикле нет проверки, есть ли уже буква в словаре: для новой буквы by_letter[item[0]] создаёт пустой список, и append добавляет в него товар. Повторы сохраняются: болт продан трижды, и в группе три болта.

У этого удобства есть цена. Чтение отсутствующего ключа в defaultdict тоже создаёт ключ.

Простая проверка «есть ли товары на букву в» добавила в словарь пустую группу. Если потом вернуть все группы, в ответе окажется лишняя. Проверяют наличие ключа через in — он ключ не создаёт. Counter при чтении отсутствующего ключа возвращает 0 и ключ не добавляет.

На занятии словари пишутся и вручную, и через эти типы. Ручная запись показывает, что происходит на каждом шаге, а на собеседовании часто просят решение без готового Counter.

§3Как узнать задачу по условию

Задачу на счётчики и группировку узнают по трём признакам.

  1. Ответ — сводка по значениям. В условии встречаются слова «сгруппируйте», «разбейте на классы», «сколько раз», «самые частые», «чаще всего», «по количеству». Где стоял элемент, для ответа не важно.
  2. Элементы с одним признаком нужно собрать вместе. Признак — ключ группировки: отсортированные буквы слова, первая буква, домен почты, частота. Простое решение сравнивает каждую пару элементов, O(n²). Словарь по ключу собирает группы за один проход.
  3. После подсчёта нужно восстановить ответ. Частоты — промежуточный результат. Вернуть нужно элементы: «три самых частых числа», а не «частоты 5, 4, 4». Этот шаг называют восстановлением ответа, и в нём часто ошибаются: возвращают пары или теряют порядок.

Если нужен только один самый частый элемент, сортировка не нужна: max(count, key=count.get) проходит словарь один раз. Бывает, что ответ зависит от того, где стоят элементы: «самая длинная серия одинаковых подряд», «первая буква без пары». Тогда одного счётчика мало, нужен ещё проход по исходной последовательности, как в первой уникальной букве из модуля 13.

§4Вопросы до кода

Первая задача КТП — группы анаграмм. На LeetCode слова состоят из строчных латинских букв, а порядок групп в ответе любой. Контроль занятия требует проверить стабильность и дубликаты, поэтому до кода их нужно уточнить. Слева — условие в том виде, в каком его произнёс интервьюер. Справа — вопросы.

    Ответ про порядок делает задачу строже, чем на LeetCode: там тест сравнивает группы без учёта порядка, а здесь сравнивает списки целиком. Это и есть проверка стабильности из контроля КТП. Устойчивым, или стабильным, называют результат, который сохраняет порядок входа там, где условие не требует другого.     §5Контракты функций

    На этих контрактах построены код и тесты модуля. Для каждой задачи по два решения: контроль КТП требует сравнить два подхода к ключу, а для самых частых чисел есть сортировка и вёдра.

    Правило «при равной частоте — в порядке первого появления» нужно, чтобы ответ был однозначным. На LeetCode условие гарантирует, что ответ единственный, и равных частот на границе k не бывает. В задаче занятия они бывают: для [5, 5, 2, 2, 7] и k = 1 подходят и 5, и 2. Контракт выбирает 5 — она встретилась первой. Первая задача — группы анаграмм, глава 18.2.

    Проверьте себяПосле строк d = defaultdict(int) и if d['x'] > 0: print('есть') что даст len(d)?

    • Чтение d['x'] в defaultdict создаёт ключ со значением по умолчанию, даже если результат только сравнивается.

    • Верно. Чтобы не создавать ключ, проверяют 'x' in d или пишут d.get('x', 0).

    • KeyError даёт обычный словарь. defaultdict для отсутствующего ключа создаёт значение.

    • int() без аргумента возвращает 0, это и есть значение по умолчанию.
