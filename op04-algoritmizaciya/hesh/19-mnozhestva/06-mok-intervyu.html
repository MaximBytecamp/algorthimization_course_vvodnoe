В этой главе восемь задач на множества в формате алгоритмической секции. Каждая проходит этапы по шаблону interview canvas: условие, уточнения, примеры, перебор и идея, сложность, код, проверка. Этапы открываются по одному, рядом идёт секундомер с планом на 25 минут. Код пишется и проверяется прямо на странице. Тренажёр устроен так же, как в главах 13.6–15.6 книги о строках и в главах 8.6–12.6 книги о массивах.

§1Как устроен тренажёр

Задача разбита на семь этапов шаблона interview canvas. Сначала открыт только первый; кнопка «Этап пройден» открывает следующий и записывает, сколько минут ушло на этап. Над этапами — полоса с планом: сколько минут отводится на каждый этап, чтобы уложиться в 25.

В каждом этапе сначала работа самостоятельно, потом сверка. Пересказ, перебор, правило шага и эталонный код спрятаны в раскрывающихся блоках, ответы к примерам скрыты до нажатия кнопки. В этапе «Перебор и идея» нужно выбрать технику из шести. Четыре из них — формы множества: множество одного входа с проходом по другому, множество значений с проверкой соседей, два множества для двух вопросов и множество посещённых состояний. Ещё две нужны, чтобы заметить, когда хватает другого: множества каждого входа с подсчётом и арифметика без дополнительной памяти.

Секундомер запускается кнопкой «Старт» и не ограничивает время. В конце задачи появляется таблица «план — фактически». Кнопка «Открыть все этапы» показывает задачу целиком: так задачу разбирают после попытки или читают как разобранный пример.

В тренажёр не входят задачи дополнительного набора extra.py — LeetCode 1436, 645, 884 — и задача домашнего задания LeetCode 36. Их решения здесь были бы подсказкой.

    • Множество значений берут, когда ответ зависит от соседних значений: есть ли x + 1, x + d. Порядок элементов во входе не важен, важно, какие значения есть.

    • Арифметику берут, когда ответ следует из формулы по всем данным: сумма 0…n известна заранее, и пропуск — разность. Память O(1).

    • Множество каждого входа берут, когда важно, в скольких входах встречается значение, а не сколько раз внутри одного.

    1. Множество. in_b = set(b), seen = set().

    3. Ответ. Список в порядке a.

                  • Арифметику берут, когда ответ следует из формулы по всем данным: сумма 0…n известна заранее, и пропуск — разность. Память O(1).

                  • Множество каждого входа берут, когда важно, в скольких входах встречается значение, а не сколько раз внутри одного.

                  • Множество из одного входа с проходом по другому берут, когда нужен состав двух списков и порядок одного из них. Множество отвечает «есть ли», порядок даёт проход.

                  Правило шага
                  1. Множество. s = set(nums).
                  2. Проверка. Для x: x + diff in s and x + 2 * diff in s.
                  3. Ответ. Число таких x.

                  Сложность называют до кода: интервьюер соглашается с решением раньше, чем на запись потрачено время.
