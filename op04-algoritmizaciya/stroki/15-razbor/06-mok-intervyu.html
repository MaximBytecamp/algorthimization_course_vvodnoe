§1Как устроен тренажёр

Задача разбита на семь этапов шаблона interview canvas. Сначала открыт только первый; кнопка «Этап пройден» открывает следующий и записывает, сколько минут ушло на этап. Над этапами — полоса с планом: сколько минут отводится на каждый этап, чтобы уложиться в 25.

В каждом этапе сначала работа самостоятельно, потом сверка. Пересказ, перебор, правило шага и эталонный код спрятаны в раскрывающихся блоках, ответы к примерам скрыты до нажатия кнопки. В этапе «Перебор и идея» нужно выбрать технику из шести: проход по сериям, разбор в два уровня, разбиение на слова, запись в тот же список, нарезка на группы и проход с конца. Каждая встречается в задачах тренажёра. В последнем этапе эталонное решение проходится по шагам, и интервьюер задаёт вопрос, который меняет условие.

Секундомер запускается кнопкой «Старт» и не ограничивает время. В конце задачи появляется таблица «план — фактически». Кнопка «Открыть все этапы» показывает задачу целиком: так задачу разбирают после попытки или читают как разобранный пример.

В тренажёр не входят задачи дополнительного набора extra.py — LeetCode 1446, 1108, 1859 — и задача домашнего задания LeetCode 8. Их решения здесь были бы подсказкой.

    Сначала называют медленное решение, которое точно верное, и его сложность. Потом ищут быстрое: выбирают форму техники и формулируют правило шага.

    Перебор, который называет кандидат

    Отрезать от строки найденную серию и продолжить с остатком: верно, но каждый срез копирует остаток, O(n · r), на коротких сериях O(n²).

    ТехникаКакая техника подходит?

    • Верно. Ответ строится из серий одинаковых символов. Проход по сериям берут, когда ответ строится из серий одинаковых символов: i стоит на начале серии, j уходит до её конца, затем i = j. Каждый символ проходится один раз.

    • Разбор в два уровня берут, когда строка делится на части, а каждая часть — ещё на две: поля по «;», поле по первому «=», адрес по «@».

    • split() без аргумента берут, когда части разделены пробелами в любом количестве: он режет по любым пробелам и не оставляет пустых слов. Ответ собирают через join.

    • Запись в тот же список берут, когда ответ нужно получить без нового списка: ответ не длиннее прочитанного, поэтому указатель записи никогда не обгоняет чтение.

    • Группы фиксированной длины берут, когда символы нужно переразбить на куски по k: сначала убрать старые разделители, потом нарезать заново.

    • Проход с конца берут, когда ответ находится в конце строки: не нужно делить всю строку, хватает символов последнего слова и пробелов после него.

    Правило шага
    1. Серия. j идёт от i, пока j < len(s) и s[j] == s[i].
    2. Запись. В out — символ и str(j - i), если длина больше 1.
    3. Сдвиг. i = j; в конце ''.join(out).

    Проверьте серии руками: впишите строку и посмотрите, на какие серии она делится и что попадёт в ответ.

    Сложность называют до кода: интервьюер соглашается с решением раньше, чем на запись потрачено время.

                  Перебор, который называет кандидат

                  len(s.split()[-1]): O(n) по времени, но split строит список всех слов, O(n) по памяти.

                  ТехникаКакая техника подходит?

                  • Разбор в два уровня берут, когда строка делится на части, а каждая часть — ещё на две: поля по «;», поле по первому «=», адрес по «@».

                  • split() без аргумента берут, когда части разделены пробелами в любом количестве: он режет по любым пробелам и не оставляет пустых слов. Ответ собирают через join.

                  • Запись в тот же список берут, когда ответ нужно получить без нового списка: ответ не длиннее прочитанного, поэтому указатель записи никогда не обгоняет чтение.

                  • Группы фиксированной длины берут, когда символы нужно переразбить на куски по k: сначала убрать старые разделители, потом нарезать заново.

                  • Верно. Ответ стоит в конце строки, читать её с начала не нужно. Проход с конца берут, когда ответ находится в конце строки: не нужно делить всю строку, хватает символов последнего слова и пробелов после него.

                  • Проход по сериям берут, когда ответ строится из серий одинаковых символов: i стоит на начале серии, j уходит до её конца, затем i = j. Каждый символ проходится один раз.

                  Правило шага
                  1. Хвост. j с конца, пока s[j] == ' '.
                  2. Слово. Пока j >= 0 и s[j] != ' ': length += 1, j -= 1.
                  3. Ответ. Вернуть length.

                  Сложность называют до кода: интервьюер соглашается с решением раньше, чем на запись потрачено время.
