§2Порядок работы на паре

Работа идёт в папке lesson_13 на своём компьютере, нужен Python с pytest. Если Python ещё не настроен, начните с песочниц в главах 13.2–13.3: там те же функции пишутся прямо на странице и проверяются похожими тестами. Сдать при этом нужно solution.py с зелёным pytest.

  1. Скопируйте папку lesson_13 в portfolio/lesson_13/ личного репозитория и выполните python -m pytest tests.py -v. Все 36 тестов должны упасть: так проверяется, что pytest нашёл файлы и запустил тесты.
  2. До кода откройте initial_attempt.txt. Запишите вопросы к условиям задач 1 и 2, перебор с его сложностью и примеры с ответами: пустая строка, разный регистр, ё и е, строки разной длины, строка без букв. Образец вопросов — глава 13.1, §4.
  3. Задача 0 — normalize_name, глава 13.3, §4. Проверка: python -m pytest tests.py -k name.
  4. Напишите letters и is_anagram: -k "letters or anagram". Если тест падает, найдите симптом в сводке главы 13.4, §2.
  5. Напишите first_unique: -k unique.
  6. Запустите замер: python bench.py > bench_results.txt. Он идёт около 10 секунд.
  7. Заполните complexity_note.md для трёх обязательных функций.
  8. Если осталось время — can_construct, записка из букв журнала: -k construct.
  9. Если и это готово — extra.py: сколько раз слово составляется из букв текста, изоморфные строки и слова, которые составляются из набора букв. Проверка: python -m pytest tests_extra.py -v.

ЗадачаЧто сделатьГде помогут
1 · Довести решенияsolution.py проходит все 36 тестов. bench_results.txt — ваш замер. complexity_note.md заполнен по трём функциям: правила нормализации и кто их задаёт, что хранится в словаре, время, память и таблицы двух опытов замера.Главы 13.2–13.4
2 · Три ошибки на границеВ bugs_13.py функции is_pangram_ru, top_letter, all_unique. Каждая верно отвечает на обычных входах и ошибается на граничном. Для каждой: вход, на котором ответ неверный; падающий тест в tests_bugs_13.py; исправление одной строки; повторный прогон. Вывод pytest — в bugs_run.txt.Глава 13.4: граничные входы и сводка ошибок; глава 0.2: где в таблице стоит ё
3 · Все анаграммы в строкеФункция find_anagrams(s, p), LeetCode 438. Вернуть индексы начала всех подстрок s, которые являются анаграммами p, по возрастанию. Символы сравниваются как есть. Пример: 'cbaebabacd', 'abc' → [0, 6]; 'abab', 'ab' → [0, 1, 2]. Время O(n · k), k — число разных символов; частоты каждой подстроки заново не пересчитывать. Не меньше шести своих тестов: p длиннее s, вхождения, которые перекрываются, повторы в p ('ааааа', 'аа'), кириллица, вхождений нет.Глава 13.2: частотный словарь; модуль 9 книги о массивах: окно фиксированной длины

Тест к bugs_13.py засчитывается, если до исправления он падает, а после — проходит. Тест, который проходит и на ошибочной версии, ошибку не находит.
