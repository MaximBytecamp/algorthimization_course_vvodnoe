13.3

Первая уникальная буква
и нормализация ввода

Вторая задача КТП — найти первую букву, которая встречается в строке один раз. В главе разобрано, почему для неё нужны два прохода, как убрать регистр, не сдвинув индексы, и что меняет ключ с регистром. Вторая часть главы — задача 0 занятия: привести ФИО из формы к единому виду.

В этой главе
  1. Почему одного прохода мало
  2. Код и пошаговый прогон
  3. Ключ с регистром
  4. ФИО из формы

§1Почему одного прохода мало

Возьмём слово «Казак». Первая буква К. Уникальна ли она, становится известно только на последнем символе: там стоит к, а регистр по контракту не важен. Так с любой буквой: пока строка не прочитана до конца, нельзя сказать, что буква больше не встретится. Поэтому решение состоит из двух проходов. Первый строит частотный словарь всей строки. Второй идёт по строке слева направо и возвращает индекс первой буквы, у которой частота 1.

Перебор делает то же без словаря: для каждой буквы вызывает text.count. Это O(n) на каждый из n символов, всего O(n²). В главе 0.4 и во втором опыте bench.py эта версия при n = 16 000 работает около 124 мс, два прохода со словарём — около 2 мс.

Строку по контракту не нормализуют: ответ — индекс в исходной строке, и удаление знаков сдвинуло бы индексы. Нормализация выполняется по месту. В первом проходе ключ словаря — символ после casefold. Во втором проходе символ, который не буква, пропускается проверкой isalpha.

§4ФИО из формы

Задача 0 занятия — нормализация пользовательского ввода. Покупатель вписывает ФИО в форму как угодно: ' салтыков-щедрин михаил '. Перед записью в базу и печатью на документах его приводят к единому виду: 'Салтыков-Щедрин Михаил'. В главе 0.3 строка приводилась к ключу для сравнения, и регистр там убирался полностью. Здесь результат показывают людям, поэтому каждое слово пишется с заглавной буквы, а буква ё сохраняется.

Правила записаны в контракте из главы 13.1: NFC, пробелы сжаты, в каждом слове и в каждой части двойной фамилии первая буква заглавная, остальные строчные. Порядок такой же, как в главе 0.3: сначала NFC, затем деление на слова. Деление на части через дефис идёт внутри слова.

Python в этой строке: part.capitalize() и title()

capitalize делает первую букву строки заглавной, а все остальные — строчными. title делает заглавной каждую букву, перед которой стоит не буква. Для двойной фамилии title подходит, а у фамилии с апострофом заглавной становится и буква после апострофа. По контракту нужен первый вариант, поэтому слово делится по дефису явно.

>>> 'иВАН'.capitalize()
'Иван'
>>> 'салтыков-щедрин'.title()
'Салтыков-Щедрин'
>>> "д'артаньян".title(), "д'артаньян".capitalize()
("Д'Артаньян", "Д'артаньян")

Прогон показывает, как строка из формы делится на слова и как каждое слово делится на части. Лента — список words.

На шаге 1 split() без аргумента убрал пробелы по краям и между словами, осталось два слова. На шаге 4 первое слово разделено по дефису на две части, каждая получила заглавную букву. Напишите функцию сами: тесты проверяют пробелы, неразрывный пробел, регистр, ё, NFD, апостроф и пустую строку.
