§1Частотный словарь

При инвентаризации склада порядок коробок на полках не записывают. Записывают, сколько единиц каждого товара: «болты — 120, гайки — 80». Две полки с одинаковыми записями равны по составу, как бы ни стояли коробки. Со строкой так же. Сколько раз символ встречается в строке, называют его частотой, а словарь «символ → частота» — частотным словарём.

Частотный словарь строится за один проход: для каждого символа счётчик в словаре увеличивается на единицу. Порядок символов в словаре — порядок их первого появления в строке, но на равенство словарей порядок не влияет.

Python в этой строке: count[ch] = count.get(ch, 0) + 1

Обращение count[ch] к ключу, которого ещё нет, даёт KeyError. Метод get возвращает значение по ключу, а если ключа нет — второй аргумент. Поэтому для новой буквы count.get(ch, 0) даёт 0, и счётчик становится равен 1.

>>> count = {}
>>> count.get('к', 0)
0
>>> count['к']
KeyError: 'к'

Counter из модуля collections строит тот же словарь одной строкой. На занятии словарь пишется вручную: так видно, что происходит на каждом шаге, а на собеседовании часто просят решение без готовых счётчиков. Сколько стоит каждый способ, измерено в главе 13.2.

§2Как узнать задачу по условию

Задачу на частоты узнают по трём признакам.

  1. Порядок символов не влияет на ответ. Важно, какие символы есть и сколько раз. В условии встречаются слова «анаграмма», «переставить буквы», «составить из букв», «одинаковый набор», «уникальный», «повторяется», «встречается чаще всего».
  2. Число разных символов ограничено. Строчных латинских букв 26, русских — 33. Словарь хранит не больше ключей, чем букв в алфавите, сколько бы ни было символов в строке.
  3. Перебор пересчитывает строку для каждого символа. Вызов text.count(ch) в цикле или поиск пары для каждой буквы стоит O(n²). Сортировка символов даёт O(n log n). Частотный словарь — O(n).

§3Когда словаря мало

Порядок символов важен. Частотный словарь забывает, где стоял символ. Для «марка» и «рамка» словари равны, а для вопроса «читается ли строка одинаково с двух концов» нужны позиции. Это задачи на палиндромы, занятие 14, их решают двумя указателями.

Символы должны идти подряд. В задаче 438 ищут подстроку, у которой частоты совпадают с образцом. Частоты считаются не по всей строке, а по окну фиксированной длины, и при сдвиге окна словарь обновляется на два символа. Это окно из модуля 9 книги о массивах, соединённое с частотным словарём.

Строк много, и их нужно группировать. Сравнивать каждую пару строк — O(n²) сравнений. Вместо этого каждой строке вычисляют ключ, одинаковый у всех анаграмм, и складывают строки в словарь по ключу. Такие задачи по КТП разбирают на занятии 18 о группировке.

§4Вопросы до кода

Первая задача КТП — анаграммы. В главе 0.3 правила нормализации задавало условие, здесь их получают у интервьюера. Слева — условие в том виде, в каком его произнёс интервьюер. Справа — вопросы. После каждого появляются ответ интервьюера и то, что он меняет в решении.

Анаграммы
условие от интервьюера

«Даны две строки. Проверьте, что одна получается из другой перестановкой букв».

уточнено

    Три ответа из пяти задают нормализацию: регистр, пробелы и знаки, NFC. Два других — граничные тесты: ё и пустые строки. Все пять ответов входят в контракт функции и в тесты занятия. Если такие вопросы не задать, решение опирается на допущения, которых в условии нет. Так в КТП сформулирован принцип занятия: «Перед строковым алгоритмом нужно явно определить нормализацию и единицу сравнения».
