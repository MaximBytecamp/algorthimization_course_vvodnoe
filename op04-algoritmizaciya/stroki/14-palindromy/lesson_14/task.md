# Занятие 14. Палиндромы и симметричные проверки — работа на паре

ОП.04 «Основы алгоритмизации и программирования», 3 курс.
Материалы: книга «Алгоритмы на строках», модуль 14, главы 14.1–14.6.

## Что в папке

| Файл | Что в нём |
|---|---|
| `solution.py` | пять функций с пустыми телами: `is_palindrome`, `is_palindrome_copy`, `can_be_palindrome`, `removal_index`, `longest_palindrome_length` |
| `tests.py` | 44 публичных теста pytest, среди них 36 тестов границ |
| `bench.py` | замер: указатели против копии по времени и памяти, одно удаление против перебора |
| `complexity_note.md` | заготовка заметки: инвариант указателей, время, память, замер |
| `initial_attempt.txt` | сюда до кода записываются вопросы к условию и примеры |
| `bugs_14.py`, `tests_bugs_14.py`, `homework_14.md` | домашнее задание |
| `extra.py`, `tests_extra.py` | дополнительные задачи: LeetCode 345, 1750, 1328 |

## Формат пары

По КТП задачи 1 и 2 решаются в формате собеседования: 40 минут на обе, без ИИ и поиска.
После решения — самостоятельный пошаговый проход на сложном примере (таблица указателей, глава 14.4)
и проверка кода соседом по списку из главы 14.4.

## Задачи

1. **Палиндром с пропуском символов** (LeetCode 125). `is_palindrome(text)`: два указателя без копии строки.
   Затем `is_palindrome_copy(text)` — та же проверка через очищенную копию, для замера.
2. **Почти-палиндром** (LeetCode 680). `can_be_palindrome(s)` и восстановление ответа `removal_index(s)`.
3. **Расширение: самый длинный палиндром из букв** (LeetCode 409). `longest_palindrome_length(s)`.

Обязательны задачи 1 и 2, задача 3 — после них. Кто закончил всё, берёт `extra.py`: три задачи и 15 тестов.

## Порядок работы

1. Скопировать папку в `portfolio/lesson_14/` личного репозитория, выполнить `python -m pytest tests.py -v`.
   Все 44 теста падают.
2. До кода записать в `initial_attempt.txt` вопросы к условию задач 1 и 2, перебор и примеры с ответами,
   среди них пустая строка, один символ, строка без букв, разный регистр, цифры.
3. Засечь 40 минут. Решить `is_palindrome` (`python -m pytest tests.py -k "palindrome_edges or no_copy"`),
   затем `can_be_palindrome` и `removal_index` (`-k "removal"`).
4. Заполнить таблицу указателей для фразы из главы 14.4 и пройти код соседа по списку проверки.
5. Решить `is_palindrome_copy` (`-k copy`) и запустить `python bench.py > bench_results.txt`.
6. Заполнить `complexity_note.md`.
7. Если осталось время — `longest_palindrome_length` (`-k longest`), затем `extra.py`.

## Ограничения

- `is_palindrome` не создаёт копию строки: ни среза, ни списка символов. Это проверяет тест `test_palindrome_no_copy`.
- `can_be_palindrome` — O(n): перебор удалений O(n²) записать в `initial_attempt.txt`, но не сдавать.
- ИИ и поиск решений — только после 40 минут и первой собственной версии.
