§2Порядок работы на паре

По КТП задачи 1 и 2 решаются в формате собеседования: 40 минут на обе, без ИИ и поиска. Работа идёт в папке lesson_14 на своём компьютере, нужен Python с pytest. Если Python ещё не настроен, начните с песочниц в главах 14.2–14.3: там те же функции пишутся прямо на странице. Сдать при этом нужно solution.py с зелёным pytest.

  1. Скопируйте папку lesson_14 в portfolio/lesson_14/ личного репозитория и выполните python -m pytest tests.py -v. Все 44 теста должны упасть: так проверяется, что pytest нашёл файлы и запустил тесты.
  2. До кода откройте initial_attempt.txt. Запишите вопросы к условиям задач 1 и 2, перебор с его сложностью и примеры с ответами: пустая строка, один символ, строка без букв, разный регистр, цифры, удаление последнего символа, два различия. Образец вопросов — глава 14.1, §4.
  3. Засеките 40 минут. Напишите is_palindrome без копии строки. Проверка: python -m pytest tests.py -k "palindrome_edges or no_copy".
  4. Напишите can_be_palindrome и removal_index: -k removal. Если тест падает, найдите симптом в сводке главы 14.4, §3.
  5. Заполните таблицу указателей для фразы «А в Енисее — синева» из главы 14.4, §2, и пройдите код соседа по списку из главы 14.4, §5.
  6. Напишите is_palindrome_copy (-k copy) и запустите замер: python bench.py > bench_results.txt. Он идёт около 5 секунд.
  7. Заполните complexity_note.md для четырёх обязательных функций.
  8. Если осталось время — longest_palindrome_length, самый длинный палиндром из букв строки: -k longest. Решение — частотный словарь из модуля 13, глава 14.1, §3.
  9. Если и это готово — extra.py: развернуть только гласные, удалить одинаковые концы строки, сломать палиндром одной заменой. Проверка: python -m pytest tests_extra.py -v.

ЗадачаЧто сделатьГде помогут
1 · Довести решенияsolution.py проходит все 44 теста. bench_results.txt — ваш замер. complexity_note.md заполнен: инвариант указателей, почему при первом различии хватает двух проверок, время, память и таблицы опытов замера.Главы 14.2–14.4
2 · Три ошибки на границеВ bugs_14.py функции is_word_palindrome, reverse_letters, count_mismatches. Каждая верно отвечает на обычных входах и ошибается на граничном. Для каждой: вход, на котором ответ неверный; падающий тест в tests_bugs_14.py; исправление одной строки; повторный прогон. Вывод pytest — в bugs_run.txt.Глава 14.4: граничные входы и сводка ошибок; глава 13.3: как делить строку на слова
3 · Самый длинный палиндром в строкеФункция longest_palindrome_substring(s), LeetCode 5. Вернуть самую длинную подстроку s, которая является палиндромом; если таких несколько — любую. Символы сравниваются как есть. Пример: 'babad' → 'bab' или 'aba'; 'cbbd' → 'bb'. Время O(n²), память O(1), без таблицы n × n. Не меньше шести своих тестов: пустая строка, один символ, палиндром чётной длины, вся строка — палиндром, кириллица, строка без повторов ('абв').Глава 14.1, §3: указатели от центра наружу

Тест к bugs_14.py засчитывается, если до исправления он падает, а после — проходит. Тест, который проходит и на ошибочной версии, ошибку не находит.

У задачи 3 бывает несколько верных ответов: для 'babad' подходят и 'bab', и 'aba'. Поэтому тест проверяет не конкретную подстроку, а три свойства ответа: длину, то, что ответ — палиндром, и то, что он есть в s.
