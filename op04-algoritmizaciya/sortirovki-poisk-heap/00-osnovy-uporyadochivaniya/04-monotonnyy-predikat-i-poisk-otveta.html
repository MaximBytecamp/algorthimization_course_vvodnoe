Бинарный поиск находит не только значение в списке. Он умеет находить наименьший ответ, который проходит проверку. Для этого проверка должна менять результат только в одном направлении.

В этой главе
  1. Ответ как число из диапазона
  2. Предикат «успеем ли за два рейса»
  3. Почему предикат монотонный

§1Ответ как число из диапазона

Нужно перевезти грузы массой 4, 8, 3 и 5 тонн за два рейса. Грузы идут в заданном порядке: сначала 4, затем 8, потом 3 и 5. Требуется найти наименьшую грузоподъёмность машины, при которой двух рейсов достаточно.

Машина не может иметь грузоподъёмность меньше 8: груз массой 8 тогда не поместится ни в один рейс. Грузоподъёмность 20 точно подходит: все грузы можно увезти за один рейс. Значит ответ лежит в диапазоне от 8 до 20.

Ищем минимальное число из этого диапазона.

Для каждого кандидата на ответ зададим один вопрос: хватит ли такой грузоподъёмности, чтобы выполнить перевозку не больше чем за два рейса? Функция с ответом True или False называется предикатом.

§2Предикат «успеем ли за два рейса»

Предикат получает одну вместимость capacity. Он последовательно добавляет грузы в текущий рейс. Когда следующий груз не помещается, начинается новый рейс. Если рейсов стало больше двух, кандидат не подходит.

Переменная current_weight хранит массу в текущем рейсе. Переменная trips считает начатые рейсы. Условие current_weight + weight > capacity проверяет, поместится ли следующий груз. Когда груз не помещается, счётчик рейсов увеличивается. Масса нового рейса начинается с нуля. Затем груз добавляется в этот рейс.

рейс 35третий рейс → не подходит

Для вместимости 11 понадобились три рейса. Предикат возвращает False.

Проверка capacity = 12ожидаем True
рейс 14 + 8масса 12
рейс 23 + 5масса 8

Для вместимости 12 достаточно двух рейсов. Предикат возвращает True.

Порядок грузов не меняется. При вместимости 12 груз 8 не объединяется с 3, потому что перед ним уже стоит 4: сумма 4 + 8 + 3 больше 12. Условие фиксирует порядок загрузки. При его изменении предикат описывал бы другую перевозку.

§3Почему предикат монотонный

Для вместимости 8, 9, 10 и 11 предикат возвращает False. Для 12 и всех больших вместимостей он возвращает True. Увеличение грузоподъёмности не может потребовать больше рейсов. Такая последовательность результатов называется монотонной.

Бинарный поиск по ответу хранит диапазон, в котором ещё может быть первый подходящий кандидат. Если середина подходит, ответ может быть равен середине или находиться левее. Поэтому правую границу сдвигают на середину. Если середина не подходит, ответ находится правее, и левую границу сдвигают за середину.

Здесь границы образуют полуинтервал [left, right] с кандидатом на ответ внутри. Цикл продолжается, пока границы различаются. Когда они совпадут, единственная оставшаяся вместимость будет первым значением с результатом True.

§4Четыре шага до минимального ответа

Начинаем с left = 8 и right = 20. На кадрах показан диапазон после каждого ответа предиката. Синий цвет — кандидаты, которые ещё могут стать ответом. Жёлтый — проверяемая середина. Серый — исключённые вместимости.

Шаг 1mid = 14, can_ship(14) = True
891011121314151617181920

14 подходит. Более маленький подходящий ответ может быть слева, поэтому right = 14.

Шаг 2mid = 11, can_ship(11) = False
891011121314151617181920

11 не подходит. Все меньшие вместимости тоже не подходят, поэтому left = 11 + 1 = 12.

Шаг 3mid = 13, can_ship(13) = True
891011121314151617181920

13 подходит. Ищем меньший ответ, поэтому right = 13.

Шаг 4mid = 12, can_ship(12) = True
891011121314151617181920

12 подходит. После присваивания right = 12 границы совпали: left == right == 12. Это минимальный ответ.

Ни один массив вместимостей создавать не нужно. Бинарный поиск использует только границы и вызывает предикат для нескольких чисел. Предикат даёт ответ на локальный вопрос «подходит ли кандидат». Поиск находит границу между ответами False и True.

  • Такой сдвиг отбросит подходящую середину и может пропустить минимальный ответ.

  • Середина подходит, но она может не быть минимальной.
