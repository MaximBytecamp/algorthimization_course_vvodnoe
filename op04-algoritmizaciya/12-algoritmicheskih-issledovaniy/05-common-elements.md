# 05. Общие числа двух списков

## Задача

Напишите `common_unique(left, right)`. Верните список чисел, которые есть в обоих списках. Повторов в ответе быть не должно. Порядок не важен.

## Входные данные

Два списка целых чисел `left` и `right`.

## Выходные данные

Список общих чисел.

## Пример

```text
[1, 2, 2, 4], [2, 2, 3] → [2]
```

## Данные для замеров

1. Два списка по 1 000 чисел.
2. Два списка по 100 000 чисел.
3. Два отсортированных списка по 100 000 чисел.

## Сценарии

1. В каждом списке 1 000 000 чисел, свободной памяти мало.
2. В каждом списке 100 чисел, нужен быстрый ответ.
