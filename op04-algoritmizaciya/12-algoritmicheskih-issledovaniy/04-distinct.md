# 04. Количество разных чисел

## Задача

Напишите `count_distinct(numbers)`. Верните количество разных чисел в списке.

## Входные данные

Список `numbers` из `n` целых чисел.

## Выходные данные

Одно целое число.

## Пример

```text
[5, 2, 5, 5, 9, 2] → 3
```

## Данные для замеров

1. 1 000 случайных чисел.
2. 100 000 случайных чисел.
3. 100 000 чисел от 0 до 99.

## Сценарии

1. `n = 10 000 000`, дополнительная память не более 8 МБ.
2. `n = 100`, значения от 0 до 999, нужен быстрый ответ.
