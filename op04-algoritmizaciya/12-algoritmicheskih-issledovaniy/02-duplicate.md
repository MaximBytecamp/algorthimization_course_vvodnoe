# 02. Повтор в списке

## Задача

Напишите `has_duplicate(numbers)`. Верните `True`, если хотя бы одно число встречается дважды. Иначе верните `False`.

## Входные данные

Список `numbers` из `n` целых чисел.

## Выходные данные

`True` или `False`.

## Пример

```text
[4, 9, 2, 9] → True
```

## Данные для замеров

1. 1 000 случайных чисел.
2. 100 000 разных чисел.
3. 100 000 чисел, повтор только в конце.

## Сценарии

1. `n = 10 000 000`, числа приходят по одному, памяти мало.
2. `n = 100`, проверка один раз, нужен быстрый ответ.
