# 11. Анаграмма

## Задача

Напишите `is_anagram(left, right)`. Верните `True`, если строки состоят из одинаковых букв в разном порядке. Регистр важен.

## Входные данные

Две строки `left` и `right`.

## Выходные данные

`True` или `False`.

## Пример

```text
"listen", "silent" → True
```

## Данные для замеров

1. Строки по 1 000 букв.
2. Строки по 100 000 букв.
3. Строки только из букв `a`…`z`.

## Сценарии

1. Строки по 10 000 000 символов, дополнительная память не более 16 МБ.
2. Строки по 100 символов, нужен быстрый ответ.
