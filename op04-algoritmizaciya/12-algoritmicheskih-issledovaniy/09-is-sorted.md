# 09. Проверка сортировки

## Задача

Напишите `is_sorted(numbers)`. Верните `True`, если список отсортирован по неубыванию.

## Входные данные

Список `numbers` из `n` целых чисел.

## Выходные данные

`True` или `False`.

## Пример

```text
[1, 2, 2, 5] → True
```

## Данные для замеров

1. 1 000 отсортированных чисел.
2. 100 000 случайных чисел.
3. 100 000 чисел, нарушение только в конце.

## Сценарии

1. `n = 10 000 000`, дополнительная память не более 8 МБ.
2. `n = 100`, нужен быстрый ответ для одного списка.
