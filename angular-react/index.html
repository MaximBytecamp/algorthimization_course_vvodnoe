Angular и React:
веб-приложения

Как устроено современное веб-приложение: компоненты, состояние, данные с сервера, несколько страниц, публикация и автоматизация. Основной фреймворк — React, Angular разбирается обзорно в модуле 4. Каждый модуль идёт по одной схеме: главы справочника, проект для своей службы колледжа и автоматизация, которая работает с этим проектом. Все инструменты бесплатные и запускаются на своём компьютере.

Проекты и автоматизация

П1 Проект модуля 1 · доска заявок своей службы

Доска из глав 1.1–1.7 переделывается для общежития, студсовета или своей службы: тексты, поле места, четыре категории, свои заявки. Сохранение в браузере и отправка новой заявки на вебхук n8n. Режим ИИ Р1 и журнал ai-log.md.

модуль 1projects/p1-вариантзащита по коду А1 Автоматизация модуля 1 · заявка → n8n → Telegram

n8n в Docker, бот от @BotFather, шаблон процесса из двух узлов: заявка с доски приходит мастеру сообщением в Telegram. Токен бота хранится в n8n и не попадает в код доски.

Docker · n8nбот Telegram П2 Проект модуля 2 · доска заявок с базой

Вариант проекта 1 переезжает на сервер: своя коллекция PocketBase с правилами доступа, загрузка с ошибкой и кнопкой «Повторить», хук, обновление по событиям без F5 и ИИ-диспетчер со своими категориями.

модуль 2projects/p2-вариантдва окна · сервер · бот А2 Автоматизация модуля 2 · ИИ-диспетчер и кнопка «Взять»

Языковая модель qwen2.5:3b в Ollama на своём компьютере определяет категорию и срочность заявки, n8n записывает категорию в PocketBase и присылает мастеру сообщение с кнопкой. Нажатие переводит заявку в работу на доске.
