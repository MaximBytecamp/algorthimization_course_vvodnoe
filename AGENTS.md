# Контекст проекта

Перед содержательной работой прочитайте `docs/project-context/INDEX.md`,
`CURRENT.md` и `PREFERENCES.md` (постоянные правила пользователя). Затем открывайте только тематические заметки,
которые нужны для текущей задачи. Не загружайте целиком `archive/claude-memory`:
его каталог находится в `archive/claude-memory/MEMORY.md`.

Для содержательных многошаговых задач применяйте `$router`: оставляйте простые
действия основной модели, а крупные изолируемые подзадачи направляйте экономичному
профильному агенту. Передавайте агенту только нужные пути, ограничения и ожидаемый
результат; не копируйте ему весь диалог или архив контекста.

Когда для задачи нужны прошлые решения, пути или ограничения, используйте
`$context-search` и открывайте только найденные заметки. Архив Claude ищите только
если основной контекст не дал ответа.

После продолжительной задачи обновляйте `CURRENT.md`. Устойчивые решения записывайте
в `DECISIONS.md`, постоянные ограничения — в `CONSTRAINTS.md`, согласованные будущие
задачи — в `BACKLOG.md`. Для передачи работы в новый чат используйте `$handoff`.

Полезный для будущих задач контекст сохраняйте в `docs/project-context` сразу после
появления: принятое решение, проверенный факт, найденный путь, особенность инструмента,
результат исследования или состояние большой работы. Не откладывайте запись до конца
сеанса. Обновляйте существующую тематическую заметку вместо создания дубликата.
После добавления, удаления или перемещения модуля либо урока обновляйте смысловой граф:
`python3 docs/project-context/tools/build_graph.py`.

После создания или существенной переработки учебной главы, урока либо другого
материала для студента перед отчётом о готовности один раз применяйте `$vychitka`
к завершённому материалу. Не запускайте полную вычитку после каждого абзаца;
повторяйте её только после существенных правок.

Проверки запускайте по изменённой области: для кода — ближайшие тесты, линтер или
сборку; после крупных изменений проектной памяти — `$context-audit`; перед переходом
в новый чат или после длинного этапа — `$handoff`. Не загружайте эти навыки в
контекст, если их условие не наступило.

В Claude Code те же навыки вызываются как `/router`, `/context-search`, `/handoff`,
`/context-audit`, `/vychitka`; агенты — `luna-fast`, `terra-writer`, `sol-builder`.
`PREFERENCES.md` и `CURRENT.md` подставляются хуком в начале сессии, повторно их не читайте. Встроенная
память Claude для проекта выключена: записывайте всё в `docs/project-context`.

Снимки экрана для своей проверки смотрите по уменьшенной копии в scratchpad
(`sips -Z 1200`), а рамку на кнопке и мелкий текст — по вырезанному фрагменту
в полном разрешении. Кадры для студентов не уменьшайте.

Проверяйте заметки по текущему коду и Git: архив содержит исторические срезы.
Сохраняйте чужие изменения рабочего дерева. Готовую работу сразу коммитьте и пушьте,
не спрашивая: в коммит идут только файлы этой задачи (правило в `PREFERENCES.md`).
Публикацию в других местах (артефакты, сайты, рассылки) выполняйте только по прямой
просьбе пользователя.
