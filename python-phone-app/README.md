# Собираем приложение на Python

Презентация для начинающих студентов по этапам документа `phone_app_steps (1).docx`.

- Откройте [index.html](index.html) в браузере: интернет для показа не требуется.
- [slides.pdf](slides.pdf) — статическая версия из 32 страниц. Переключение вариантов работает только в HTML.
- Стрелки `←` / `→` переключают слайды, `Home` / `End` — первый / последний.
- `F` включает полный экран; `N` показывает заметки преподавателя. Есть экранные кнопки.
- На слайдах с кодом нажимайте на строки: пояснение и визуальная модель изменятся.
- На слайде 28 вводите только вымышленные номера. «Перезапустить окно» моделирует загрузку ранее сохранённых записей; «Начать заново» очищает модель.

## Оформление

Цвета и блоки взяты из проекта «Твоя среда»: фон `#020835`, панели `#0a2d69`, прямые углы и тонкие границы. Заголовки — Haipapikuseru Rehyper, текст и код — Roboto Mono. Шрифты и лицензии находятся в `fonts/`; подключение к сети не требуется. Окно Tkinter сохраняет условное системное оформление, чтобы отличаться от самой презентации.

## Границы модели

Браузерная демонстрация написана на JavaScript. Она не запускает Python, Tkinter или SQLite и не создаёт файл базы. Данные хранятся в памяти страницы; её перезагрузка сбрасывает модель. Интерфейс условный: оформление и размеры настоящих элементов Tkinter зависят от системы и шрифтов. Окна в модели уменьшены в едином масштабе.

На настоящем занятии студенты собирают `app.py` из фрагментов, запускают его в Python 3 и проверяют сохранение после закрытия приложения. Относительный путь `phones.db` отсчитывается от рабочей папки запуска. Полный готовый исходник приложения в презентацию не включён.

В исходном плане этап 9 теряет автоматическое обновление списка после сохранения, которое было в этапе 8. В колоде оставлен согласованный вариант: `show_phones()` вызывается после успешного сохранения и очистки поля. Отдельная кнопка обновления — необязательное дополнение в заметках.

## Проверено

- Все 32 слайда в Chrome: 1440 × 900, 1280 × 800, 390 × 844.
- 198 переключений строк кода, без ошибок JavaScript и горизонтального переполнения страницы.
- Пустой ввод, обрезка крайних пробелов, добавление, сортировка, повторная загрузка и сброс модели.
- Настоящий SQLite во временном файле: создание таблицы, параметры, результат SELECT, порядок DESC, сохранность после переподключения, поведение NOT NULL и пустой строки.

Реальное окно Tkinter в рамках этих проверок не запускалось. Документация по конструкциям приведена в последнем слайде; пояснения преподавателю — в заметках каждого слайда.
