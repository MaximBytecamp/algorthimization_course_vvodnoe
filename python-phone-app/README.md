# Карточки клиентов на Python

Презентация для начинающих студентов: от пустого окна до локального справочника клиентов. Сквозная запись содержит имя, телефон и email. Основа — этапы `phone_app_steps (1).docx`, расширенные для карточки клиента.

- Откройте [index.html](index.html) в браузере: интернет для показа не требуется.
- [slides.pdf](slides.pdf) — статическая версия. Интерактивность доступна только в HTML.
- Стрелки `←` / `→` переключают слайды; `Home` / `End` — первый / последний.
- `F` включает полный экран; `N` показывает заметки преподавателя. Есть экранные кнопки.
- Нажимайте на строки кода: пояснение и модель окна или базы изменятся.
- В демонстрации вводите только вымышленные данные. «Перезапустить окно» моделирует повторную загрузку записей; «Начать заново» очищает модель.

## Содержание

44 слайда: результат и план, Python и его применение, устройство команды, Tkinter и SQLite, архитектура приложения, окно и его параметры, три поля ввода, обработчик кнопки, таблица `clients`, проверка заполнения, параметризованный INSERT, commit, загрузка SELECT и Listbox, проверка повторным запуском и границы работы с данными клиентов.

Каждый механизм сопровождается схемой, таблицей или условной моделью интерфейса. Python и SQLite представлены официальными логотипами; остальные иллюстрации созданы для этой колоды и не являются снимками настоящего приложения.

## Оформление и изображения

Цвета и блоки — из проекта «Твоя среда»: фон `#020835`, панели `#0a2d69`, прямые углы и тонкие границы. Заголовки — Haipapikuseru Rehyper, текст и код — Roboto Mono. Шрифты с лицензиями находятся в `fonts/`; логотипы и сведения об источниках — в `images/`. Сетевые подключения при показе не нужны.

Окно Tkinter имеет условное системное оформление, чтобы отличаться от самой презентации. Масштаб модели уменьшен; реальные размеры элементов зависят от системы и шрифта.

## Границы модели

Браузерная демонстрация написана на JavaScript. Она не запускает Python, Tkinter или SQLite и не создаёт файл базы. Записи хранятся в памяти страницы; её перезагрузка сбрасывает модель. «Перезапустить окно» сохраняет массив в памяти и повторно заполняет список — это имитация чтения из файла.

В настоящем приложении студенты собирают `app.py` из разобранных фрагментов и запускают его в Python 3. Файл `clients.db` создаётся относительно рабочей папки запуска. Таблица `clients` содержит `id`, `name`, `phone`, `email`. Полный готовый исходник приложения здесь не публикуется.

Все три значения обрезаются по краям и проверяются на пустоту. Формат телефона/email, существование адреса и уникальность карточки не проверяются. Параметры передаются SQLite отдельно от SQL-текста. `show_clients()` вызывается при запуске и после сохранения.

Прототип не предназначен для настоящих данных клиентов: нет разграничения доступа, встроенного шифрования базы, резервного копирования и полноценной обработки ошибок. Правила обработки персональных данных зависят от юрисдикции и процесса.
