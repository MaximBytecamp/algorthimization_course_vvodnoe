# Источники изображений

Логотипы сохранены локально, чтобы презентация работала без сети. Названия и логотипы обозначают соответствующие технологии; их присутствие не означает одобрения презентации правообладателями.

- `python-logo.svg` — официальный логотип Python, без изменения пропорций и цветов. Источник: https://www.python.org/static/community_logos/python-logo-generic.svg . Правила использования и сведения о товарных знаках: https://www.python.org/community/logos/ . Python Software Foundation.
- `sqlite-logo.svg` — официальный логотип SQLite, без изменения пропорций и цветов. Источник: https://www.sqlite.org/images/sqlite370_banner.svg . Сведения о правовом статусе SQLite: https://www.sqlite.org/copyright.html .

Получены 20.11.2026. Белая подложка в презентации нужна для читаемости оригинальных логотипов на тёмном фоне.

Карточки, схемы слоёв приложения, сопоставления полей, таблицы и модели окон созданы для презентации средствами HTML/CSS. Это условные иллюстрации, а не снимки работающего Tkinter. Имена и контактные данные вымышлены; адреса используют зарезервированный домен example.com.
