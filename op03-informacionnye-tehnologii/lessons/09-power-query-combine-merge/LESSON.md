## Уточнения сценария

1. From Folder может читать вложенные папки; later, backup и lookup вынесены за incoming. Отбор по точному пути и префиксу имени не фиксирует список трёх стартовых файлов.
2. Skip files with errors выключен: пропуски нельзя прятать ради успешной загрузки.
3. Combine сначала применяет правила чтения файла, затем складывает результаты по логике Append. Helper queries сохраняются.
4. Source.Name оставлен для происхождения; заголовки и типы проверяются до первого Refresh.
5. Перед Refresh явно показана Close & Load, затем возврат в редактор и импорт справочников.
6. Ключи соединения Text, Trim, lowercase в обеих таблицах; fuzzy matching выключен. Разные названия ключевых столбцов допустимы.
7. Уникальность ключа справа — условие сохранения числа строк после Expand. Left Outer сохраняет левые заявки, но множественные совпадения могут их размножить.
8. Вложенная Table может быть пустой, содержать одну либо несколько строк. В нашем lookup все описания заполнены, поэтому null показывает отсутствие связи. В общем случае это не универсальный тест: используется Left Anti.
9. После демонстрационного фильтра null удаляется именно последний Filtered Rows. Основной набор должен вернуться к 12 строкам до построения отчёта.
10. Merge as New: обе таблицы выбираются явно. Отчёт — подмножество основного набора, его строки не прибавляют к основному количеству.
11. Правка tiktok выполняется в исходном lookup CSV, не в загруженной Excel-таблице. Допустимость tiktok — явное условие упражнения.
12. status_order — порядок сортировки, не обязательная цепочка переходов done → rejected. is_final — логический тип.
13. Итоговая структура показана полностью: 8 исходных полей + Source.Name + 4 поля двух справочников = 13.
14. Исправлено направление зависимостей: справочники питают leads_combined; unmatched_sources зависит от leads_combined и sources_lookup.
15. Обновление папки читает её текущее состояние, не ведёт неизменяемый журнал. Удаление файла может убрать строки из следующего результата.
16. Финальное состояние: 6 CSV в incoming, 14 основных строк, одна REQ-121/youtube в unmatched_sources. Ошибки схемы обсуждаются без порчи рабочего набора.
