# Слайд 1. Google Analytics 4

## Заголовок

Google Analytics 4

## Подзаголовок

От перехода на сайт до данных о пользователе

## Текст

GA4 — система веб-аналитики Google.

Она позволяет видеть:

* сколько пользователей приходит на сайт;
* откуда они приходят;
* какие страницы открывают;
* какие действия совершают;
* какие источники приводят к нужному результату.

## Визуал

Не скриншот интерфейса.

Сделать простую схему:

Пользователь → Сайт → GA4 → Отчёты

# Слайд 2. Продолжаем тему UTM-меток

## Заголовок

Мы уже знаем, откуда пришёл пользователь

## Текст

UTM-метки находятся в ссылке и описывают источник перехода.

Например:

utm_source = telegram
utm_medium = social
utm_campaign = september

Но сама UTM-метка не создаёт отчёт.

Нам нужна система, которая получит эти данные, сохранит их и позволит анализировать.

Такой системой может быть Google Analytics 4.

## Визуал

Схема:

Telegram
↓
Ссылка с UTM
↓
Сайт
↓
GA4

Выделить UTM как информацию об источнике.

# Слайд 3. Что добавляет GA4

## Заголовок

GA4 видит не только источник

## Текст

После перехода пользователя GA4 может собирать информацию о его взаимодействии с сайтом.

Например:

* открытие страницы;
* переход между страницами;
* прокрутка;
* клик;
* отправка формы;
* регистрация;
* покупка.

Таким образом, можно связать источник пользователя с его дальнейшими действиями.

## Визуал

Схема:

Telegram
↓
utm_source = telegram
↓
Сайт
↓
page_view
↓
click
↓
generate_lead

# Слайд 6. Как устроен Google Analytics

## Заголовок

Account → Property → Data Stream

## Текст

Перед настройкой необходимо понимать три уровня.

**Account**
Контейнер верхнего уровня. Обычно соответствует организации, компании или владельцу данных.

**Property**
Ресурс, внутри которого собираются и анализируются данные конкретного продукта или проекта.

**Data Stream**
Источник данных: сайт, Android-приложение или iOS-приложение.

## Визуал

Большая схема:

ACCOUNT
Компания / проект

↓

PROPERTY
Сайт проекта

↓

DATA STREAM
Web

Не использовать скриншот. Лучше сделать схему.

# Слайд 15. Часовой пояс

## Заголовок

Шаг 7. Reporting time zone

## Текст

Выберите часовой пояс, по которому должны формироваться отчёты.

# Слайд 21. Что такое Data Stream

## Заголовок

Data Stream — поток данных

## Текст

Data Stream связывает источник данных с ресурсом GA4.

В нашем случае:

Сайт
↓
Web Data Stream
↓
GA4 Property

Через этот поток GA4 будет получать информацию о взаимодействии пользователей с сайтом.

## Визуал

Не нужен скриншот.

Сделать простую схему:

website.ru → WEB STREAM → GA4

# Слайд 27. Measurement ID

## Заголовок

Что такое G-XXXXXXXXXX?

## Текст

Measurement ID — идентификатор веб-потока GA4.

Он выглядит примерно так:

**G-XXXXXXXXXX**

По этому идентификатору определяется, в какой поток и ресурс необходимо отправлять данные сайта.

Это не пароль и не секретный ключ.

Он используется при настройке Google Tag и многих CMS.

## Скриншот

Крупный фрагмент **Web stream details**.

Выделить:

**Measurement ID: G-XXXXXXXXXX**
