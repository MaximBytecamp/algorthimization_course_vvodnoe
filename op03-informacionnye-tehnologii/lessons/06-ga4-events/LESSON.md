## Уточнения сценария

- file_download подтверждает клик по ссылке, а не завершение загрузки.
- form_submit не подтверждает приём заявки сервером. generate_lead в стенде иллюстрирует клиентскую проверку; для реального проекта нужен успешный ответ сервера.
- У старого шаблона есть contact-form и submit-обработчик: нужно переименовать форму и заменить обработчик, не дублировать его.
- Рекомендуемое имя не означает автоматическую реализацию события.
- Custom Dimension регистрирует разрез; отчётные данные появляются не мгновенно и не задним числом.
- Key Event — статус события, а не новый сетевой этап. Не включайте повторно, если generate_lead уже помечен.
- Для отключения debug_mode параметр удаляют, не устанавливают false.
- Учебную воронку нельзя считать из несопоставимых общих счётчиков событий.

## Что не завершено

39 предусмотренных сценарием кадров перечислены в SCREENSHOTS.md и shots/manifest.json. Для каждого кадра на соответствующем слайде есть пустая рамка с именем PNG. Новые скриншоты живых GA4/Vercel не получены: браузер возвращает ERR_CONNECTION_CLOSED для analytics.google.com, проверка соединения также дала TLS error. После восстановления доступа снять кадры по списку и повторить build.mjs.
