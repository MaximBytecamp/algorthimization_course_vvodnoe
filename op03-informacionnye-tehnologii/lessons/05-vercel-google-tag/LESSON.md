## Файлы

- `index.html` — готовая статическая веб-презентация.
- `styles.css` — локальные компоненты поверх общего `../../styles.css`.
- `script.js` — навигация, увеличение изображений, демонстрация публикации, подмена заглушек.
- `SOURCE.md` — неизменённый авторский текст.
- `build.mjs` — воспроизводимая сборка HTML, SVG и списков из исходника и отредактированных текстов. Запуск: `node build.mjs`.
- `screenshots.html` — доступный в браузере список всех кадров с переходами на нужные слайды.
- `SCREENSHOTS.md` — подробное задание на съёмку.
- `shots/manifest.json` — точная привязка исходных номеров, экранов темы и файлов.
- `shots/placeholders/` — 43 SVG-заглушки, не имитирующие настоящие интерфейсы.

## Визуальная система

Как в темах про воронку и UTM: подключён общий CSS дисциплины, используются его переменные `--brand-ink`, `--brand-blue`, `--brand-light`, `--paper-base`, `--brand-sky`. Сохранены светлый серо-зелёный фон, бирюза, тёмные рамки, небольшие скругления, тени со смещением. Шрифты: Space Grotesk / Inter / Roboto Mono с системными запасными вариантами.

Компоненты темы: цепочки публикации `.lab-flow`, сравнение неизменного Measurement ID с обновляемым URL `.identity`, анимация Save → Commit → Push → Deploy, интерактивная диагностика из 12 пунктов. Технические шаги расположены рядом с кадром соответствующего экрана. Авторский порядок и тексты слайдов 20–88 не изменены; десять дополнительных экранов собраны из тех же компонентов и вставлены после слайдов 24, 58, 77 и 78.

## Съёмка и замена

Все 43 кадра сняты с настоящих интерфейсов и лежат в `shots/` под именами из таблицы, например `60-shot.png`. Практика пройдена целиком на отдельном учебном стенде: репозиторий `MaximBytecamp/ga4-analytics-lab-ivanov`, сайт `https://ga4-analytics-lab-ivanov.vercel.app`, учебный поток GA4 с прежним Measurement ID. Рабочий ByteCamp не изменялся.

SVG-заглушки сохранены как запасной вариант: успешная загрузка PNG заменяет их при открытии страницы, а при отсутствии PNG остаётся заглушка и сломанного изображения не появляется. Замена выполняется в браузере через JavaScript; без JavaScript остаются исходные SVG.

Интерфейс GA4 на кадрах русскоязычный, а в текстах слайдов кнопки названы по-английски: снимали реальный аккаунт, язык интерфейса не переключали.

Слайд 23 содержит настоящий шаблон: https://github.com/MaximBytecamp/ga4-analytics-lab (Use this template включён). Его локальная копия — `../../ga4-analytics-lab/`, отдельный Git-репозиторий. Три страницы, CSS и JavaScript готовы; Google Tag в шаблоне отсутствует, студенты устанавливают свой. Для преподавателя создана отдельная копия https://github.com/MaximBytecamp/ga4-analytics-demo и опубликован сайт https://ga4-analytics-demo.vercel.app/. Статус стенда — `INFRASTRUCTURE.md`. Домены и Measurement ID внутри учебных примеров студенты заменяют своими. Авторский SOURCE.md сохранён без изменений.

## Уточнения к исходному тексту

- Для статического Vercel-проекта Other: пустая Build Command, при необходимости явный Override; без `public` публикуется корень.
- Клонирование, staging, commit и Push показаны через интерфейс VS Code, без терминала.
- Production URL отличается от URL отдельных Preview Deployment.
- Обновление Website URL потока не устанавливает тег и само по себе не является фильтром доменов.
- Localhost технически может передавать события; публичный URL выбран как цель этой практики.
- Google Tag ставится по одному разу на каждую отслеживаемую HTML-страницу.
- Новая вкладка не гарантирует новую сессию GA4; проверка отдельного UTM-источника требует новой сессии.
- Active users не позволяет однозначно идентифицировать человека.
- Enhanced Measurement уже может фиксировать часть кликов, скачиваний и взаимодействий с формами; следующая тема проверяет это и расширяет измерение.

Официальные источники доступны в окне S, сверены 11 сентября 2026 года.

## Проверка

Авторские 69 экранов ранее проверены при 1440×900, 1366×768 и 390×844: горизонтальных переполнений нет, на двух настольных размерах содержимое помещается без прокрутки. Проверены клавиатурная навигация, содержание, увеличение картинки, анимация публикации, диагностический чекбокс и чтение всех экранов без JavaScript.

После съёмки кадров и добавления десяти экранов проверено заново: колода отдаёт 79 слайдов, все 43 PNG загружаются вместо заглушек, сломанных изображений нет, ошибок JavaScript нет. Проверены двадцать прямых ссылок — по исходным номерам и по всем дополнительным `#24a` … `#78c`, — переходы из содержания и увеличение кадра по клику. Десять новых экранов проверены при 1440×900, 1366×768 и 390×844: горизонтальных переполнений нет, на настольных размерах они помещаются без прокрутки.

Печать и чтение без JavaScript после добавления экранов не перепроверялись. Показатели GA4 проверены на живом учебном потоке: Realtime получил `page_view`, проверка тега вернула «На вашем сайте обнаружен тег Google».

## Управление

← / →, Page Up / Page Down, пробел — листание; Home / End — начало / конец; M — содержание; S — источники; F — полный экран; Escape — закрыть диалог. Изображения увеличиваются по клику или Enter. На телефоне горизонтальный свайп листает, вертикальная прокрутка сохраняет доступ к длинным слайдам. Печать показывает все 79 экранов. Анимации учитывают `prefers-reduced-motion`.
