# Тема 5. Свой сайт, Vercel и Google Tag

69 экранов строго в порядке исходника: исходные слайды 20–88 соответствуют экранам 1–69 этой темы. На каждом слайде есть оба номера. Прямые ссылки используют исходный номер: `index.html#60` открывает вставку Google Tag (экран 41).

## Файлы

- `index.html` — готовая статическая веб-презентация.
- `styles.css` — локальные компоненты поверх общего `../../styles.css`.
- `script.js` — навигация, увеличение изображений, демонстрация публикации, подмена заглушек.
- `SOURCE.md` — неизменённый авторский текст.
- `build.mjs` — воспроизводимая сборка HTML, SVG и списков из исходника и отредактированных текстов. Запуск: `node build.mjs`.
- `screenshots.html` — доступный в браузере список всех кадров с переходами на нужные слайды.
- `SCREENSHOTS.md` — подробное задание на съёмку.
- `shots/manifest.json` — точная привязка исходных номеров, экранов темы и файлов.
- `shots/placeholders/` — 43 SVG-заглушки, не имитирующие настоящие интерфейсы.

## Визуальная система

Как в темах про воронку и UTM: подключён общий CSS дисциплины, используются его переменные `--brand-ink`, `--brand-blue`, `--brand-light`, `--paper-base`, `--brand-sky`. Сохранены светлый серо-зелёный фон, бирюза, тёмные рамки, небольшие скругления, тени со смещением. Шрифты: Space Grotesk / Inter / Roboto Mono с системными запасными вариантами.

Компоненты темы: цепочки публикации `.lab-flow`, сравнение неизменного Measurement ID с обновляемым URL `.identity`, анимация Save → Commit → Push → Deploy, интерактивная диагностика из 12 пунктов. Технические шаги расположены рядом с заглушкой соответствующего экрана. Исходный порядок не изменён и дополнительные учебные слайды не добавлены.

## Съёмка и замена

По указанию пользователя сейчас создаются заглушки. Скриншоты не снимались; внешние проекты и аккаунты в рамках этой темы не изменялись. Сохраните PNG в `shots/` под именами из таблицы: например, `60-shot.png`. После обновления страницы успешная загрузка PNG автоматически заменит SVG. Если PNG отсутствует, SVG остаётся; сломанного изображения нет. Замена выполняется в браузере через JavaScript; перед показом проверьте все настоящие кадры, читаемость и подписи. В режиме без JavaScript остаются исходные SVG.

Слайд 23 содержит настоящий шаблон: https://github.com/MaximBytecamp/ga4-analytics-lab (Use this template включён). Его локальная копия — `../../ga4-analytics-lab/`, отдельный Git-репозиторий. Три страницы, CSS и JavaScript готовы; Google Tag в шаблоне отсутствует, студенты устанавливают свой. Для преподавателя создана отдельная копия https://github.com/MaximBytecamp/ga4-analytics-demo. Домен проекта и Measurement ID в объяснениях пока остаются примерами. Авторский SOURCE.md сохранён без изменений.

## Уточнения к исходному тексту

- Для статического Vercel-проекта Other: пустая Build Command, при необходимости явный Override; без `public` публикуется корень.
- Клонирование, staging, commit и Push показаны через интерфейс VS Code, без терминала.
- Production URL отличается от URL отдельных Preview Deployment.
- Обновление Website URL потока не устанавливает тег и само по себе не является фильтром доменов.
- Localhost технически может передавать события; публичный URL выбран как цель этой практики.
- Google Tag ставится по одному разу на каждую отслеживаемую HTML-страницу.
- Новая вкладка не гарантирует новую сессию GA4; проверка отдельного UTM-источника требует новой сессии.
- Active users не позволяет однозначно идентифицировать человека.
- Enhanced Measurement уже может фиксировать часть кликов, скачиваний и взаимодействий с формами; следующая тема проверяет это и расширяет измерение.

Официальные источники доступны в окне S, сверены 11 сентября 2026 года.

## Проверка

Проверены все 69 экранов при 1440×900, 1366×768 и 390×844: горизонтальных переполнений нет, на двух настольных размерах содержимое помещается без прокрутки. Все 43 SVG загружаются. Проверены клавиатурная навигация, содержание, увеличение картинки, анимация публикации, диагностический чекбокс и чтение всех экранов без JavaScript. Ошибок JavaScript не обнаружено. Пробная печать даёт 69 непустых страниц PDF. Проверка выполнена в отдельном локальном Chromium; реальная работа внешних аккаунтов и показатели GA4 не проверялись.

## Управление

← / →, Page Up / Page Down, пробел — листание; Home / End — начало / конец; M — содержание; S — источники; F — полный экран; Escape — закрыть диалог. Изображения увеличиваются по клику или Enter. На телефоне горизонтальный свайп листает, вертикальная прокрутка сохраняет доступ к длинным слайдам. Печать показывает все 69 экранов. Анимации учитывают `prefers-reduced-motion`.
