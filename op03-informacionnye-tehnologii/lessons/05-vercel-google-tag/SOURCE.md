# Слайд 83. Если Realtime пустой

## Заголовок

Диагностика

## Текст

Проверяем по порядку:

1. сайт опубликован на Vercel;
2. открывается правильный `.vercel.app` URL;
3. этот URL указан в учебном Web Data Stream;
4. используется правильный Measurement ID;
5. Google Tag вставлен целиком;
6. тег находится после `<head>`;
7. изменения сохранены;
8. создан commit;
9. изменения отправлены в GitHub;
10. Vercel завершил новый Deployment;
11. открыта именно новая Production-версия;
12. браузер или расширение не блокирует Analytics.

После этого снова открыть сайт и Realtime.
