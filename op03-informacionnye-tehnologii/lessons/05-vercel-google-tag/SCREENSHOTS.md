# Скриншоты для темы 5

43 кадра. Номера файлов соответствуют исходному тексту (20–88), а не номеру шага.

Папка: op03-informacionnye-tehnologii/lessons/05-vercel-google-tag/shots/

Снимать PNG, желательно 1600×900 или больше, масштаб браузера 100%. Оставлять нужные поля и кнопки читаемыми. Для кадров сайта обязательно показать адресную строку. Для VS Code использовать графический интерфейс, как в исходнике. Не показывать пароли, email, аватар и посторонние проекты. Measurement ID не является секретом. Снимать только учебный поток; рабочий ByteCamp не изменять.

Не рисовать интерфейс и не подменять реальные результаты. Если экран недоступен, записать причину. Кадры 38–42, 50–52, 56–58 и 72–75 удобно снимать подряд. Для разных раскрытых списков и состояний нужны отдельные кадры.

После сохранения PNG под указанными именами презентация автоматически попробует загрузить их вместо SVG-заглушек при открытии. Заглушки сохраняются для отсутствующих PNG. Проверить кадры через HTTP-сервер; подписи и увеличение уже предусмотрены.
