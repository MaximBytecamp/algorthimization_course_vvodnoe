# Учебный стенд занятия 2 — UTM-метки

Развитие стенда занятия 1. Отличия:

- из адреса читаются три метки — `utm_source`, `utm_medium`, `utm_campaign`
  (плюс `utm_term` и `utm_content`, если они есть);
- первое значение сохраняется в `sessionStorage`, поэтому при переходе на вторую
  страницу сайта (`programma.html`) источник не теряется, хотя меток в адресе уже нет;
- в форме есть три скрытых поля, которые код заполняет значениями меток;
- после отправки показывается блок «Заявка сохранена» — строка, которая на настоящем
  сайте ушла бы в таблицу заявок, вместе с полями источника;
- под формой выведен блок `#peek`: что прямо сейчас лежит в скрытых полях. На настоящем
  сайте его нет — он нужен, чтобы разметку было видно до отправки.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | посадочная страница с кнопкой и формой |
| `programma.html` | внутренняя страница с такой же формой — переход без меток |
| `analytics.js` | учебный аналог `gtag.js`: чтение меток, `sessionStorage`, запрос `/g/collect` |
| `form.js` | подстановка меток в скрытые поля, событие `generate_lead`, показ заявки |
| `stend.css` | оформление |
| `serve.py` | локальный сервер: отдаёт файлы и отвечает `204` на `/g/collect` |

## Как запустить

**Способ 1, основной — свой сервер стенда** (работает без интернета):

```bash
cd stend && python3 serve.py
```

Открыть `http://localhost:8000/?utm_source=vk&utm_medium=social&utm_campaign=sept_open_2026`.

`serve.py` отличается от встроенного сервера Python тем, что знает адрес
`/g/collect` и отвечает на него `204 No Content` — как настоящий сервер аналитики.
Строки в панели Network будут зелёными, а в терминале печатаются имена
отправленных событий. Порт задаётся аргументом: `python3 serve.py 8080`.

**Способ 2 — любой статический сервер.** `python3 -m http.server`, Live Server
в VS Code и подобные адреса `/g/collect` не знают и отвечают `404` или
`405 Method Not Allowed` (Live Server — именно `405`, потому что `sendBeacon`
отправляет `POST`). Строка в панели будет красной. **Разбору это не мешает:**
запрос браузер сформировал, и все параметры читаются на вкладке Payload
при любом коде ответа. Но на занятии удобнее способ 1.

**Способ 3 — открыть файлом** (`open index.html`): запросы уйдут на настоящий адрес
`https://www.google-analytics.com/g/collect` и получат `204`. Нужен интернет.

## Что показывать на паре

1. Открыть с меткой → в `#peek` три значения → отправить → в заявке `vk / social / sept_open_2026`.
2. Открыть без метки → в `#peek` три `(not set)` → в заявке тоже `(not set)`.
3. Открыть с меткой → перейти на «Программу курса» → метки в адресе нет,
   а в `#peek` источник прежний: сработал `sessionStorage`.
4. Открыть с меткой `?utm_source=VK Реклама` → в адресной строке `VK%20Реклама`,
   в `ep.source` — `VK Реклама` с пробелом и прописными буквами.
