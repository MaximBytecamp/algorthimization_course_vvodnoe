# Учебный стенд занятия 2 — UTM-метки

Развитие стенда занятия 1. Отличия:

- из адреса читаются три метки — `utm_source`, `utm_medium`, `utm_campaign`
  (плюс `utm_term` и `utm_content`, если они есть);
- первое значение сохраняется в `sessionStorage`, поэтому при переходе на вторую
  страницу сайта (`programma.html`) источник не теряется, хотя меток в адресе уже нет;
- в форме есть три скрытых поля, которые код заполняет значениями меток;
- после отправки показывается блок «Заявка сохранена» — строка, которая на настоящем
  сайте ушла бы в таблицу заявок, вместе с полями источника;
- под формой выведен блок `#peek`: что прямо сейчас лежит в скрытых полях. На настоящем
  сайте его нет — он нужен, чтобы разметку было видно до отправки.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | посадочная страница с кнопкой и формой; стили встроены в `<style>` |
| `programma.html` | внутренняя страница с такой же формой — переход без меток; стили встроены |
| `analytics.js` | учебный аналог `gtag.js`: чтение меток, `sessionStorage`, сборка события |
| `g/collect.gif` | прозрачный пиксель 1×1, 43 байта — им отправляется событие |
| `form.js` | подстановка меток в скрытые поля, событие `generate_lead`, показ заявки |
| `serve.py` | локальный сервер: отдаёт файлы и отвечает `204` на `/g/collect` |

## Как запустить

Подойдёт **любой** способ отдать папку по HTTP: Live Server в VS Code,
`python3 -m http.server`, `python3 serve.py` из этой папки, публикация на Vercel
или GitHub Pages. Специальный сервер стенду не нужен.

```bash
cd stend && python3 serve.py        # либо Live Server, либо любой другой
```

Открыть `http://localhost:8000/?utm_source=vk&utm_medium=social&utm_campaign=sept_open_2026`.

**Почему работает везде.** Событие уходит запросом картинки: браузер загружает
прозрачный пиксель `g/collect.gif`, а все поля события едут в строке запроса этой
картинки. Файл существует, поэтому любой сервер отвечает `200`, и строки в панели
Network зелёные. Так работали счётчики до появления `sendBeacon` — на занятии 1 мы
разбирали этот способ под названием «отслеживающий пиксель», и часть рекламных
счётчиков пользуется им до сих пор.

Настоящий `gtag.js` вместо этого делает `POST` на `google-analytics.com/g/collect`
через `navigator.sendBeacon`. Для учебного стенда так не годится: раздатчики
статики адреса `/g/collect` не знают и на `POST` отвечают `404` или `405`, и
строки краснеют, будто стенд сломан. Набор полей события при этом одинаков —
разбираем мы именно их.

**Открыть файлом** (`open index.html`): в этом случае стенд шлёт `POST` на
настоящий адрес Google — как живой сайт. Нужен интернет.

## Что показывать на паре

1. Открыть с меткой → в `#peek` три значения → отправить → в заявке `vk / social / sept_open_2026`.
2. Открыть без метки → в `#peek` три `(not set)` → в заявке тоже `(not set)`.
3. Открыть с меткой → перейти на «Программу курса» → метки в адресе нет,
   а в `#peek` источник прежний: сработал `sessionStorage`.
4. Открыть с меткой `?utm_source=VK Реклама` → в адресной строке `VK%20Реклама`,
   в `ep.source` — `VK Реклама` с пробелом и прописными буквами.
