# Практика 8 · Power Query

1. Распакуйте архив в постоянную папку lesson_power_query.
2. Импортируйте data/leads_dirty.csv (UTF-8, запятая), выберите Transform Data.
3. Создайте запрос leads_clean по презентации. Сохраните книгу в result/power_query_leads.xlsx.
4. Для Refresh скопируйте содержимое leads_dirty_v2.csv в leads_dirty.csv, сохранив имя и путь. V2 не импортируйте новым запросом. Закройте текстовый редактор после сохранения.
5. В Excel: Data → Refresh All. Дождитесь завершения и сохраните книгу.
6. Для повторения верните содержимое leads_dirty_v1_backup.csv в leads_dirty.csv и обновите запрос.

Все данные вымышленные. Это учебный CSV, а не выгрузка настоящих заявок. Короткие REQ-001…REQ-008 — удобные метки строк для анализа; их не отправляют в приёмник темы 7, требующий UUID.

V1: 5 строк, 8 исходных столбцов, одна ошибочная дата (REQ-003).
V2: 8 строк, 8 исходных столбцов, две ошибочные даты (REQ-003 и REQ-008).
Результат после Split: 9 столбцов, столько же строк. Ошибочные даты сохраняем видимыми; не применяем Remove Errors или Replace Errors.

Trim удаляет только краевые пробелы. Чтобы получить Иван Тестов из Иван  Тестов, нужен отдельный Replace Values двух обычных пробелов на один. Clean удаляет управляющие символы; на V1 видимого изменения может не быть.
Trim + Clean: name, email, direction, source_medium, utm_campaign, status; ID остаётся Text. После Split повторите Trim двух UTM-полей. Lowercase: utm_source, utm_medium, utm_campaign, status. Replace tg → telegram только с Match entire cell contents.

Контроль REQ-006: Елена / telegram / social / lesson08 / new.
Контроль REQ-007: Максим / vk / social / lesson08 / done.
Имя/email не переводим в нижний регистр, пустые поля не выдумываем.

Основной маршрут слайдов — Excel для Windows. В Excel Microsoft 365 для Mac меню импорта может отличаться; перед началом убедитесь, что доступен Power Query Editor. Excel в браузере не является заменой этого пошагового маршрута.

В комплекте намеренно нет готовой книги: запрос создаётся студентом через интерфейс. При переносе папки на другой компьютер обновите путь в Source / Data Source Settings.
