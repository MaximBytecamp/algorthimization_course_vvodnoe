## Уточнения исходника

1. Выгрузка Google Sheets имеет 9 столбцов. Учебный файл намеренно подготовлен отдельно: 8 входных столбцов, включая объединённый source_medium. Это вымышленные данные, не реальные заявки пользователя.
2. Короткие REQ-001… используются только для чтения примеров. Сервер темы 7 принимает полный UUID; эти CSV в него не отправляют.
3. Распаковка, выбор постоянной папки и доступность редактора объяснены до импорта. Основной маршрут — Excel Windows; варианты Mac зависят от версии. Excel в браузере не заявлен эквивалентом.
4. UTF-8, Comma, отключение автоматического определения типов при наличии настройки, проверка заголовков и возврат к последнему шагу после просмотра истории показаны отдельно.
5. Trim не исправляет двойной внутренний пробел в исходном «Иван  Тестов». Добавлен отдельный Replace Values двух пробелов на один только для name.
6. Clean удаляет управляющие символы; на v1 видимого изменения нет. Clean не заменяет Trim.
7. До lowercase отдельно выполняется Trim utm_campaign и status. Это закрывает пропуск исходного сценария.
8. Для tg → telegram используется Match entire cell contents: текстовая замена по умолчанию заменяет и подстроки.
9. Фильтр статуса используется для просмотра значений; после проверки Cancel. Строки не отфильтровываются случайно.
10. Ошибочные даты не удаляются и не заменяются выдуманными. Обозначение ошибки на листе может отличаться от Error в редакторе. Ошибка ячейки и остановившая загрузку ошибка шага различаются.
11. V1 содержит 5 строк и одну ошибочную дату, v2 — 8 строк и две. После Split ожидаются 9 столбцов и сохранение всех строк. REQ-006 проверяет сразу Trim, Split, lowercase и Replace.
12. Перед Refresh меняется содержимое рабочего leads_dirty.csv, а не путь Source и не результат Excel. После обновления сохраняется книга. При переносе папки проверяется путь подключения.

## Файлы

- index.html, styles.css, script.js — веб-презентация.
- build.mjs — воспроизводимая сборка HTML, списка кадров и ZIP.
- files/power-query-lab.zip — папка практики: CSV v1, резервная v1, v2, result и README.
- materials.html — скачивание файлов, ожидаемые результаты, список кадров.
- SCREENSHOTS.md и shots/manifest.json — 54 позиции для настоящих кадров.
- shots/evidence.json — состояние съёмки. PNG пока нет; показаны подписанные заглушки.

Запуск сборки: node build.mjs из этой папки. PNG добавлять как shots/<номер>-shot.png, затем пересобирать. Не редактировать сгенерированные HTML вручную.

Управление: стрелки, PageUp/PageDown, пробел; Home/End; M — содержание; S — источники; F — полный экран. На телефоне — кнопки и свайп. Увеличение снятого кадра — кликом. Без JavaScript доступно последовательное чтение; reduced motion и печать предусмотрены.
