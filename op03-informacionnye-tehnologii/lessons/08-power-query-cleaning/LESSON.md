## Почему Google Таблицы

Исходный сценарий (SOURCE.md) построен на Power Query в Excel для Windows. 30.09.2026 по решению автора курса тема переведена на Google Таблицы: на машине съёмки нет Excel с Power Query. SOURCE.md сохранён без изменений как исходник; колода собирается из SHEETS.md.

Замена сохраняет идею темы — правила записываются один раз и повторяются на новых данных:

- Source → лист source, куда CSV импортируется как текст (флажок «Преобразовывать текст в числа, даты и формулы» снят);
- Applied Steps → по одной формуле ARRAYFORMULA во второй строке каждого столбца листа leads_clean;
- Refresh → повторный импорт новой выгрузки на тот же лист source с целью «Заменить текущий лист»; формулы пересчитываются сами;
- ошибка шага Power Query → формула проверки заголовков на отдельном листе check (формулы находят данные по буквам столбцов, перестановка столбцов в CSV ошибки не даёт).

## Отличия от Power Query, учтённые в тексте

1. СЖПРОБЕЛЫ в Google Таблицах сжимает повторные пробелы внутри строки, поэтому отдельная замена двух пробелов на один не нужна.
2. Функции показываются по-русски при региональных настройках «Россия»; разделитель аргументов — точка с запятой (слайд 292).
3. Подсказка ошибки называет функцию по-английски (VALUE), строка формул показывает #ЗНАЧ! (слайд 300).
4. Столбец G заполняется формулой из F2 (SPLIT); ввод в ячейки, которые занимает формула, даёт #REF! (слайды 308, 332).
5. Результат не загружается отдельной командой: лист leads_clean пересчитывается сразу. Для сдачи он скачивается как CSV (приходит в «Загрузки») и переносится в result.
6. Проверка структуры стоит на отдельном листе check: на листе leads_clean она попала бы в скачанный CSV лишними столбцами J и K (проверено 30.09.2026).
