# Слайд 267. Повторяемый процесс

## Заголовок
Правила обработки данных

## Текст
Повторяемый процесс состоит из трёх частей:

```ПРОЦЕСС
ИСТОЧНИК
↓
ПРАВИЛА
↓
РЕЗУЛЬТАТ
```

Правила записываются один раз. Когда источник меняется, те же правила применяются к новым данным без повторной ручной работы.

# Слайд 268. Правила в Google Таблицах

## Заголовок
Формулы как правила подготовки данных

## Текст
В Google Таблицах правило записывается формулой. Формула ссылается на ячейки другого листа и пересчитывается сама, когда значения там меняются.

В этой теме таблица состоит из двух листов:

лист source хранит данные из CSV в том виде, в каком они пришли;

лист leads_clean хранит формулы, которые берут значения из source и очищают их.

Функция ARRAYFORMULA позволяет записать правило один раз для всего столбца: формула в ячейке второй строки заполняет все строки ниже.

# Слайд 270. Extract → Transform → Load

## Заголовок
Три этапа подготовки данных

## Текст
Подготовку данных принято описывать тремя этапами.

**Extract** — получить данные: импортировать CSV на лист source.

**Transform** — преобразовать данные: формулы листа leads_clean очищают значения.

Сокращённо этот процесс называют ETL.

# Слайд 288. Первая формула

## Заголовок
Шаг 10. Формула для request_id

## Текст
Выделите ячейку A2 листа leads_clean и введите:

```ФОРМУЛА A2
=ARRAYFORMULA(ЕСЛИ(source!A2:A="";;СЖПРОБЕЛЫ(source!A2:A)))
```

source!A2:A — все ячейки столбца A листа source, начиная со второй строки.

СЖПРОБЕЛЫ убирает лишние пробелы.

ЕСЛИ(source!A2:A="";;…) оставляет ячейку пустой, если в source строка пустая. Между двумя точками с запятой ничего нет: это пустой результат.

ARRAYFORMULA применяет правило ко всем строкам сразу. Столбец A заполнился до пятой заявки, хотя формула записана только в A2.

## Скриншот
Ячейка A2 с формулой в строке формул; столбец request_id заполнен.

# Слайд 297. Формула для created_at

# Слайд 338. Изменение структуры источника

## Текст

# Слайд 339. Проверка структуры

## Заголовок
Шаг 27. Формула проверки заголовков

## Текст
Проверка ставится на отдельный лист: если поставить её рядом с таблицей, она попадёт в скачанный CSV лишним столбцом.

Добавьте лист кнопкой **+**, переименуйте его в check и в ячейку A1 введите:

```ФОРМУЛА check!A1
=ЕСЛИ(JOIN(",";source!A1:H1)="request_id,created_at,name,email,direction,source_medium,utm_campaign,status";"структура source: OK";"СТОП: изменились столбцы source")
```

JOIN склеивает заголовки source через запятую. Формула сравнивает их с контрактом и сообщает, совпадает ли структура.

## Скриншот
Лист check: в A1 сообщение «структура source: OK».

# Слайд 340. Два вида ошибок

## Заголовок
Ошибка значения и ошибка структуры

## Текст
**Ошибка значения** — #VALUE! в одной ячейке. Остальные строки обработаны, проблема видна сразу.

**Ошибка структуры** — изменился порядок или названия столбцов. Формулы продолжают работать, но берут не те данные. Такую ошибку показывает только лист check.

# Слайд 341. Проверка срабатывает

## Заголовок
Диагностика на копии таблицы

## Текст

Порядок диагностики:

1. прочитать сообщение проверки;
2. сравнить заголовки source с контрактом;
3. найти, что изменилось в выгрузке;
4. исправить выгрузку или согласованно изменить формулы.

## Скриншот
Копия таблицы: сверху source с заголовком traffic, снизу лист check с сообщением СТОП.
