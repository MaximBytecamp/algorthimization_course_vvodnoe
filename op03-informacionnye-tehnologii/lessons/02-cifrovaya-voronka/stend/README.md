# Учебный стенд занятия 1

Страница курса с кнопкой призыва к действию и формой заявки. Внутри — учебный
аналог `gtag.js`: он собирает запрос `/g/collect` в формате GA4 Measurement
Protocol и отправляет его через `navigator.sendBeacon`, как это делают настоящие
счётчики.

## Как запускать

**Вариант 1 — просто открыть файл.** Двойной клик по `index.html`. Запросы уйдут
на настоящий адрес `https://www.google-analytics.com/g/collect`. Нужен интернет;
идентификатор учебный, данные никуда не записываются.

**Вариант 2 — локальный сервер (работает без интернета).** В терминале из этой
папки:

```bash
python3 -m http.server 8000
```

затем открыть `http://localhost:8000/?utm_source=college&utm_medium=post`.
Запросы пойдут на `/g/collect` этого же сервера. Встроенный сервер Python не знает
такого адреса и ответит `404` — строка будет красной, но параметры в ней видны
полностью, и для разбора этого достаточно. Чтобы получить зелёный `204`,
используйте вариант 1 или поднимите сервер, который отвечает `204` на `/g/collect`.

## Ссылки для практики

| Что показать | Адрес |
|---|---|
| переход с меткой | `index.html?utm_source=college&utm_medium=post&utm_campaign=sept_open` |
| переход без метки | `index.html` |

Разница будет видна в параметре `ep.source`: в первом случае `college`,
во втором — `(not set)`.

## Какие события отправляет стенд

| Действие | Событие (`en`) | Дополнительные параметры |
|---|---|---|
| открытие страницы | `page_view` | `dl`, `dt` |
| прокрутка ниже 85 % | `scroll` | `epn.percent_scrolled=90` |
| нажатие кнопки | `select_content` | `ep.content_type=cta`, `ep.item_id=lead_button` |
| фокус в форме | `form_start` | `ep.form_id=lead_main` |
| отправка формы | `generate_lead` | `ep.form_id`, `ep.source`, `epn.value`, `ep.currency` |

## Если строки красные

Красная строка в панели Network — это не поломка стенда, а ответ сервера или
блокировка. Что бывает:

- **404** — адрес `/g/collect` не обслуживается локальным сервером (вариант 2).
  Запрос ушёл, параметры видны; для разбора этого достаточно.
- **(failed) / ERR_BLOCKED_BY_CLIENT** — запрос заблокировал блокировщик рекламы
  или расширение приватности. Отключите его для этой вкладки.
- **(failed) / ERR_INTERNET_DISCONNECTED** — нет сети при варианте 1.
  Используйте вариант 2.

Во всех случаях сам запрос браузер сформировал, и его параметры можно прочитать
во вкладке **Payload** — а именно они и разбираются на занятии.
