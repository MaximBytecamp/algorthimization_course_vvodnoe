# Проверка перед сдачей

- [ ] Все результаты относятся к указанному Property и периоду.
- [ ] Период Explore проверен отдельно; источники имеют правильную область действия.
- [ ] generate_lead отмечен как Key event; дата отметки учтена.
- [ ] Key events не назван числом заявок без проверки состава.
- [ ] На сравнении Instagram/Direct нет фильтра, исключающего Direct.
- [ ] Тип сегмента соответствует формулировке группы.
- [ ] Основной Funnel содержит 4 условия, Closed, Indirectly, без Within.
- [ ] Event count, пользователи Funnel и сеансы подписаны отдельно.
- [ ] Для потерь указаны числитель, знаменатель и критерий максимума.
- [ ] Path имеет указанную метрику; события и страницы не перепутаны.
- [ ] Основной кейс ограничен source И campaign на каждой нужной вкладке.
- [ ] Общий Event name-фильтр не обрезает Funnel/Path.
- [ ] Сверка Sheets выполнена по уникальным непустым request_id отдельно от GA4.
- [ ] Ограничения данных и доступа описаны честно.
- [ ] Наблюдение подкреплено кадром; гипотеза отделена от причины.
- [ ] Экспорт открыт и сверен с активной вкладкой.
