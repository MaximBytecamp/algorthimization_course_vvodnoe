# Проверка перед сдачей

- [ ] Выгрузка GA4 без служебных строк и «Общего итога»; заголовки латиницей.
- [ ] generate_lead выгружен отдельным листом; трафик событием не отфильтрован.
- [ ] В подключении три листа; у листов GA4 включены заголовки.
- [ ] Числа — «Целое число» с агрегацией «Сумма»; дата GA4 — DATE_PARSE.
- [ ] source и campaign в GA4 приведены к формату формы: direct, not_set.
- [ ] Поля Дата, source, campaign называются одинаково в трёх датасетах.
- [ ] name и email скрыты в датасете «Заявки».
- [ ] Lead Count = COUNTD(request_id); Done Count — условие внутри формулы.
- [ ] Копии карточек статусов имеют только свой фильтр.
- [ ] В сводной таблице связи только по source, campaign, Дата.
- [ ] Сеансы по паре в сводной таблице совпадают с вкладкой Web Analytics.
- [ ] null не превращён в ноль; пары без совпадения разобраны в сверке.
- [ ] Алиасы Дата и source для виджета GA4 Lead Events; селектор «Статус» отвязан от карточек.
- [ ] Селекторы проверены в режиме просмотра и сброшены перед сдачей.
- [ ] Пользователи по дням не выданы за уникальных.
- [ ] Публичный доступ выключен; права на воркбук — только у нужных людей.
- [ ] Спецификация и сверка заполнены фактическими числами.
