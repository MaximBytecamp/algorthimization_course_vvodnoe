# Data Studio · три страницы общего отчёта

Продолжаем GA4 и лист leads предыдущих тем. Актуальная подготовка данных темы 8 выполнялась в Google Таблицах. Создаётся новый отчёт Data Studio; существующие источники не заменяются вымышленными данными.

1. Запишите GA4 Property, Spreadsheet/worksheet, период и часовой пояс в dashboard-spec.md. Снимите исходные числа отдельно.
2. Создайте Report, подключите GA4. Page 1: Sessions, Active users, карточка Key events с фильтром generate_lead; подпись GA4 Lead Events. Если событие не отмечено Key event, используйте Event count и укажите это в спецификации.
3. Добавьте период, динамику Date/Sessions/Active users, таблицы source/campaign/content, устройства, controls. Трафик не фильтруйте общим Event name=generate_lead. Проверьте View и сброс cross-filter.
4. Page 2: подключите worksheet leads. Проверьте непустые уникальные ID, тип created_at, согласованность статусов и ключей. Создайте Lead Count в источнике Sheets. Добавьте показатели, диаграммы и свои controls source/campaign/status/date.
5. Копируя карточки New/Done/In Progress, заменяйте фильтр, а не добавляйте противоречащий старому. Период выбирает created_at, статус — текущее состояние, не история.
6. Page 3: Blend с GA4 Traffic слева и Sheets Leads справа. Dimensions — только Source + Campaign, даты отдельно для периода, оба диапазона Auto. Left Outer по двум ключам.
7. Сверьте каждую пару с отдельными исходниками. NULL не называйте нулём без проверки. Заявки без пары GA4 останутся только на Page 2; внесите их в сверку.
8. Чтобы отдельно показать generate_lead, добавьте третью таблицу того же GA4-источника: source/campaign, Event count, фильтр generate_lead внутри этой таблицы. Присоедините Left Outer по ключам первой таблицы и тому же периоду. Sessions в первой части не фильтруются.
9. Done Count вычисляется в Sheets условным COUNT_DISTINCT; в Blend это метрика, не новый ключ status. Формулы — formulas.md.
10. Actual Leads / Sessions — отношение агрегатов, не доля конвертированных сеансов. Проверяйте исходные суммы и нулевой знаменатель до форматирования Percent. Не суммируйте Active users по кампаниям для общего числа пользователей.
11. Проверьте controls каждой страницы, периоды, обновление и модель Data credentials. Не добавляйте name/email на dashboard. Не выдавайте всем Editor; не делайте данные заявок публичными.
12. Сдайте спецификацию, сверку и реальные кадры по SCREENSHOTS.md. Наблюдение подкрепите числами; возможную причину расхождения называйте гипотезой.

Комплект не создаёт отчёт или источники через API и не меняет права автоматически. Для съёмки требуется подключённый браузер и доступ к ресурсам. При отсутствии данных/прав сохраните фактическое ограничение; числа слайдов условные.
