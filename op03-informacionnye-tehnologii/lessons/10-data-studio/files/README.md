# DataLens · три вкладки общего дашборда

Data Studio (Looker Studio) из России недоступен, поэтому дашборд строим в Yandex DataLens (datalens.ru, вход через Яндекс ID). Продолжаем GA4 и лист leads предыдущих тем.

1. **Выгрузка GA4.** GA4 → Исследования → Свободная форма. Строки: Дата, Источник сеанса, Кампания, связанная с сеансом, Тип устройства. Значения: Активные пользователи, Сеансы. 500 строк. Экспорт → Google Таблицы.
2. **Чистка выгрузки.** Удалите 6 служебных строк сверху и строку «Общий итог». Заголовки: date, utm_source, utm_campaign, device, active_users, sessions. Таблица «GA4 для DataLens», лист ga4_traffic.
3. **generate_lead.** Копия вкладки: строки Дата, Источник сеанса, Кампания; значение Количество событий; фильтр Название события = generate_lead. Выгрузите и перенесите на лист ga4_leads (date, utm_source, utm_campaign, lead_events).
4. **Контрольные числа.** Запишите в dashboard-spec.md период выгрузки, сеансы, уникальных пользователей и generate_lead из GA4; число заявок и статусы из leads.
5. **Подключение.** Подключения → Создать → Google Sheets → «Войти через Google». Добавьте лист leads и оба листа GA4. У листов GA4 включите «Показывать заголовки столбцов: Да». Сохраните в воркбук (без точек и стрелок в названиях).
6. **Датасеты.** «GA4 трафик», «GA4 generate_lead», «Заявки». Числа — «Целое число» с агрегацией «Сумма». Формулы — в formulas.md. Поля source, campaign и «Дата» называйте одинаково во всех трёх датасетах. В «Заявках» скройте name и email.
7. **Чарты Web Analytics.** Индикаторы Сеансы, Активные пользователи (сумма по дням), GA4 Lead Events; линии Сеансы и Пользователи по дате; таблица источников и кампаний; круговая диаграмма устройств.
8. **Чарты заявок.** Actual Leads (Lead Count), Новые и В обработке (Lead Count с фильтром status), Done (Done Count). Копию карточки сохраняйте через «Сохранить как копию»; в её фильтре старое значение status убирается кнопкой «Очистить», затем выбирается новое.
9. **Сводная таблица.** Чарт из трёх датасетов: GA4 трафик + Заявки + GA4 generate_lead. В «Настройках датасетов → Связи» оставьте только source, campaign и Дата. Поля: source, campaign, sessions, lead_events, Lead Count, Done Count.
10. **Дашборд.** Три вкладки: Web Analytics, Заявки, Маркетинг и заявки. На каждой — свои закреплённые селекторы. Для виджетов другого датасета задайте алиасы Дата = Дата и source = source. Селектор «Статус» отвяжите от карточек «Новые» и «В обработке».
11. **Проверка.** Режим просмотра: выберите источник, период, кампанию. Сверьте числа с контрольными, расхождения — в reconciliation.csv с гипотезой.
12. **Доступ.** «Поделиться»: права выдаются на весь воркбук. Публичный доступ не включайте. Не выводите name и email.

Выгрузка GA4 — снимок на дату экспорта. Для новых данных GA4 повторите выгрузку; лист leads DataLens перечитывает сам («Обновить данные» или автообновление не чаще раза в 30 минут).
