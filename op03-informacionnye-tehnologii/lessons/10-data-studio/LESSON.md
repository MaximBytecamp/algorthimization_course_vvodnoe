## Дополнения и исправления

- Сохранены все исходные логические позиции и места для кадров; добавлены сохранение вычисляемых полей, проверка типов, дат и фильтров копий, сброс controls, доступ зрителя и итоговая сверка.
- Название Data Studio проверено по официальной документации Google 08.10.2026.
- GA4 Lead Events явно отделён от All Key Events и реальных заявок. В Blend для него добавляется третья таблица того же GA4-источника с фильтром generate_lead; исходный трафик не фильтруется событием.
- На обеих сторонах Blend задан общий период и детализация source/campaign. request_id, status и device не добавляются случайно в Dimensions.
- Left Outer сохраняет строки GA4; отсутствие правого совпадения — NULL, не доказанный ноль. Заявки без пары GA4 учитываются отдельно на Page 2 и в сверке.
- Done Count — условный COUNT_DISTINCT в Sheets, без размножения строк по status. created_at выбирает созданные заявки с текущим статусом; истории завершений здесь нет.
- Actual Leads / Sessions подписано как отношение агрегатов, не вероятность конверсии сеанса. Нулевой знаменатель, агрегация и несовпадения требуют проверки.
- Active users нельзя просто суммировать по кампаниям для общего итога. Пустые ID и конфликтующие значения одного ID не исправляются одним COUNT_DISTINCT.
- Контролы каждой страницы используют свой источник. Совпадение подписи поля не означает совпадение внутреннего ID.
- Share и Data credentials показаны отдельно. Скрытие name/email в диаграмме не считается защитой всего источника.
