ЧастьДетализацияПоказатели
GA4 TrafficSource + Campaign за периодSessions, Active users, All Key Events
Sheets LeadsSource + Campaign за периодLead Count, Done Count
GA4 Lead EventsSource + Campaign за период; фильтр generate_leadEvent count

GA4 слева; обе следующие таблицы присоединяются Left Outer по ключам первой. Дата используется для отбора периода, а не добавляется случайно в детализацию. Это сопоставление агрегатов, не соединение пользователей по ID.

Модель JOIN

На слайде 697a можно сравнить ключ Source с Source + Campaign и отдельные заявки с агрегатами. Числа модели вымышлены. Она не отправляет запросы в аккаунты.
