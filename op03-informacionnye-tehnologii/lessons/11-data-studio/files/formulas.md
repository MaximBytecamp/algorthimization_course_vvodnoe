# Формулы и область применения

## Источник Google Sheets · Lead Count

```text
COUNT_DISTINCT(request_id)
```

request_id имеет тип Text. Пустые ID и конфликты одного ID по статусам/кампаниям исправьте в источнике. Подсчёт уникальных значений не исправляет структуру записей.

## Источник Google Sheets · Done Count

```text
COUNT_DISTINCT(
  CASE WHEN status = "done" THEN request_id
  ELSE NULL END
)
```

Поле создайте и сохраните в Sheets data source, затем добавьте как метрику правой таблицы Blend. Не добавляйте status в Dimensions Blend. Функции относятся к текущим статусам созданных за период заявок, а не к дате завершения.

## Текстовая дата — только для указанного формата

Если исходное значение строго `2026-10-08 14:30:00`:

```text
PARSE_DATETIME("%Y-%m-%d %H:%M:%S", created_at)
```

Назовите поле created_at_parsed, используйте как Date range dimension. Если Sheets уже хранит настоящую дату, разбор текста не нужен. Формат со знаком T, Z или смещением часового пояса нельзя молча считать этим форматом. Согласуйте преобразование на стороне источника, проверьте даты около полуночи и часовой пояс GA4.

## Диаграмма на Blend · Actual Leads / Session

```text
CASE
  WHEN SUM(Sessions) > 0
  THEN SUM(Lead Count) / SUM(Sessions)
  ELSE NULL
END
```

Создать через Add metric → Create field в диаграмме с Blend; выбрать поля подсказками, тип Percent. Это формула для уже объединённых агрегатов, не для исходной метрики GA4 с Auto. При ошибке повторной агрегации сначала проверьте, что выбран именно Blend и его поля.

При отсутствии правого совпадения оставляйте NULL до сверки. Общий показатель вычисляйте как отношение сумм; среднее процентов строк даст другой смысл. Это не идентифицированная пользовательская конверсия и может превысить 100%.

## Отдельный generate_lead

Третья таблица Blend использует тот же GA4 data source: source/campaign, Event count, фильтр Event name Equal to generate_lead. Переименуйте метрику в GA4 Lead Events. Не применяйте этот фильтр к таблице всего трафика.

Формулы подготовлены по документации; выполнение в конкретном аккаунте Data Studio ещё не проверено. В отчёте фиксируйте фактическую валидацию редактором и сверку результатов.
