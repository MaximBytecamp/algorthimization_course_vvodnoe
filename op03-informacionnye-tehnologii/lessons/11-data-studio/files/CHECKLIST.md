# Проверка перед сдачей

- [ ] Три страницы и два нужных Data sources.
- [ ] Названия показателей соответствуют метрикам; все Key events не названы generate_lead.
- [ ] Event name-фильтр не ограничивает весь трафик.
- [ ] request_id непустой; уникальность и конфликтующие статусы проверены.
- [ ] created_at — дата; один согласованный период на обеих сторонах.
- [ ] Копии status-карточек имеют только свой фильтр.
- [ ] Контролы source/campaign/status/date проверены в View и после сброса.
- [ ] Source + Campaign согласованы; дубли ключей агрегированы перед JOIN.
- [ ] request_id, status, device случайно не добавлены в детализацию Blend.
- [ ] Left Outer и обе пары ключей проверены.
- [ ] NULL не превращён в ноль без проверки; правые несовпадения учтены отдельно.
- [ ] Третья таблица GA4 считает только generate_lead, не меняя Sessions слева.
- [ ] Done Count — метрика Sheets, а не дополнительный ключ.
- [ ] Sessions после JOIN совпадают с исходными по каждой паре.
- [ ] Отношение заявок к сеансам имеет определённый знаменатель; итог — отношение сумм.
- [ ] Active users не суммируются по разрезам без проверки пересечений.
- [ ] Data credentials проверены отдельно от Share; доступ ограничен.
- [ ] Личные данные не показаны; скрытие колонок не считается защитой источника.
- [ ] Спецификация, сверка и кадры содержат фактический результат.
