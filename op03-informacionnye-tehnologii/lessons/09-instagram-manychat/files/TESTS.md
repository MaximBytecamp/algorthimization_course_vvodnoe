# Проверка результата

| Шаг | Ожидаем | Если не получилось |
|---|---|---|
| Production /guide.html | Материал открывается без 404 | Проверить commit, путь файлов, Deployment Ready |
| Ссылка с UTM → CTA | contacts.html содержит все четыре UTM | Проверить guide.js, отсутствие ошибок в Console |
| Automation | Specific Post, ГАЙД, Private Reply, URL, Live | Save / Update; сверить публикацию |
| Первый комментарий тестового аккаунта | Публичный ответ, если настроен, и private DM | Проверить keyword, права, Requests, первый комментарий |
| Получить материал | Открылся guide.html с UTM | Проверить Open Website и полный URL |
| GA4 | page_view; в debug page_location содержит UTM | Проверить поток, тег, режим отладки, блокировщик |
| Кнопка материала | cta_click с guide_to_form | Проверить guide.js и правильную кнопку |
| Начало формы | form_start при включённом измерении и первом взаимодействии в сеансе | Проверить Form interactions; повтор не обязан дать событие |
| Отправка формы | generate_lead | Проверить валидацию, обработчик и GA4 |
| Sheets | Новая строка с request_id, backend, new, тремя UTM | Проверить Apps Script /exec, Executions, запрос формы |
| Атрибуция | После обработки Session source / medium = instagram / social для соответствующего сеанса | Учитывать существующий сеанс и scope отчёта |

Итог фиксируйте по фактам, отдельно для события и записи. Не отправляйте форму повторно только ради появления события: сначала проверьте таблицу. В evidence укажите время, тестовый аккаунт, публикацию и request_id, не пароли и не чужие заявки.
