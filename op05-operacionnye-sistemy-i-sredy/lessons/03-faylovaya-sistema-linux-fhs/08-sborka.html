Практическая работа: размещение файлов приложения

В этой части применим правила размещения файлов к собственному приложению shop-api и оформим отчёт по уроку.

  1. 8.1 Размещение файлов приложения
  2. 8.2 Отчёт

8.1 Размещение файлов приложения

Предположим, что в систему устанавливается служба shop-api. У неё есть исполняемый файл, настройки, база данных, журнал, файл с номером запущенного процесса и промежуточные файлы. По правилам из частей 2–4 каждый из них должен оказаться в каталоге, соответствующем типу данных.

Если сложить все файлы сервиса в один каталог, например в /home/admin/shop-api, появятся проблемы. При обновлении программы легко затереть настройки и базу. Резервную копию придётся делать для всего каталога целиком. Другой администратор не найдёт журнал там, где его обычно ищут.

ФайлКаталогОснование
исполняемый файл, установленный вручную/usr/local/binпрограммы вне пакетов дистрибутива
настройки/etc/shop-apiконфигурационные файлы
база данных/var/lib/shop-apiпостоянные изменяемые данные
журнал/var/log/shop-apiжурналы служб
номер процесса/run/shop-apiсведения о работающей службе, до перезагрузки
промежуточные файлы/tmpвременные данные

Системные каталоги в работе не изменяются. Структура воспроизводится внутри каталога model-root: путь model-root/etc/shop-api соответствует системному /etc/shop-api.

В терминалеСтруктура каталогов shop-api
  1. cd ~/linux-fhs-lab
  2. mkdir -p model-root/{usr/local/bin,etc/shop-api,var/lib/shop-api,var/log/shop-api,run/shop-api}# создать каталоги
  3. cp config/app.conf model-root/etc/shop-api/# настройки
  4. cp data/info.txt model-root/var/lib/shop-api/# данные
  5. printf "service started\n" > model-root/var/log/shop-api/app.log# журнал
  6. find model-root -type f# список файлов
Результат

find выводит три файла в etc, var/lib и var/log.

8.2 Отчёт

Отчёт оформляется в файле README.md в каталоге linux-fhs-lab по шаблону из материалов урока. Снимки экрана сохраняются в каталог screenshots. Под каждым снимком кратко указывается, что проверялось и какой получен результат. Начало отчёта можно создать из терминала: оператор > создаёт файл заново, >> дописывает строки в конец.

В терминалеНачало отчёта
  1. cd ~/linux-fhs-lab
  2. printf "# Linux FHS lab\n\n" > README.md# создать файл
  3. printf "## System\n" >> README.md# дописать строку
  4. cat /etc/os-release | head -4 >> README.md
  5. printf "\n## Root filesystem\n" >> README.md
  6. findmnt / -o TARGET,SOURCE,FSTYPE >> README.md
  7. cat README.md
Результат

в README.md записаны сведения о системе и корневой файловой системе.

Примечание

В Live-сессии файлы не сохраняются после выключения. Скопируйте каталог linux-fhs-lab на внешний носитель.
