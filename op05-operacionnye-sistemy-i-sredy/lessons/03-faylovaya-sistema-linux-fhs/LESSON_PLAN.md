# Тема 03 · Файловая система Linux и стандарт FHS

Формат: практическая книга, 8 глав, 23 последовательных опыта. Планируемое время — две пары по 90 минут с продолжением отчёта дома при необходимости.

## Вход

Ubuntu после работы №1 либо Live. Терминал Bash. Все изменения в ~/linux-fhs-lab; sudo только для временного tmpfs. Инструменты входят в демонстрационный Ubuntu Desktop. Если file отсутствует в минимальной установке: sudo apt update и sudo apt install file. Если отсутствует Python, опыт поиска можно выполнить с Bash.

## Ход занятия

1. 3.1 — корень, пути, дом, стартовая папка: 25 минут.
2. 3.2 — FHS, /etc, учётная запись и find: 20 минут.
3. 3.3 — PATH, /usr и usrmerge: 15 минут.
4. 3.4 — /var и сроки жизни данных: 15 минут.
5. 3.5 — /dev, /proc и /sys: 20 минут.
6. 3.6 — типы, символическая и жёсткая ссылки, inode: 20 минут.
7. 3.7 — findmnt, df/du, подключение и отключение tmpfs: 25 минут.
8. 3.8 — модель приложения, самостоятельная задача и отчёт: 40 минут.

На каждом шаге: объяснение → выполнение → сравнение с реальным кадром → вопрос до раскрытия ответа. Режим по одному шагу работает внутри главы. Номера 3.1–3.8 — подразделы одного нового урока дисциплины.

## Ведущий приём

Путь → назначение → доказательство командой. Интерактивная карта связывает каталог, роль и кадр; модель монтирования показывает два источника содержимого одного пути. Отдельная модель относительных путей явно не обрабатывает символические ссылки. Книга адаптирует запрошенный пользователем формат темы 02 МДК.01.01 в палитре Ubuntu.

## Проверка и сдача

13 собственных снимков по шаблону, README, модель shop-api и финальный анализ 6 путей. 10 баллов по пяти критериям на последней странице. При недоступном sudo — снимок отказа и объяснение кадров mount/umount вместо утверждения о выполнении. В Live данные обязательно сохранить на постоянный носитель.

## Авторская сборка

Текст разделов — content.json. Разметка страниц и материалы — build.py; команда python3 build.py. Оформление — book.css, интерактив — book.js. Страницы статические и читаются без JavaScript. Карта в JS встроена для file://; сборка синхронизирует её с map.json по маркерам FHS_MAP_START/FHS_MAP_END.

Кадры и команды задокументированы в shots/SOURCES.md и shots/commands.json. Не запускать команды создания файлов повторно поверх студенческого отчёта.
