Один корень, разные маршруты

Начнём с терминала: найдём себя в дереве каталогов и подготовим папку для всех опытов.

Корень дерева — /

Откройте установленную ранее Ubuntu и запустите «Терминал» сочетанием Ctrl + Alt + T. Команды в книге выполняются в Bash внутри Ubuntu. Знак $ на скриншотах — приглашение оболочки, вводить его не нужно.

В Linux абсолютный путь начинается с /. Это корневой каталог всего видимого дерева. Внутри него находятся etc, usr, home и другие каталоги. Даже файловая система второго диска подключается к этому дереву.

cd меняет текущий каталог, pwd печатает его путь, ls показывает содержимое. У ls -lah ключ -l включает подробный список, -a добавляет скрытые имена, -h делает размеры удобными для чтения. Ключи можно объединять.

Почему /home и /usr не являются аналогами отдельных дисков C: и D:?

Это пути в одном дереве. Они могут относиться к одной файловой системе или к разным: определять это нужно через findmnt, а не по имени каталога.

Абсолютный и относительный путь

Абсолютный путь /usr/bin не зависит от текущего каталога. Относительный путь отсчитывается от места, которое показывает pwd. Поэтому cd bin из /usr приведёт в /usr/bin, а из домашнего каталога будет искать совсем другой bin.

. обозначает текущий каталог, .. — родительский. В пути ../bin сначала выполняется переход на уровень выше, затем в bin. Linux различает регистр: Data и data — разные имена. Путь с пробелами заключают в кавычки: cd "My Files".

От какого каталога отсчитывать путь?

Модель разбирает /, . и .. как текст. Символические ссылки и существование файлов здесь не проверяются — результат затем проверьте в Ubuntu.

Буквы C: и D: — привычное представление томов Windows, но Windows также поддерживает подключение тома к папке. Аналогично, /home в Linux не обязательно является отдельным разделом.

Мини-практика на Windows, если система есть под рукой: выполните Get-Location, $HOME, Get-Command powershell. Сравните с pwd, echo "$HOME", command -v bash в Ubuntu. Кадры этой книги сняты в Linux; эта таблица — справочное сопоставление команд.

Куда ведёт ../bin из /usr/share?

В /usr/bin. А путь bin без двух точек означал бы /usr/share/bin. Смысл относительного пути задаёт текущий каталог.

Домашний каталог и скрытые имена

Команда cd ~ возвращает в домашний каталог текущего пользователя. Bash раскрывает ~ в домашний путь; переменная $HOME обычно содержит тот же адрес. Но pwd показывает именно текущее место: совпадение появится только после перехода домой.

Имена с точкой в начале, например .bashrc или .config, скрывает обычный ls. Это соглашение интерфейса, а не защита от чтения. /root — домашний каталог администратора root; / — корень дерева. Учётная запись root и корневой каталог — разные понятия.

Станет ли .config недоступным другим пользователям только из-за точки?

Нет. Точка влияет на отображение. Доступ регулируют права и принадлежность файла, которые будем изучать отдельно.

Одна папка для всей практики

Создадим рабочее дерево ~/linux-fhs-lab. Здесь будут конфигурация, данные, результаты опытов и отчёт. Это наша учебная структура внутри домашнего каталога, а не установка приложения в системные пути.

mkdir -p создаёт недостающие каталоги и не считает существующий каталог ошибкой. Bash раскрывает фигурные скобки в несколько путей. printf выводит текст, а > направляет его в файл и перезаписывает прежнее содержимое. Выполните создание стартовых файлов один раз; дальше продолжайте работу с ними.
