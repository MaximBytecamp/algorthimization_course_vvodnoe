# Разрез Linux · памятка

## Главная мысль

1. Все файлы Linux лежат в одном дереве каталогов, и путь к любому файлу начинается с корня /.
2. Каталог для файла выбирают по тому, что в нём хранится: программа, настройки или данные.
3. Программы лежат в /usr, а оболочка находит их по списку каталогов из переменной PATH.
4. Данные, которые меняются во время работы, раскладывают по сроку хранения: /var, /tmp и /run.
5. Не каждый путь ведёт к файлу на диске: содержимое /proc, /sys и /dev выдаёт ядро.
6. Имя файла записано в каталоге и указывает на inode — запись со сведениями о файле.
7. Какая файловая система стоит за путём, определяет монтирование.
8. По этим правилам мы размещаем файлы своего приложения и проверяем результат командами.

## Карта корня

| Путь | Назначение | Проверка | Слой |
|---|---|---|---|
| `/` | Самый верхний каталог, с него начинается любой путь. | `pwd` | 1 |
| `/home` | Файлы и настройки обычных пользователей. | `ls /home` | 1 |
| `/root` | Домашний каталог root. Не путать с корнем /. | `getent passwd root` | 1 |
| `/etc` | Настройки системы и программ. | `cat /etc/os-release` | 2 |
| `/boot` | Файлы для загрузки системы. | `ls /boot` | 2 |
| `/usr` | Программы, библиотеки и справка. | `ls /usr` | 3 |
| `/usr/local` | Сюда администратор ставит программы сам, без менеджера пакетов. | `ls /usr/local` | 3 |
| `/opt` | Программы, установленные целиком в один каталог. Часто пуст. | `ls -la /opt` | 3 |
| `/var` | Журналы, базы, очереди и кэш. | `ls /var` | 4 |
| `/tmp` | Файлы могут быть удалены в любой момент. | `findmnt -T /tmp` | 4 |
| `/run` | После перезагрузки каталог пуст. | `findmnt -T /run` | 4 |
| `/dev` | Файлы, через которые программы обращаются к устройствам. | `ls -l /dev/null` | 5 |
| `/proc` | Сведения о процессах и памяти, их выдаёт ядро. | `cat /proc/uptime` | 5 |
| `/sys` | Параметры устройств, их выдаёт ядро. | `ls /sys/class/net` | 5 |
| `/mnt` | Место, куда вручную подключают диски. | `findmnt -T /mnt` | 7 |
| `/media` | Сюда подключаются флешки. | `ls /media` | 7 |
| `/srv` | Файлы, которые сервис отдаёт, например сайт. | `ls -la /srv` | 8 |

## Команды

- `pwd`, `cd` — текущий каталог и переход.
- `ls -lah`, `ls -li` — подробный список; `-i` добавляет inode.
- `command -v`, `type` — во что превращается имя команды.
- `readlink`, `readlink -f` — записанная и итоговая цель ссылки.
- `file`, `file -L` — содержимое объекта и цели ссылки.
- `stat` — сведения из inode.
- `ln -s цель ссылка` — символическая ссылка; `ln файл имя` — жёсткая.
- `findmnt -T путь` — какая файловая система отвечает за путь.
- `lsblk` — блочные устройства; `df -h .` — место; `du -sh каталог` — занято содержимым; `df -i .` — inode.
- `dpkg -S файл`, `dpkg -L пакет` — чей файл и какие файлы у пакета.

`/var/lib` — постоянное состояние; `/var/log` — журналы; `/var/cache` — восстанавливаемый кэш; `/var/spool` — очереди; `/run` — до перезагрузки.
