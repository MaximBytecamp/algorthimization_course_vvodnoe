# Файлы, маски, поиск и справка · памятка

## 1. Каталоги и файлы

- `mkdir` создаёт каталог; с ключом `-p` — весь путь и без ошибки, если каталог уже есть.
- `touch` создаёт пустой файл или обновляет время изменения существующего; `-d` записывает заданную дату.
- `ls -A` показывает скрытые файлы, `ls -lh` — размеры в K и M.
- Скрипт `files-lab-setup.sh` возвращает каталог `inbox` в исходное состояние.

## 2. Копирование, перемещение и ссылки

- `cp` копирует файлы; для каталога нужен ключ `-r`.
- `mv` переносит и переименовывает; внутри одной файловой системы данные файла не копируются.
- `cp` и `mv` заменяют существующий файл без вопроса; `-i` спрашивает, `-n` пропускает.
- Символическая ссылка хранит путь к файлу; `cp` по ссылке копирует содержимое целевого файла.

## 3. Удаление файлов и имена с пробелами

- `rm` удаляет файлы без корзины; `rmdir` удаляет только пустой каталог; `rm -r` — каталог с содержимым.
- Перед удалением содержимое выводят командой `ls` с тем же путём.
- Ключ `-i` спрашивает перед каждым удалением, `-f` отключает вопросы и сообщения об ошибках.
- Имя с пробелом берут в кавычки или ставят перед пробелом `\`.

## 4. Маски имён файлов

- `*` — любые символы, `?` — один символ, `[ ]` — один символ из набора, `{a,b}` — варианты.
- Маску раскрывает оболочка до запуска команды; `echo` показывает результат раскрытия.
- Маска без совпадений и маска в кавычках передаются команде без изменений; `*` не находит скрытые файлы.
- Перед `rm` маску проверяют командой `ls` с той же маской.

## 5. Поиск файлов

- `find каталог условия` обходит всё дерево; маску в `-name` берут в кавычки.
- `-size` округляет размер вверх до указанных единиц; `-mtime` считает полные сутки.
- `-exec` выполняет команду для каждого найденного файла; `-delete` ставят в конце и только после проверки списка.
- `2>/dev/null` отбрасывает сообщения об ошибках.
- `locate` ищет по базе и видит изменения только после `updatedb`.
- `which` ищет программу в PATH, `type` сообщает, чем является имя.

## 6. Справочная система

- `man имя` открывает страницу справки; разделы страницы: NAME, SYNOPSIS, DESCRIPTION.
- Внутри справки / ищет по тексту, n переходит к следующему совпадению, q закрывает страницу.
- Раздел 1 — команды, 5 — форматы файлов, 8 — администрирование; `man 5 passwd` открывает раздел 5.
- `man -f` показывает разделы страницы, `man -k` ищет по описаниям.
- `--help` — краткая справка программы, `help` — справка встроенной команды оболочки.

## 7. Практическая работа № 3 · Разбор каталога inbox

- `history` выводит историю команд, `>` записывает вывод в файл.
- Журнал содержит команду, результат и безопасный вариант каждой команды.
- Скрипт проверки только читает каталог и показывает, какие пункты выполнены.
