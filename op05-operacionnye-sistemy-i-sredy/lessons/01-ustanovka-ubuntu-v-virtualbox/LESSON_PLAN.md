# Практическая работа 1. Установка Ubuntu в VirtualBox

## Результат

Студент выбирает совместимые версии VirtualBox и Ubuntu, создаёт виртуальную машину, устанавливает Ubuntu Desktop, выполняет первое обновление и фиксирует рабочее состояние снимком.

## Организация пары — 90 минут

- 0–12 мин: модель «хост — гипервизор — гостевая ОС» и проверка архитектуры.
- 12–27 мин: установка VirtualBox на Windows или macOS.
- 27–47 мин: создание и настройка виртуальной машины.
- 47–72 мин: установка Ubuntu Desktop.
- 72–84 мин: обновление, снимок состояния, корректное завершение работы.
- 84–90 мин: приёмка по чек-листу и разбор ошибок.

## Что сдаёт студент

1. Скриншот окна VirtualBox с выключенной виртуальной машиной.
2. Скриншот рабочего стола Ubuntu после входа.
3. Скриншот окна терминала после обновления пакетов.
4. Скриншот созданного снимка `clean-install`.
5. Короткая запись: архитектура хоста, выбранный ISO, объём RAM, число CPU, размер виртуального диска.

## Методические замечания

- Для Windows x64 и Intel Mac нужен ISO `amd64`.
- Для Mac с Apple Silicon нужен ISO `arm64`; VirtualBox на ARM не запускает гостевые x86-системы.
- На учебной практике выбирается ручная установка, чтобы студент увидел каждый шаг.
- «Стереть диск и установить Ubuntu» безопасно только тогда, когда установщик работает внутри созданной виртуальной машины: речь идёт о виртуальном диске, а не о диске хоста.
- Исходная презентация `ПР1. Установка операционной системы.pptx` использована как тематическая основа. Системные требования, интерфейс и последовательность обновлены по официальной документации.
