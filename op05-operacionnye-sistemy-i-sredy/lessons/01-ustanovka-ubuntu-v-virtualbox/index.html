Маршрут A · Windows

Скачайте Windows hosts и запустите установщик

  1. Откройте скачанный файл .exe

    Если Windows спросит разрешение на изменения — выберите «Да».

  2. Нажмите Next и оставьте компоненты по умолчанию

    Программа, USB, сеть и ярлыки устанавливаются вместе.

  3. Подтвердите установку сетевых драйверов

    Сеть может кратко отключиться: VirtualBox добавляет виртуальные адаптеры.

  4. Нажмите Install → Finish

    После завершения откроется VirtualBox Manager.

macOS · от загрузки до первого запуска

DMG открывает установочный диск, а файл PKG устанавливает программу

  1. В Finder откройте Downloads и дважды нажмите файл .dmg

    DMG не устанавливает программу: он подключает временный диск и открывает окно VirtualBox.

  2. В открывшемся окне запустите VirtualBox.pkg

    Появится системный Installer macOS. Нажмите Continue → Install и подтвердите действие паролем или Touch ID.

  3. Если установка заблокирована, откройте Privacy & Security

    System Settings → Privacy & Security → Allow. Затем снова запустите пакет; при запросе перезагрузите Mac.

  4. После сообщения об успешной установке откройте Applications → VirtualBox

    Теперь DMG можно извлечь. При первом запуске разрешите программе доступ к сети и нужным папкам.

macOS · граница платформы

Apple Silicon — это не «тот же Intel, только быстрее»

РАБОТАЕТГостевые ARM64-системы

Ubuntu ARM64 и другие AArch64-образы.

НЕ РАБОТАЕТГостевые x86 / AMD64

VirtualBox не эмулирует другой набор инструкций.

ЕСТЬ ОГРАНИЧЕНИЯGuest Additions и устройства

Часть функций ARM-хоста может отличаться от x86.

Если выбран несовместимый ISO, не «лечите» RAM и видеопамять. Сначала замените образ на правильную архитектуру.

Шаг 2 · первый экран мастера

Укажите имя VM, каталог хранения и установочный ISO-образ

  • NAME — ИМЯ В СПИСКЕ VIRTUALBOXВведите Ubuntu-lab-01. Это только название виртуальной машины в Manager; имя пользователя Ubuntu задаётся позднее внутри установщика.

Шаг 3 · RAM и CPU

Выделяем ресурсы, не обкрадывая хост

  • BASE MEMORY4 ГБ минимум для учебной VM; 6 ГБ комфортнее.
  • PROCESSORS2 ядра достаточно для установки и терминала.
  • ЗЕЛЁНАЯ ЗОНАНе выходите за неё: хост тоже должен работать.

Рекомендуемый профиль

Настройки зависят от возможностей хоста

ОПЕРАТИВНАЯ ПАМЯТЬ4–6 ГБ

При 8 ГБ на хосте отдаём гостю 4; при 16 ГБ — 6.

ПРОЦЕССОРЫ2 CPU

Не выделяем больше половины логических ядер.

ВИДЕОПАМЯТЬ128 МБ

Контроллер VMSVGA; 3D включаем только после стабильного запуска.

Красная зона в мастере означает, что хосту останется слишком мало ресурсов. Виртуальная машина не должна замораживать основной компьютер.

Шаг 4 · виртуальный диск

Создаём новый диск размером 30 ГБ

  • CREATE NOWНовый чистый диск для Ubuntu.
  • 30 GBМинимум курса; официальный минимум Ubuntu Desktop — 25 ГБ.
  • DYNAMICФайл растёт по мере заполнения, но лимит остаётся 30 ГБ.

Что такое VDI

Виртуальный диск — обычный файл на диске хоста

VDIФормат VirtualBox

Хранит виртуальные разделы, файлы и загрузчик Ubuntu.

DYNAMICALLY ALLOCATEDРастёт постепенно

Лимит 30 ГБ не означает, что файл сразу займёт 30 ГБ.

FIXED SIZEЗанимает всё сразу

Предсказуемее по производительности, но дольше создаётся.

Удаление файла .vdi равносильно удалению диска компьютера. Не переносите его при запущенной VM.

После создания VM · до первого запуска

Где открыть и проверить настройки виртуальной машины

  1. Полностью выключите VM и выберите её в списке

    В Ubuntu выполните «Завершить работу», дождитесь состояния Выключена / Powered Off. В VirtualBox Manager выделите Ubuntu-lab-01 и нажмите верхнюю кнопку Настроить / Settings. При запущенной или сохранённой VM часть полей заблокирована.

  2. Откройте «Дисплей → Экран»

    Установите VMSVGA и 128 МБ видеопамяти. Для первого запуска снимите флажок «Включить 3D-ускорение»; вернуть его можно после устойчивой загрузки рабочего стола.

  3. Откройте «Сеть → Адаптер 1»

    Включите сетевой адаптер, выберите тип подключения NAT и раскройте «Дополнительно»: флажок «Кабель подключён» должен быть установлен.

  4. Проверьте «Носители» и «Система → Материнская плата»

    В «Носителях» выберите оптический привод и подключите Ubuntu ISO через значок диска. В порядке загрузки поставьте Оптический диск перед Жёстким диском, нажмите ОК и только затем запускайте VM.

Контрольный результат: в сводке VirtualBox видны VMSVGA, 128 МБ, NAT, файл Ubuntu ISO и виртуальный диск VDI.

Ubuntu · сеть

Как настроить NAT и проверить получение адреса

  1. До запуска откройте настройки адаптера

    VirtualBox Manager → выключенная VM → Настроить → Сеть → Адаптер 1. Включите адаптер, выберите NAT и установите «Кабель подключён».

  2. На экране Network configuration найдите интерфейс

    Строка enp0s8 — виртуальная сетевая карта. Адрес вида DHCPv4 10.0.2.15/24 означает, что DHCP VirtualBox уже выдал настройки.

  3. Если адрес получен — продолжайте

    Клавишей Tab перейдите на Done и нажмите Enter. Ручной IP, шлюз и DNS в режиме NAT не вводятся.

  4. Если строки DHCPv4 нет

    Вернитесь назад, выключите VM и повторно проверьте «Кабель подключён». После установки выполните ip -br a, затем ping -c 3 1.1.1.1 и ping -c 3 ubuntu.com.

Ubuntu · состав системы

Как выбрать полный Ubuntu Desktop в текстовом установщике

  1. Передайте клавиатуру окну VM

    Щёлкните внутри окна VirtualBox. В Subiquity перемещение выполняется стрелками, выбор — Space, переход между областями — Tab, подтверждение — Enter.

  2. Выделите строку Ubuntu Desktop

    Стрелками перейдите на Ubuntu Desktop и нажмите Space. Маркер (X) подтверждает выбор полного графического рабочего стола.

  3. Не выбирайте минимальный вариант для курса

    Minimal устанавливает рабочую систему без части стандартных приложений. Это усложнит последующие лабораторные и потребует установки пакетов вручную.

  4. Проверьте выбор перед продолжением

    На экране должно остаться (X) Ubuntu Desktop. Настройку сторонних драйверов выполните по следующему слайду, затем выберите Done.

Тот же экран · сторонние драйверы

Где включить Third-party drivers и нужны ли они в VirtualBox

  1. Найдите блок Additional options

    На экране выбора Ubuntu Desktop стрелкой ↓ перейдите к строке Search for third-party drivers. Квадрат [ ] означает, что функция выключена.

  2. Для учебной VM оставьте флажок снятым

    VirtualBox предоставляет виртуальные видео-, сетевые и аудиоустройства, поэтому проприетарный драйвер физической видеокарты или Wi‑Fi гостевой системе обычно не нужен.

  3. Когда флажок действительно включают

    На физическом компьютере его отмечают клавишей Space, если требуется фирменный драйвер устройства и есть стабильный интернет. Установщик может запросить согласие с отдельной лицензией.

  4. Завершите экран и проверьте драйверы позднее

    Нажмите Tab до кнопки Done, затем Enter. После первого входа дополнительные драйверы проверяются через Программы и обновления → Дополнительные драйверы.

Guest Additions — отдельный компонент VirtualBox. Он устанавливается после Ubuntu и не относится к флажку сторонних драйверов на этом экране.

Ubuntu · разметка диска

Как проверить виртуальный диск перед удалением данных

  1. Выберите Use an entire disk

    Стрелками выделите этот вариант и нажмите Space. Маркер (X) означает автоматическую разметку всего выбранного виртуального диска.

  2. Сверьте устройство и объём

    В раскрывающейся строке должен быть /dev/sda local disk 30.000G или созданный вами объём. Если размер отличается от VDI, не продолжайте и проверьте «Настроить → Носители».

  3. Примите решение по LVM

    [X] Set up this disk as an LVM group — штатный вариант Ubuntu с гибким управлением томами; для курса его можно оставить включённым. Шифрование LUKS не включайте без отдельного задания и сохранённой парольной фразы.

  4. Подтвердите в два этапа

    Клавишей Tab выберите Done и нажмите Enter. На следующей сводке ещё раз проверьте только /dev/sda 30 GB, затем подтвердите запись изменений.

В этой работе стирается только файл виртуального диска VDI. На физическом компьютере команда Use an entire disk уничтожила бы данные выбранного накопителя.

После создания VM · Guest Additions

Где установить дополнения и включить интеграцию

  1. Сначала завершите установку Ubuntu

    Запустите VM, войдите в установленную систему и убедитесь, что рабочий стол работает без зависаний. Guest Additions устанавливаются внутри гостевой ОС, а не в VirtualBox Manager.

  2. Подключите установочный диск дополнений

    Сделайте окно запущенной VM активным. Windows/Linux: откройте меню окна Devices; macOS: используйте верхнюю системную строку меню. Выберите Devices → Insert Guest Additions CD Image.

  3. Запустите установщик внутри Ubuntu

    В появившемся диалоге нажмите Run и введите пароль. Если автозапуск не появился: откройте «Файлы» → диск VBox_GAs → терминал и выполните sudo sh ./VBoxLinuxAdditions.run, затем перезагрузите Ubuntu.

  4. Включите функции после перезагрузки

    В окне VM выберите Devices → Shared Clipboard → Bidirectional и при необходимости Drag and Drop → Bidirectional. Автоподстройка экрана: View → Auto-resize Guest Display.

  5. Добавьте общую папку отдельно

    Выключите VM → Настроить → Общие папки → + → выберите каталог хоста → отметьте «Автоподключение» и «Постоянная». В Ubuntu папка обычно появляется как /media/sf_имя.

Для Ubuntu ARM64 на Apple Silicon официальная поддержка Guest Additions ограничена. Если базовый драйвер уже работает, не заменяйте его без снимка VM; включайте функции по одной и проверяйте загрузку.

Диагностика · реальный случай

Белое окно установщика: последовательность исправления

  1. Отделите сбой установщика от зависания всей VM

    Подождите 1–2 минуты и проверьте, реагируют ли панель Ubuntu, курсор и другие приложения. Если работает только белое окно, проблема относится к его отрисовке; если не реагирует весь рабочий стол — проверяйте RAM и CPU по слайду 23.

  2. Выполните полное выключение

    В меню Ubuntu выберите «Завершить работу». Не сохраняйте состояние VM: сохранение вернёт тот же графический сбой при следующем запуске.

  3. Исправьте параметры дисплея в VirtualBox

    Manager → Ubuntu-lab-01 → Настроить → Дисплей → Экран: контроллер VMSVGA, видеопамять 128 МБ, 3D-ускорение выключено. Нажмите ОК.

  4. Проверьте ISO и повторите загрузку

    Настроить → Носители: Apple Silicon — ISO arm64, Intel/AMD — amd64. Запустите VM; если доступен пункт Ubuntu (safe graphics), выберите его. После открытия установщика продолжайте с обычными параметрами.

После установки извлеките Ubuntu ISO через Devices → Optical Drives → Remove disk. 3D и Guest Additions возвращайте по одному, каждый раз проверяя перезагрузку.
