Маршрут A · Windows

Скачайте Windows hosts и запустите установщик

  1. Откройте скачанный файл .exe

    Если Windows спросит разрешение на изменения — выберите «Да».

  2. Нажмите Next и оставьте компоненты по умолчанию

    Программа, USB, сеть и ярлыки устанавливаются вместе.

  3. Подтвердите установку сетевых драйверов

    Сеть может кратко отключиться: VirtualBox добавляет виртуальные адаптеры.

  4. Нажмите Install → Finish

    После завершения откроется VirtualBox Manager.

macOS · от загрузки до первого запуска

DMG открывает установочный диск, а файл PKG устанавливает программу

  1. В Finder откройте Downloads и дважды нажмите файл .dmg

    DMG не устанавливает программу: он подключает временный диск и открывает окно VirtualBox.

  2. В открывшемся окне запустите VirtualBox.pkg

    Появится системный Installer macOS. Нажмите Continue → Install и подтвердите действие паролем или Touch ID.

  3. Если установка заблокирована, откройте Privacy & Security

    System Settings → Privacy & Security → Allow. Затем снова запустите пакет; при запросе перезагрузите Mac.

  4. После сообщения об успешной установке откройте Applications → VirtualBox

    Теперь DMG можно извлечь. При первом запуске разрешите программе доступ к сети и нужным папкам.

macOS · граница платформы

Apple Silicon — это не «тот же Intel, только быстрее»

РАБОТАЕТГостевые ARM64-системы

Ubuntu ARM64 и другие AArch64-образы.

НЕ РАБОТАЕТГостевые x86 / AMD64

VirtualBox не эмулирует другой набор инструкций.

ЕСТЬ ОГРАНИЧЕНИЯGuest Additions и устройства

Часть функций ARM-хоста может отличаться от x86.

Если выбран несовместимый ISO, не «лечите» RAM и видеопамять. Сначала замените образ на правильную архитектуру.

Шаг 2 · первый экран мастера

Укажите имя VM, каталог хранения и установочный ISO-образ

  • NAME — ИМЯ В СПИСКЕ VIRTUALBOXВведите Ubuntu-lab-01. Это только название виртуальной машины в Manager; имя пользователя Ubuntu задаётся позднее внутри установщика.
  • FOLDER — КАТАЛОГ ФАЙЛОВ VMЗдесь будут храниться конфигурация .vbox и растущий виртуальный диск .vdi. Выберите локальный каталог с запасом свободного места, не облачную папку.
  • ISO IMAGE — УСТАНОВОЧНЫЙ НОСИТЕЛЬУкажите скачанный файл .iso, не распаковывая его. Для Windows x64 и Intel Mac нужен amd64; для Apple Silicon — arm64.
  • TYPE И VERSION — РЕЗУЛЬТАТ РАСПОЗНАВАНИЯПосле выбора ISO VirtualBox должен определить Linux и Ubuntu соответствующей архитектуры. Если показана другая система, остановитесь и проверьте выбранный файл.

Шаг 2 · VirtualBox 7.2 · автоматическая установка

Параметры этого раздела VirtualBox передаст установщику Ubuntu

  • УЧЁТНАЯ ЗАПИСЬ UBUNTUИмя пользователя станет логином внутри гостевой ОС. Пароль необходимо ввести дважды одинаково: пока оба поля пусты, красный индикатор сообщает об ошибке проверки, а кнопка «Готово» остаётся недоступной.
  • ИМЯ ХОСТА И ДОМЕНИмя хоста идентифицирует виртуальную машину в сети; для лабораторной работы задайте осмысленное значение, например ubuntu-lab-01. Поле ключа продукта неактивно, поскольку для Ubuntu оно не требуется.
  • ФОНОВАЯ УСТАНОВКАОставьте флажок снятым, если необходимо видеть окно запуска и ход установки. При включении VirtualBox выполняет установку без отображения графического окна виртуальной машины.
  • ДОПОЛНЕНИЯ ГОСТЕВОЙ ОСНа первом запуске этот флажок можно не устанавливать. Guest Additions подключают позднее, после успешной загрузки Ubuntu, когда требуется изменить разрешение экрана или включить интеграцию буфера обмена.
  • КАКОЙ СЦЕНАРИЙ ОТКРЫТНаличие этого раздела означает, что автоматическая установка включена. Внутри показанного блока отдельного переключателя режима нет: чтобы изменить способ установки, раскройте верхний раздел «Имя и операционная система виртуальной машины».

Шаг 3 · RAM и CPU

Выделяем ресурсы, не обкрадывая хост

  • BASE MEMORY4 ГБ минимум для учебной VM; 6 ГБ комфортнее.
  • PROCESSORS2 ядра достаточно для установки и терминала.
  • ЗЕЛЁНАЯ ЗОНАНе выходите за неё: хост тоже должен работать.

Рекомендуемый профиль

Настройки зависят от возможностей хоста

ОПЕРАТИВНАЯ ПАМЯТЬ4–6 ГБ

При 8 ГБ на хосте отдаём гостю 4; при 16 ГБ — 6.

ПРОЦЕССОРЫ2 CPU

Не выделяем больше половины логических ядер.

ВИДЕОПАМЯТЬ128 МБ

Контроллер VMSVGA; 3D включаем только после стабильного запуска.

Красная зона в мастере означает, что хосту останется слишком мало ресурсов. Виртуальная машина не должна замораживать основной компьютер.

Шаг 4 · виртуальный диск

Создаём новый диск размером 30 ГБ

  • CREATE NOWНовый чистый диск для Ubuntu.
  • 30 GBМинимум курса; официальный минимум Ubuntu Desktop — 25 ГБ.
  • DYNAMICФайл растёт по мере заполнения, но лимит остаётся 30 ГБ.

Что такое VDI

Виртуальный диск — обычный файл на диске хоста

VDIФормат VirtualBox

Хранит виртуальные разделы, файлы и загрузчик Ubuntu.

DYNAMICALLY ALLOCATEDРастёт постепенно

Лимит 30 ГБ не означает, что файл сразу займёт 30 ГБ.

FIXED SIZEЗанимает всё сразу

Предсказуемее по производительности, но дольше создаётся.

Удаление файла .vdi равносильно удалению диска компьютера. Не переносите его при запущенной VM.
