1. Задача

Сегодня последний рабочий день администратора Дмитрия Козлова (kozlov). Служба безопасности поручила закрыть его доступ к серверу ops-03 и передать его зону ответственности Анне Орловой (orlova). Бухгалтер Ирина Лебедева (lebedeva) работает с каталогом /srv/finance, её работа не должна прерваться.

Учётную запись не удалять: 30 дней она нужна для расследований. Всё, что может понадобиться, сохранить в /var/backups/offboarding/kozlov, доступ к копии — только у root.

2. Стенд

Копия сервера разворачивается в вашей виртуальной машине. Скачайте скрипты стенда и приёмки и разверните стенд:

cd ~/Downloads
wget https://algorthimization-course-vvodnoe.vercel.app/op05-operacionnye-sistemy-i-sredy/proekty/ekspluataciya-servera/materials/offboarding-stand.sh
wget https://algorthimization-course-vvodnoe.vercel.app/op05-operacionnye-sistemy-i-sredy/proekty/ekspluataciya-servera/materials/offboarding-acceptance.sh
sudo bash offboarding-stand.sh

Стенд создаёт учётные записи kozlov, orlova и lebedeva, каталоги команды и запускает процессы kozlov. Перед изменениями стенд записывает список программ с setuid, чтобы приёмка увидела новые.

Что есть на сервере

/srv/devopsскрипты выкладки и ключ доступа к продуктовым серверам; владелец сейчас kozlov
/srv/financeплатёжные документы бухгалтерии
/srv/shareобщая папка для обмена файлами
/home/kozlovдомашний каталог уволенного

3. Требования

1. Учётная запись

  1. 1.1
    Вход запрещён: пароль заблокирован, срок действия учётной записи истёк, оболочка — nologin. Учётная запись и домашний каталог остаются.
  2. 1.2
    kozlov исключён из всех дополнительных групп. Личных правил sudo не осталось ни в одном файле.
  3. 1.3
    Все процессы kozlov завершены. Перед завершением записано, что это за процессы: командная строка, родитель, текущий каталог, с какого времени работают.

2. Передача дел

  1. 2.1
    Каталог /srv/devops со всем содержимым принадлежит orlova, группа — devops; права не ослаблены; ключ выкладки доступен только владельцу.
  2. 2.2
    orlova запускает deploy.sh и читает ключ выкладки. lebedeva по-прежнему работает в /srv/finance.

3. Аудит файлов

  1. 3.1
    Найдены все файлы kozlov вне его домашнего каталога, по каждому принято решение: передать, перенести в копию или удалить.
  2. 3.2
    Дамп базы с персональными данными клиентов убран из общей папки в копию.
  3. 3.3
    Из домашнего каталога в копию перенесены notes.txt и .ssh.
  4. 3.4
    Найдены программы с битом setuid, которые не принадлежат пакетам системы. Посторонние удалены.

4. Акт аудита

  1. 4.1
    Каждая находка: что найдено, чем опасно, что сделано. Отдельный раздел — что нужно сделать вне сервера: какие пароли, токены и ключи kozlov знал и кому их сменить.

4. Распределение работ в паре

  • Инженер 1 · учётная запись и доступблокировка входа, группы, правила sudo, поиск и описание процессов kozlov, их завершение.
  • Инженер 2 · файлыпоиск файлов kozlov по всей системе, передача /srv/devops, копия в /var/backups, дамп из общей папки, программы с setuid.
  • Вместеприёмка, скрипт audit-user.sh, акт аудита.

5. Результат работы

В репозитории пары, кроме общих файлов:

audit.mdакт аудита: находки, действия, что сменить вне сервера.
audit-user.shскрипт: для имени пользователя из аргумента печатает группы, правила sudo, процессы, файлы вне домашнего каталога. Проверка: стенд заново, sudo bash audit-user.sh kozlov находит всё, что вошло в акт.
runbook.mdжурнал работ: время, кто из пары, команда, результат.
screenshots/процессы kozlov до завершения, найденные файлы и программы с setuid, вывод приёмки со всеми OK.

6. Приёмка

Скрипт приёмки ничего не меняет, только проверяет сервер и печатает OK или FAIL по каждому пункту. Работа принята, когда на стенде, развёрнутом заново, после вашего решения все пункты OK. Требования, которые скрипт проверить не может, проверяет преподаватель по документам.

sudo bash ~/Downloads/offboarding-acceptance.sh | tee acceptance.txt

Пункт FAIL — это подсказка, какое требование не выполнено. Подгонять сервер под скрипт в обход требований нельзя: при защите пара объясняет каждое действие из журнала.
