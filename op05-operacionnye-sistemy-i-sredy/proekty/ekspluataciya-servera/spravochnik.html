Скрипты bash

Скрипт — команды, записанные в файл по порядку. Запуск: sudo bash script.sh. Скрипт эксплуатации должен выдерживать повторный запуск: шаг, который уже выполнен, не ломает работу.

КонструкцияПримерЧто делает
первая строка#!/bin/bashкаким интерпретатором выполнять файл
строгий режимset -euостановиться на первой ошибке и на неизвестной переменной
переменнаяDIR=/srv/app; ls "$DIR"имя без пробелов вокруг =; при использовании — в кавычках
аргумент скриптаU=${1:-}первый аргумент или пусто, если его нет
вывод команды в переменнуюP=$(pgrep -f образец)
условиеif [ -d "$DIR" ]; then echo есть; else echo нет; fi-d — каталог, -f — файл, -e — существует, -z — пустая строка
выполнить, если первое не удалосьmkdir /srv/app 2>/dev/null || echo "каталог уже есть"так шаг не падает при повторном запуске
циклfor f in a.txt b.txt; do echo "$f"; done
функцияstep() { echo "== $*"; }вызов: step "Шаг 1"
проверить синтаксис без запускаbash -n script.sh
запуск с печатью каждой командыbash -x script.shудобно искать, на каком шаге ошибка
