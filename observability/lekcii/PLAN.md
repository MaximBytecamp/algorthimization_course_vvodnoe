# Метрики и наблюдаемость — карта справочника

Макаров Максим Николаевич. План пересборки, 06.11.2026. Одна книга в `lekcii/` вместо модулей
`temy/`, `modul-02-prometheus/`, `modul-03-metrika/`, `modul-04-sbor/`.

## Принципы

- **Только observability.** Инструменты сбора, хранения, запросов и анализа телеметрии: метрики,
  логи, трассы, профили, алерты. Инфраструктура вокруг (Kubernetes, базы данных, CI) — только там,
  где без неё не понять инструмент наблюдаемости.
- **Каждая технология подробно, объём — по самой технологии.** У сложной системы с несколькими
  компонентами и своим языком запросов — 8–12 лекций, у узкого инструмента — 3–4. Внутри части
  технология проходит один путь: зачем она → архитектура → запуск на стенде → конфигурация →
  запросы → эксплуатация и отказ → масштаб → типичные проблемы. Пункты, которых у технологии нет,
  пропускаются.
- **Одна лекция — одна подтема.** 6–10 разделов, 10–15 шагов в режиме чтения.
- **Без повторов, ссылки только назад.** Понятие объясняется в одной лекции, дальше — ссылка
  и строка в глоссарии.
- **Формат лекции** — как `lekcii/2-2-counter.html`. Всё проверено запуском на стенде.
