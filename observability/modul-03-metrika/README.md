# Модуль 3 · Метрика как данные

Третий модуль справочника «Метрики и наблюдаемость». Визуал — как у модуля 2: стили и скрипты
(`styles.css`, `algo.css`, `prom.css`, `book.js`, `algo.js`, `prom.js`) подключаются из папки
`../modul-02-prometheus/`, свои блоки модуля — в `m3.css` и `m3.js`.

## Главы

| Глава | Файл | Опыт на стенде |
|---|---|---|
| 3.1 Измерение, timestamp и sample | `01-sample.html` | отсчёты `[1m]`, одна отметка на опрос, мгновенный запрос |
| 3.2 Имя и единица измерения | `02-imya-i-edinica.html` | `promtool check metrics`, окончания prometheus-client |
| 3.3 Метки и идентичность ряда | `03-labels.html` | появление рядов, `__name__`, пустая метка, селекторы |

| 3.9 Итоги модуля | `09-itogi.html` | — |

Правила текста — как в модуле 2 после правок 12–13.10.2026: сравнение из жизни до термина в каждом
разделе, связные абзацы, одна схема на механизм, переход в конце раздела (`p.bridge`). Каждая глава
вычитана скиллом `/vychitka` (review.py, snap.mjs на 1280 и 390 px).

## Сборка

```sh
python3 build.py
```

Текст глав — `src/*.html`. `build.py` добавляет каркас, собирает `metrika-start.zip` из `stand/`
и `metrika-praktika.zip` из `stand-praktika/`. Глава без файла в `src/` на обложке помечается
«в работе». Оглавление справочника — `../tools/build_book.py` (переменная `module3`).

## Стенды и происхождение данных

`stand/` — сервис заказов (FastAPI 0.115.6, prometheus-client 0.26.0) и Prometheus 3.5.0,
порты 8031 и 9094, проект Compose `metrika-dannye`. Все числа, выводы и кадры `shots/` получены
на нём 23.10.2026; команды опытов — в `stand/README.md`.

- Кадры `range-samples.png`, `series-labels.png` — чистый запуск (`down -v`), 10 запросов GET,
  один 404, один POST. Отметки времени в главе 3.1 — с этого кадра.
- `tsdb-status.png` — после третьего шага опыта `BAD_LABELS=1` (2 047 рядов).
- Опыты глав 3.3–3.6 — в первом запуске стенда, до опыта с кардинальностью; время каждого опыта указано в главе.

`stand-praktika/` — сервис доставки, порты 8033 и 9096, проект `metrika-praktika`.
Эталон решения и ключ ответов — вне репозитория: `~/observability-tests-private/modul-3-praktika/`
(прогон 26.10.2026). Скрипт `nagruzka.ps1` в Windows не запускался.
