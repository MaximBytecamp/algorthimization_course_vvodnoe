# Модуль 2 · Как работает Prometheus

Второй модуль справочника «Метрики и наблюдаемость». Оформлен в визуале книги
ОП.04 «Алгоритмы на массивах»: `styles.css`, `algo.css`, `algo.js`, `book.js`
скопированы оттуда без изменений, палитра и интерактивы модуля — в `prom.css`
и `prom.js`.

## Сборка

```sh
python3 build.py
```

Текст глав — `src/*.html` (только содержимое страницы). `build.py` добавляет
каркас, вставляет диаграммы из `diagrams.py` на место `<!--include:…-->`
и собирает `prometheus-start.zip` из папки `stand/`. Готовые страницы
в корне модуля руками не править.

## Стенд и происхождение данных

`stand/` — FastAPI + Prometheus 3.5.0 в Docker Compose (порты 8020 и 9092).
Все выводы, тексты ошибок и снимки в `shots/` получены на этом стенде
29.09.2026:

- `targets-errors.png`, ошибки в главах 2.3–2.4 — запуск с `prometheus-errors.yml`;
- `graph-up.png`, `graph-requests.png`, таблица отсчётов в 2.4 §8 —
  остановка `api` в 13:22:41 UTC, запуск в 13:23:32;
- таблица поведения разборщика в 2.3 §3 — отдельный сервер с восемью и тремя
  ответами-нарушениями, собранный тем же Prometheus 3.5.0;
- заголовки запроса Prometheus в 2.3 §6 — сервер, печатающий входящий запрос;
- `honor_labels` и `exported_*` в 2.2 §6 — отдельный опыт с двумя заданиями;
- вариант без Docker в 2.6 §9 — архив prometheus-3.5.0.darwin-arm64.

Цитаты сверены с исходниками документации (github.com/prometheus/docs,
docs/ в prometheus/prometheus v3.5.0) и с главой 10 книги Google SRE.
