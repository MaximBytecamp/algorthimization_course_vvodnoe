# Метрики и наблюдаемость

Учебный справочник Макарова Максима Николаевича. Самостоятельный раздел сайта.
Полностью реализована первая тема: мониторинг, наблюдаемость и телеметрия.
9 глав, 47 содержательных разделов, практикум, исходные измерения и реальные кадры.
Остальные 7 модулей обозначены как план: ссылок на пустые главы нет.

## Структура

- `index.html` — обложка, оглавление, материалы и ссылки Python/MongoDB.
- `temy/*.html` — статические главы с работающими без JavaScript объяснениями.
- `styles.css`, `book.js` — книжная вёрстка и интерактивные разборы.
- `lab/` — запускаемый FastAPI, клиент эксперимента, необязательный Compose.
- `assets/telemetry-lab.zip` — полный архив практики.
- `assets/experiment-data.js` — сохранённые измерения для интерактивов.
- `shots/` — реальные кадры; происхождение в SOURCES.md.
- `tools/build_book.py` — исходный текст глав и генератор статического сайта.
- `tools/capture.py`, `capture_stack.py` — повторная съёмка действующих страниц.

## Обновление

```sh
python3 tools/build_book.py
python3 tools/package_lab.py
```

Первая команда использует записанные результаты `lab/results/` для интерактивов.
При пересъёмке с новым набором измерений сверить числовые подписи в главе 1.4.
Вторая исключает окружения и кэши, сохраняет эталонные результаты как
`reference-results/` внутри архива. Проект работает без фронтенд-сборки.

Съёмка и проверки выполняются только на синтетическом стенде этого справочника.
