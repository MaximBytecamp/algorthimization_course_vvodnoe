# Cafe Report — эталонная сборка

Программа читает заказы кофейни из файла `data/orders.csv` и печатает отчёт:
количество заказов, выручку, средний чек и суммы по официантам.

Внешних библиотек нет, нужен только Python 3.10 или новее.

## Структура

```
cafe-report/
├── .gitignore            что не попадает в репозиторий
├── README.md             назначение, запуск, результат
├── requirements.txt      список зависимостей проекта
├── app/                  исходный код программы
│   ├── __init__.py
│   ├── main.py           точка запуска: читает данные и печатает отчёт
│   ├── services/         правила работы с заказами
│   │   ├── __init__.py
│   │   ├── orders.py     чтение файла и расчёты
│   │   └── report.py     сборка строк отчёта
│   └── utils/            мелкие вспомогательные функции
│       ├── __init__.py
│       ├── money.py      копейки в рубли и запись суммы
│       └── text.py       имена и выравнивание колонок
├── data/
│   └── orders.csv        исходные данные
├── docs/
│   ├── about.md          что делает программа
│   └── structure.md      за что отвечает каждый файл
└── tests/
    ├── test_orders.py    проверки расчётов
    └── test_report.py    проверки отчёта и вспомогательных функций
```

## Запуск

Команды выполняются из корня проекта — из папки, в которой лежит `app/`.

```
python -m venv .venv
python -m app.main
python -m unittest discover -s tests -v
```

На Windows вместо `python` может потребоваться `py`, а окружение активируется
командой `.\.venv\Scripts\Activate.ps1`.
