# Text Kit — эталонная сборка

Набор из шестнадцати небольших функций: строки, даты, расчёты по числам
и проверка введённых данных. Программа печатает пример работы каждой функции.

Внешних библиотек нет, нужен только Python 3.10 или новее.

## Структура

```
text-kit/
├── README.md
├── app/
│   ├── __init__.py
│   ├── main.py                 точка запуска: данные примера и печать
│   ├── services/               правила этого проекта
│   │   ├── __init__.py
│   │   ├── statistics.py       среднее, медиана, разброс, подсчёт значений
│   │   └── validation.py       почта, телефон, пароль
│   └── utils/                  функции, пригодные в любом проекте
│       ├── __init__.py
│       ├── dates.py            чтение, запись и сравнение дат
│       └── text.py             пробелы, обрезка, инициалы, адрес страницы
└── tests/
    ├── test_dates.py
    ├── test_statistics.py
    ├── test_text.py
    └── test_validation.py
```

`validation.py` пользуется функцией `clean_spaces` из `utils/text.py` —
это единственная связь между модулями, кроме `main.py`.

## Запуск

Команды выполняются из корня проекта.

```
python -m app.main
python -m unittest discover -s tests -v
```
