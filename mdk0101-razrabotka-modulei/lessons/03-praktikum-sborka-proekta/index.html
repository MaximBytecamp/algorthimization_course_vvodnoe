Одинаковый порядок
в обеих работах.

Каждая работа устроена так: вы скачиваете архив, распаковываете его в отдельную папку, открываете лежащий внутри файл ЗАДАНИЕ.md и выполняете работу в VS Code. Готовность проверяется двумя командами: программа должна запуститься и напечатать ожидаемый результат, а тесты — пройти без ошибок.

Код в обеих работах менять не нужно. В первой работе переносятся и переименовываются файлы, во второй — функции переезжают из одного файла в несколько. Обе программы написаны на стандартной библиотеке Python: устанавливать ничего не потребуется.

Эталонные сборки тоже выложены. Открывайте их после собственной попытки — по ним удобно сверить раскладку, но они не заменяют выполненную работу.

Как оценивается работа

За каждую работу выставляется до 10 баллов: раскладка файлов и папок — 3, запуск программы с ожидаемым результатом — 3, прохождение тестов — 2, README с деревом проекта и командами — 2.

Сдача: папка работы в вашем репозитории дисциплины. В репозиторий не должны попасть .venv/, __pycache__/ и .env.
