Маршрут работы

Выполните в своём проекте
Где
Новая папка для практики; исходный разобранный проект сохранён отдельно.
Действие
Распакуйте практику, прочитайте файлы и восстановите структуру по списку ниже.
Результат
Получается тот же пакет Student Tools с .venv, зависимостями и документацией.
Проверка
Запуск даёт 4.40, три теста проходят; готовый пример открывайте после своей попытки.
  1. Определите ответственность. Где вычисления, где оформление строки, где запуск, где проверки, где зависимости?
  2. Дайте файлам понятные имена. Используйте snake_case. Создайте app/services, app/utils и tests.
  3. Оформите пакеты. Добавьте пустые __init__.py в app, services и utils. Сопоставьте дерево с импортами в main.py.
  4. Подготовьте окружение. Создайте .venv, активируйте, проверьте sys.executable и выберите тот же Python в VS Code.
  5. Восстановите зависимости. Установите их из переименованного requirements.txt.
  6. Запустите и проверьте. Из корня выполните две команды ниже. Исправляйте причину ошибки, а не переписывайте импорты наугад.
  7. Подготовьте передачу. Добавьте .gitignore и README с командами, результатом и объяснением структуры.

Мини-тренажёр перед раскладкой

Выберите место для каждого файла. Это проверка понимания; саму практику нужно выполнить в VS Code.

Если не запускается

No module named rich

Проверьте sys.executable и python -m pip show rich. Установите зависимости в Python, которым запускаете программу.

No module named app

Терминал должен быть в папке над app. Проверьте, что app не оказался внутри второй вложенной student-tools. Запуск: python -m app.main.

Cannot import name или partially initialized module

Проверьте имя функции, содержимое файла и циклические импорты. calculator и formatter не должны импортировать main.

Тесты не найдены: Ran 0 tests

Убедитесь, что файл называется test_calculator.py, лежит в tests, а команда из корня содержит discover -s tests. Ноль тестов — не подтверждение готовности.

Python не найден / venv не создаётся

На Windows проверьте py --version, на macOS/Linux — python3 --version. Если Python не установлен, сначала установите его. На некоторых Linux-системах компонент venv ставится отдельно; следуйте сообщению системы или обратитесь к преподавателю.
