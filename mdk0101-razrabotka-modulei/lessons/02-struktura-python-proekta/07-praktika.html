Мини-тренажёр перед раскладкой

Выберите место для каждого файла. Это проверка понимания; саму практику нужно выполнить в VS Code.

Если не запускается

No module named rich

Проверьте sys.executable и python -m pip show rich. Установите зависимости в Python, которым запускаете программу.

No module named app

Терминал должен быть в папке над app. Проверьте, что app не оказался внутри второй вложенной student-tools. Запуск: python -m app.main.

Cannot import name или partially initialized module

Проверьте имя функции, содержимое файла и циклические импорты. calculator и formatter не должны импортировать main.

Тесты не найдены: Ran 0 tests

Убедитесь, что файл называется test_calculator.py, лежит в tests, а команда из корня содержит discover -s tests. Ноль тестов — не подтверждение готовности.

Python не найден / venv не создаётся

На Windows проверьте py --version, на macOS/Linux — python3 --version. Если Python не установлен, сначала установите его. На некоторых Linux-системах компонент venv ставится отдельно; следуйте сообщению системы или обратитесь к преподавателю.

Если не собирается

go.mod file not found in current directory or any parent directory

Терминал находится вне модуля или go mod init не выполнялся. Перейдите в папку, где лежит go.mod, и повторите команду. Проверьте, что проект не оказался внутри второй вложенной папки student-tools.

no required module provides package github.com/fatih/color

Импорт в коде есть, а записи в go.mod нет. Выполните go mod tidy: команда прочитает импорты и добавит нужное. Если ошибка осталась, проверьте написание пути — он должен точно совпадать с адресом репозитория, включая регистр.

found packages services and calculator in одной папке

В одной папке лежат файлы с разными объявлениями package. Приведите первую строку всех файлов папки к одному имени — тому, которое совпадает с именем папки.

undefined: services.calculateAverage

Функция названа со строчной буквы, поэтому вне своего пакета она не существует. Переименуйте её в CalculateAverage и исправьте вызов. Та же ошибка возникает, если функция лежит в другой папке, чем вы думаете.

imported and not used: "fmt"

В Go неиспользованный импорт — ошибка компиляции, а не замечание. Удалите лишнюю строку импорта или воспользуйтесь именем из этого пакета. Расширение Go в VS Code убирает такие импорты само при сохранении файла.

import cycle not allowed

Два пакета импортируют друг друга. Проверьте, не появился ли в services или utils импорт пакета main. Данные передают аргументами, результат возвращают через return; обратный импорт для этого не нужен.

Тесты не найдены: [no test files]

Файл обязан заканчиваться на _test.go, а функция — начинаться с Test и принимать *testing.T. Строки no test files не являются ошибкой, но и подтверждением готовности тоже: ищите в выводе PASS и ok.

command not found: go

Go не установлен или не попал в PATH. Установите его с go.dev/dl, затем закройте и заново откройте терминал VS Code: переменные окружения читаются при его запуске.
