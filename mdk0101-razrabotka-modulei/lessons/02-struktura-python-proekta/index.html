Сначала подготовим окружение, затем запустим один файл. Подключим Rich, разделим обязанности между модулями и соберём пакет. В конце восстановим проект из архива и подготовим собственную работу для GitHub.

Это книга для чтения и работы рядом с VS Code. У каждой главы есть конкретный результат, примеры целиком и проверка понимания. Идите по порядку при первом прохождении; возвращайтесь к нужной главе, когда требуется подсказка.
