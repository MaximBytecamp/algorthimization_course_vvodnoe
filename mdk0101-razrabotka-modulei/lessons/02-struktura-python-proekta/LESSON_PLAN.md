# Тема 02 · Структура Python-проекта

Формат: одна книга, один учебный модуль, восемь последовательных глав.
Вход: index.html из меню дисциплины. Главы — самостоятельные статические HTML;
book.css и book.js общие. Сборка и серверная часть не требуются.

## Учебная последовательность

1. .venv: проблема общих пакетов, рабочая папка, создание, активация, проверка,
   различия Windows PowerShell/CMD и macOS/Linux, запуск без активации.
2. VS Code: выбор интерпретатора, альтернативное создание окружения через палитру,
   первый запуск Student Tools одним файлом.
3. pip, PyPI, Rich: установка, проверка Location, изоляция, изменение вывода.
4. Модули: ответственность, перенос функций, именование, import, __name__, циклы.
5. Пакеты: __init__.py, дерево, абсолютные импорты, python -m app.main,
   различие структуры и архитектуры.
6. Передача: requirements, ограничения freeze, .gitignore, README, unittest,
   восстановление на другом компьютере.
7. Практика: восстановить тот же проект из разрозненных файлов без правки функций.
8. ДЗ: продолжение Student Tools в lesson_02 личного репозитория дисциплины.
   Добавить минимум и максимум, тесты и инструкцию воспроизводимого запуска.

Исходные 72 слайда переработаны в главы: окружение перенесено в начало по запросу.
Вместо разрозненных Hello World/калькулятора используется один пример со средней
оценкой. Схемы интерфейса явно обозначены как схемы, не как реальные скриншоты.

## Материалы

- materials/student-tools-start.zip — main.py без внешних зависимостей.
- materials/stages/ — полные версии main.py для промежуточных шагов.
- materials/student-tools-practice.zip — намеренно неструктурированные исходники.
- materials/student-tools-reference.zip — финальный пакет, 3 теста и инструкция.
- materials/homework.md — скачиваемые условия домашней работы.

Архивы не включают .venv. Открытые исходники доступны по кнопкам около кода.
В .vercelignore есть узкое исключение для materials этой темы, иначе сервер
публикации исключит .py, .md и requirements.txt и ссылки перестанут работать.
После изменения исходников нужно обновить соответствующий ZIP и код в главе.
