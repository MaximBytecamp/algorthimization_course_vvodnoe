# Тема 02 · Структура Python-проекта

Формат: одна книга, один учебный модуль, восемь последовательных глав.
Вход: index.html из меню дисциплины. Главы — самостоятельные статические HTML;
book.css и book.js общие. Сборка и серверная часть не требуются.

## Учебная последовательность

1. .venv: проблема общих пакетов, рабочая папка, создание, активация, проверка,
   различия Windows PowerShell/CMD и macOS/Linux, запуск без активации.
2. VS Code: выбор интерпретатора, альтернативное создание окружения через палитру,
   первый запуск Student Tools одним файлом.
3. pip, PyPI, Rich: установка, проверка Location, изоляция, изменение вывода.
4. Модули: ответственность, перенос функций, именование, import, __name__, циклы.
5. Пакеты: __init__.py, дерево, абсолютные импорты, python -m app.main,
   различие структуры и архитектуры.
6. Передача: requirements, ограничения freeze, .gitignore, README, unittest,
   восстановление на другом компьютере.
7. Практика: восстановить тот же проект из разрозненных файлов без правки функций.
8. ДЗ: продолжение Student Tools в lesson_02 личного репозитория дисциплины.
   Добавить минимум и максимум, тесты и инструкцию воспроизводимого запуска.

Исходные 72 слайда переработаны в главы: окружение перенесено в начало по запросу.
Вместо разрозненных Hello World/калькулятора используется один пример со средней
оценкой. Схемы интерфейса явно обозначены как схемы, не как реальные скриншоты.

## Материалы

- materials/student-tools-start.zip — main.py без внешних зависимостей.
- materials/stages/ — полные версии main.py для промежуточных шагов.
- materials/student-tools-practice.zip — намеренно неструктурированные исходники.
- materials/student-tools-reference.zip — финальный пакет, 3 теста и инструкция.
- materials/homework.md — скачиваемые условия домашней работы.

Архивы не включают .venv. Открытые исходники доступны по кнопкам около кода.
В .vercelignore есть узкое исключение для materials этой темы, иначе сервер
публикации исключит .py, .md и requirements.txt и ссылки перестанут работать.
После изменения исходников нужно обновить соответствующий ZIP и код в главе.

## Доработка после аудита лекции-практики

Добавлены 17 карточек «Где → Действие → Результат → Проверка», инструкция
создания и сохранения файлов, карта элементов интерфейса VS Code, пояснение
переименования промежуточного main.py и пошаговая сдача через GitHub.
В каждой главе доступен необязательный режим показа одного раздела с кнопками
«Назад / Далее», счётчиком и переходами из оглавления. Основной формат — книга.

В shots/ находятся двенадцать снимков браузерного оформления реально записанного
вывода команд из чистого окружения Python 3.12. Это не скриншоты нативного VS Code:
различие прямо указано на изображениях и схеме интерфейса. Полный stdout/stderr
сохранён в materials/run-evidence.txt, исходник оформления — shots/evidence.html.
Изображения можно открыть в полном размере; текст доступен отдельной загрузкой.

Записанный прогон покрывает: содержимое нового .venv и pyvenv.cfg, пустой pip list,
путь .venv, ModuleNotFoundError до установки, полный вывод pip install, pip show
и pip --version, цветной вывод Rich, сравнение Location внутри окружения и после
deactivate, падение python app/main.py против успешного python -m app.main, импорт
без побочного вывода, pip freeze с записью в файл, три успешных теста и полный
прогон с чистого листа по requirements.txt. Версии и абсолютные пути относятся
к записанному прогону; у студентов они будут другими.

В главе 2.2 добавлены три снимка настоящего окна VS Code (macOS, светлая тема,
чистый профиль редактора): палитра команд с Python: Select Interpreter, список
интерпретаторов с пометкой Recommended у ./.venv и рабочее окно с открытым main.py,
автоматически активированным окружением в терминале и выбранным интерпретатором
в строке состояния. В подписях указано, что это снимки нативного окна, в отличие
от карты интерфейса рядом, помеченной как схема.

Главы 2.4, 2.7 и 2.8 снимков не содержат: там студент работает с собственными
файлами, и показывать чужой результат до его попытки не нужно.

Для изменений общих CSS/JS добавлена версия URL, чтобы ранее открытая книга
не смешивала новую разметку со старым кодом из кэша. Добавлен локальный favicon.
