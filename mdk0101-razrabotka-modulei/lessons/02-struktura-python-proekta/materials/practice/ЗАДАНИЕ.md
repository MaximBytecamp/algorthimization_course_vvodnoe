# Практика: разобрать доставку файлов

Это те же Student Tools, но файлы прислали без структуры. Файлы намеренно названы
не по правилам модулей, а импорты в точке запуска уже указывают на будущую структуру.
Не запускайте заготовку до раскладки. Код функций менять не требуется.

1. Создайте student-tools, app/services, app/utils, tests.
2. Прочитайте файлы и переименуйте по ответственности: calculator.py, formatter.py,
   main.py, test_calculator.py, requirements.txt. Разложите их по папкам.
3. Добавьте пустые __init__.py в app, services, utils.
4. Создайте и проверьте .venv, выберите её в VS Code.
5. Установите зависимости: python -m pip install -r requirements.txt.
6. Запустите из корня: python -m app.main. Ожидается Средний результат: 4.40.
7. Выполните python -m unittest discover -s tests -v. Ожидаются 3 теста и OK.
8. Добавьте .gitignore и README с назначением, Python 3.10+, командами для своей ОС,
   ожидаемым выводом и объяснением структуры. Не включайте .venv в сдачу.

Подсказки и готовый пример доступны в главе 2.7 книги.
