# Student Tools — эталонная сборка (Go)

Программа считает среднюю оценку по списку и печатает результат цветом.
Нужен Go 1.21 или новее; зависимости скачиваются командой `go mod download`.

## Структура

```
student-tools/
├── .gitignore            собранная программа и локальные файлы в Git не попадают
├── README.md             назначение, запуск, результат
├── go.mod                имя модуля, версия Go и версии зависимостей
├── go.sum                контрольные суммы скачанных версий
├── main.go               пакет main: точка запуска
└── internal/             пакеты только для этого модуля
    ├── services/
    │   ├── calculator.go       расчёт средней оценки
    │   └── calculator_test.go  проверки расчёта
    └── utils/
        └── formatter.go        оформление строки результата
```

## Запуск

Команды выполняются из корня проекта — из папки, в которой лежит `go.mod`.

```
go mod download
go build ./...
go run .
go test ./... -v
```

## Ожидаемый результат

```
Средний результат: 4.40
```

Тесты дают строки `PASS` и `ok example.com/student-tools/internal/services`.
Пакеты без тестов отмечаются как `[no test files]` — это не ошибка.
