# Занятие 5 · Структура пакета и типизированный публичный интерфейс

Методичка к колоде. Здесь разбор темы, тайминг и то, чем это занятие
отличается от соседних. Правила текста — `shared/VOICE.md`, правило
непохожести колод — `shared/DECK_VARIETY.md`.

## 1. Что требует КТП

Первое занятие раздела 2 «Python bridge и рефакторинг существующего кода»
(16 часов, 8 пар). В колоде дисциплины идёт вторым: занятия 2–4 из раздела 1
(замороженный контракт, backlog вертикальных функций, Git-flow) читаются
по отдельным материалам.

| | |
|---|---|
| **Тема** | Структура пакета и типизированный публичный интерфейс |
| **Изучаем** | src-layout, packages/modules, public API, imports, type hints, aliases, static checking, cyclic dependency |
| **Студенты делают** | переводят starter code в пакет, типизируют публичные функции, устраняют циклический импорт |
| **Формат** | B — обязательный baseline, 2 академических часа |
| **Сдать** | typed package baseline и import map: пакет, `pyproject.toml`, `__all__`, `docs/import-map.md`, `docs/incident-05.md` |
| **Контроль** | запуск из чистого клона и из другой папки, один контролируемый отказ (цикл), три проверки, Pull Request, объяснение границ |
| **Продолжение по КТП** | запустить static checker и объяснить одну найденную ошибку |

Стенд занятия — `stend/`: `orders.py` (105 строк) и `orders.json` (шесть заказов).
Собранный вариант — `razbor/`. Кадры VS Code — `shots/`.

## 2. Главная мысль

**Граница модуля — это ответ на вопрос «сколько файлов придётся открыть, когда
что-то изменится».** Не «красивый код», не «правильная архитектура», а число.
Поэтому вся колода держится на счёте: 1 → 9 файлов, 3 → 0 общих переменных,
31 → 8 имён наружу, 35 → 0 замечаний проверок, 11 ссылок в 5 файлах против
4 в одном.

Занятие должно жить и вне пары: студент, открывший колоду через полгода,
находит в ней разбор шести сообщений об ошибке импорта с причинами, правило
разреза «одна причина меняться», три способа разорвать цикл с ценой каждого
и объяснение, зачем пакету нужен `py.typed`.

## 3. Границы темы

- **`dataclass`, `Enum`, value objects** — занятие 6. Здесь `Status` остаётся
  `Literal` из пяти строк, `OrderId` — псевдонимом `int`. Экран 19 прямо говорит,
  что проверки значения пока нет;
- **иерархия доменных ошибок и контекстные менеджеры** — занятие 7. У нас три
  класса ошибок, и они нужны только чтобы `find` не возвращал `None`;
- **`Protocol` и внедрение зависимостей** — занятие 8. Подмену `storage`
  фальшивой реализацией мы не делаем, хотя граница для неё уже готова;
- **асинхронность** — занятие 9;
- **Pydantic и FastAPI** — раздел 4. Те же аннотации, но уже на границе HTTP;
- **метаклассы, дескрипторы, динамическая сборка модулей** — не входят в курс.
  Названы один раз на экране границ темы как то, чего мы избегаем.

## 4. Ведущий приём: карта импортов

Колода держится на **SVG-карте импортов** `.imap`, которая перерисовывается
пять раз и каждый раз отвечает на свой вопрос:

| № | Экран | Что показывает |
|---|---|---|
| 1 | 6 | один файл: восемь функций и три общие переменные, стрелок нет вообще |
| 2 | 12 | девять узлов без связей — разрезали, но ещё не соединили |
| 3 | 14 | семнадцать стрелок, все сверху вниз: граф собирается снизу |
| 4 | 28 | те же семнадцать плюс две красные встречные: порядок исчез |
| 5 | 34 | итог «было → стало» четырьмя числами |

Второй, разовый приём — **лента публичной поверхности** `.surface` (экран 16):
все тридцать одно имя пакета в одну ленту, восемь подсвечены. Ровно один раз
за колоду и больше нигде.

Практическая часть идёт **настоящими кадрами VS Code** (`shots/`, 13 снимков).
Кадры сняты скриптом: VS Code запускался с `--remote-debugging-port` на
отдельном профиле, управление шло через Playwright по CDP, проект открыт
по короткому пути `/private/tmp/orders-service`, чтобы трассировки читались.

## 5. Что в колоде получено прогоном, а не взято из документации

| Число или строка на экране | Откуда |
|---|---|
| `всего к оплате: 15067.0` и `всего к оплате: 0` | два запуска `orders.py` из разных папок |
| `3060.0`, `6800.0`, `2968.0` в столбце сумм | тот же запуск: `int` превращается в `float` в `total()` |
| 17 ошибок mypy и 16 замечаний Ruff, всего 35 | `mypy --strict orders.py` и `ruff check --select E,F,I,UP,ANN,TID` |
| `Incompatible types in assignment … [Ln 42, Col 17]` | панель Problems на том же файле |
| трассировка `ImportError … partially initialized module` | настоящий запуск состояния с циклом |
| `Success: no issues found in 11 source files`, `11 passed in 0.01s` | прогон на собранном пакете |
| 11 ссылок в 5 файлах / 4 ссылки в 1 файле | Find All References в VS Code |

Если пересобираете стенд — числа на экранах 2, 20, 21, 30, 34 и подписи

## 6. Тайминг

| Этап | Минуты | Содержание |
|---|---|---|
| Вход | 0–8 | два запуска и ноль в отчёте, разбор трёх строк (экраны 2–4) |
| Разбор | 8–22 | модуль и пакет, карта одного файла, четыре признака (экраны 5–7) |
| Заход | 22–38 | src-layout, установка пакета, `python -m orders`, правило разреза (экраны 8–12) |
| Границы | 38–52 | разбор `pricing`, карта со стрелками, дверь пакета, лента поверхности, ссылки (экраны 13–17) |
| Типы | 52–64 | аннотация, псевдонимы, 35 замечаний, причина `3060.0`, неверный вызов (экраны 18–22) |
| Практика 1 | 64–71 | разметить границы `schedule.py` в парах (экран 23) |
| Цикл | 71–86 | термин, два файла, трассировка, красная карта, три способа, починка, проверки (экраны 24–30) |
| Практика 2 и итог | 86–90 | справка, чек-лист, приёмка, карта «было → стало», ДЗ (экраны 31–38) |

Практика на семь минут стоит **до** блока про цикл намеренно: студент успевает
сам провести границы на чужом коде, и цикл дальше читается как последствие
неудачной границы, а не как отдельный фокус языка.

## 7. Что подготовить заранее

1. **Раздать `stend/` перед парой** и попросить создать окружение. Единственный
   риск занятия не в теме, а в том, что у кого-то не встанет `mypy`.
2. Проверить, что в редакторе стоят расширения Python, Pylance, Ruff и Mypy Type
   Checker, а в `.vscode/settings.json` — `"mypy-type-checker.args": ["--strict"]`.
   Без этого экран с 35 замечаниями на паре не воспроизведётся.
3. Держать открытым свой `razbor/` — на случай, если у кого-то пакет не установится
   и придётся работать в паре.

## 8. Частые вопросы группы

**«Зачем `src`, если и так работает?»** — работает ровно до момента, когда рабочая
папка изменится: CI, чужой компьютер, запуск из редактора. Экран 9 отвечает ценой:
один лишний шаг при заведении проекта против нескольких часов на «у меня работает».

**«`__all__` же ни на что не влияет?»** — влияет на `from orders import *` и, главное,
это единственное место, где записано, что мы обещаем не ломать. Экран 17 переводит
обещание в число: 11 ссылок в 5 файлах против 4 в одном.

**«Можно я просто перенесу импорт внутрь функции?»** — можно, запуск починится.
Экран 29 честно называет цену: стрелка исчезнет с карты, но не из кода, и вернётся
при следующем разрезе. Это первый способ из трёх, и он помечен как плохой.

**«mypy ругается на чужую библиотеку»** — это отдельный разговор про `ignore_missing_imports`;
в нашем пакете внешних зависимостей нет, поэтому на паре вопрос не возникает.
