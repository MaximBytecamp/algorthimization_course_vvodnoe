# Стенд занятия 5 — исходное состояние

Сервис заказов, каким он достался нам «по наследству»: один файл `orders.py`
на 105 строк и данные рядом. Это то, что студенты открывают в начале пары
и режут на пакет к её концу.

## Что здесь

```
orders.py           сервис целиком: чтение файла, скидки, статусы, отчёт
orders.json         шесть заказов
.vscode/settings.json   настройки редактора: Ruff и mypy --strict
```

## Как запустить

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install ruff mypy pytest
python orders.py
```

Отчёт напечатается. Теперь тот же файл из папки выше:

```bash
cd .. && python orders-service/orders.py
```

Сумма станет нулевой. Это и есть точка входа занятия: ошибки нет, а результат другой.

## Что здесь специально сломано

| Место | Что не так |
|---|---|
| `DATA_FILE = "orders.json"` | относительный путь: разворачивается от текущей папки, а не от файла |
| `LOADED = []` | общая переменная: порядок вызовов нигде не записан |
| `total()`, строка 42 | `s - s * p / 100` превращает целое в дробное, отсюда `3060.0` в отчёте |
| `cancel()` | проверяет правило, пишет на диск и печатает в консоль — три обязанности |
| `report()` | правило «отменённый не считается» спрятано внутри печати |

Ни одна из этих строк не «неправильная сама по себе». Каждая мешает менять
код по частям — об этом и занятие.
