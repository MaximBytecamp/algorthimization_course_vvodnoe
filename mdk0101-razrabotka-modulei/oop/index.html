Класс объединяет данные и действия, которые поддерживают их в согласованном состоянии. ООП полезно не для замены каждой функции классом, а для работы с сущностями, у которых есть собственное состояние и правила изменения.

Как работать с примерами

  1. Выберите один блок с подписью main.py. Кнопка «Копировать» копирует программу без вывода.
  2. Сохраните код в отдельный файл main.py. Примеры независимы: одинаковые имена классов могут встречаться в разных разделах.
  3. Откройте терминал в папке файла и запустите python main.py. Если Python доступен другой командой, используйте python3 main.py или на Windows py main.py.
  4. Сравните результат с блоком «Вывод». Следующий абзац объясняет, почему получилось именно так.

Для запуска этих программ не нужны сеть, учётные записи и сторонние пакеты. Инструменты качества кода в модуле 9 перечислены отдельно: их команды не являются обязательной подготовкой к примерам.

По-простому: как читать справочник

Сначала посмотрите на действие, затем на результат, после — на объяснение. Такая последовательность помогает привязать название механизма к тому, что действительно произошло.

ПрограммаЧто передали и вызвали
→
ВыводЧто получилось
→
РазборПочему это произошло

Что есть что. Программа — проверяемый пример, вывод — результат его запуска, разбор — связь между конструкцией Python и результатом.
