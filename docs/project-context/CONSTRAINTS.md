# Ограничения памяти проекта

- Не хранить секреты, токены, пароли и значения переменных окружения.
- Не хранить персональные данные и полные переписки.
- Не копировать исходный код или полный вывод команд: давать путь и краткий вывод.
- Ссылаться на канонический файл вместо повторения его содержимого.
- Отделять проверенные факты от предположений и незакрытых вопросов.
- Указывать дату исторического среза и проверять его по текущему коду.
- Не читать весь архив памяти без задачи, которая действительно этого требует.
- Сохранять пригодный для повторного использования контекст сразу после появления,
  не дожидаясь конца сеанса или команды `$handoff`.
- Дополнять каноническую тематическую заметку вместо создания записи с тем же смыслом.
- Сохранять существующие пользовательские изменения в рабочем дереве.
- Не считать запись в памяти разрешением на commit, push, деплой или публикацию.
