## Отличия ClickHouse, которые меняют устройство

- На Windows сервер не ставится: основной путь — Docker, запасной — WSL2.
- Compass нет: кадры из встроенного Play UI (`localhost:8123/play`) через Playwright
  и из clickhouse-client; DBeaver — по решению пользователя.
- Запрос — строка SQL, одинаковая во всех драйверах; языки различаются только
  подключением, параметрами и пакетной вставкой.
- Скорость видна на миллионах строк: данные генерируются в самом сервере
  `INSERT … SELECT … FROM numbers(N)` с детерминированными хешами, без файлов.
