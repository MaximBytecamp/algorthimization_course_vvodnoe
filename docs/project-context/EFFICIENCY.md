# Экономия контекста и токенов

Обновлено: 2026-11-05

## Действующая схема

- `AGENTS.md` содержит только маршрутизацию и постоянные правила.
- В начале задачи читаются короткие `INDEX.md` и `CURRENT.md`.
- Тематические заметки и граф открываются только по запросу.
- `$handoff` сохраняет состояние перед переходом в новый чат.
- `$vychitka` подгружает большой редакторский регламент только при вычитке.
- Каталог доступных навыков ограничен значением `skills.max_context_tokens = 3500`
  в пользовательском `~/.codex/config.toml`.
- `$context-audit` проверяет ссылки, размер основных заметок, дубликаты и граф без
  загрузки всего архива в контекст модели.
- Готовый или существенно переработанный учебный материал проходит `$vychitka`
  один раз перед сдачей, а не после каждого текстового блока.
- Тесты, аудит контекста, обновление графа и handoff запускаются по типу изменения,
  поэтому не расходуют контекст на нерелевантных задачах.
- `$router` оставляет простые задачи основной модели и при реальной выгоде передаёт
  узкие подзадачи агентам `luna_fast`, `terra_writer` или `sol_builder` с минимальным
  набором путей и ограничений.
- История автоматически сжимается после ответа при заполнении 70% доступного окна.
- `$context-search` хранит перестраиваемый локальный FTS-индекс в скрытом исключённом
  из Git кэше и возвращает до пяти релевантных заметок вместо загрузки всего графа
  или архива.
- Один результат инструмента ограничен 6000 токенами; встроенная Memories явно
  отключена, чтобы не дублировать каноническую память Obsidian.
- Агенты `luna_fast` и `terra_writer` работают без каталога skills, приложений,
  плагинов и встроенной памяти.
- Качественный тест Terra, Sol и Astra сохранён в `MODEL_EVAL.md`: Terra выбрана для
  текстов, Sol — для смешанной технической работы, Astra — только для сложного аудита.

## Команды Codex

- `/compact` — сжать длинную переписку, сохранив важное состояние.
- `$handoff`, затем `/new` — начать следующую фазу в чистом чате.
- `/mention ПУТЬ` — явно приложить только нужный файл вместо большого фрагмента.
- `/status` и `/usage` — проверить расход контекста и токенов.
- `/skills` — явно выбрать редкий навык, если он не попал в сокращённый каталог.

## Схема Claude Code (настроена 2026-11-05)

- `AGENTS.md` Claude Code загружает сам; `CLAUDE.md` не создаётся, иначе правила
  попадут в контекст дважды.
- Навыки `context-search`, `context-audit`, `handoff` — символические ссылки
  `~/.claude/skills/* → ~/.codex/skills/*`, правка действует в обоих инструментах.
  `router` для Claude — отдельный `~/.claude/skills/router/SKILL.md`.
- Агенты в `~/.claude/agents`: `luna-fast` (Haiku, только чтение), `terra-writer`
  (Sonnet, тексты), `sol-builder` (Sonnet, код). Основная модель — Opus, effort medium.
- `.claude/settings.local.json` проекта: `autoMemoryEnabled: false` (архив встроенной
  памяти уже в `archive/claude-memory`) и хук `SessionStart` (startup, clear, compact),
  который выводит `CURRENT.md` в контекст.
- `~/.claude/settings.json`: `bashOutputMaxChars: 15000` (было 30000),
  `MAX_MCP_OUTPUT_TOKENS=12000` (было 25000), `skillListingMaxDescChars: 400`,
  `disableClaudeAiConnectors: true` (Notion, Figma, Google Drive, Claude Docs),
  плагин Figma выключен, редкие синхронизированные навыки скрыты через
  `skillOverrides` (morning, material-3, google-workspace, import-memory, браузерные,
  computer-use — off; deep-research, skill-creator, claude-api — только имя).
- Хук `SessionStart` выводит `PREFERENCES.md` и `CURRENT.md` (около 540 слов).
- Строка состояния `~/.claude/statusline.sh`: модель | effort | ctx % (занято/окно) |
  ветка Git. Модель не переключается сама; `opusplan` не включён (см. `DECISIONS.md`).
- Команды: `/context` — что занимает окно, `/compact` — сжать, `/clear` — новый чат
  после `/handoff`. Автосжатие встроено и включено.
- Вернуть коннектор claude.ai: убрать `disableClaudeAiConnectors` из глобальных
  настроек. Вернуть скрытый навык: удалить его из `skillOverrides`.

## Обслуживание

1. Запускать `$context-audit` после крупных изменений памяти или структуры проекта.
2. После изменения `skills.max_context_tokens` перезапускать Codex.
3. Не дублировать проектную память в Notion или встроенных memories. Встроенную память
   оставлять для личных предпочтений, действующих во всех репозиториях.
