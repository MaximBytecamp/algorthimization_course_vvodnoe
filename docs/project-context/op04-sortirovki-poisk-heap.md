# ОП.04 · Сортировка, бинарный поиск и heap

## Старт книги (26.11.2026)

- Новый раздел расположен в `op04-algoritmizaciya/sortirovki-poisk-heap/`.
  Главная страница книги — `index.html`, локальные стили — `sortirovki.css`.
- Карточка на общей странице ОП.04 ведёт в новый раздел.
- Начат модуль 0 «Упорядочивание изнутри». Первая готовая глава:
  `00-osnovy-uporyadochivaniya/01-poryadok-i-klyuch.html`.
- Глава объясняет порядок по ключу, проверку соседних ключей, `sorted(..., key=...)`,
  различие с `list.sort` и стабильность равных ключей. Примеры Python проверены.
  В §3 добавлена интерактивная трасса вызова `sorted`: вычисление ключей B → 1900,
  A → 700, C → 1200; построение `by_total = [A, C, B]`; вывод результата и
  неизменённого `orders`. Это модель наблюдаемых состояний вызова, не утверждение
  о внутреннем порядке шагов Timsort.
- План модуля 0: стабильность/цена сортировки; инвариант бинарного поиска;
  монотонный предикат; слияние отсортированных потоков; heap и priority queue.
  Будущие главы в каталоге помечены как план и не имеют несуществующих ссылок.
- КТП сверено напрямую: раздел охватывает занятия 27–36 — сортировки, пользовательский
  порядок, бинарный поиск, merge/sweep line, heap, top-k, k-way merge и мок-интервью № 3.
- После добавления раздела запускать
  `python3 docs/project-context/tools/build_graph.py`: он штатно перенумеровывает
  последовательные узлы ОП.04 после вставки нового раздела.
