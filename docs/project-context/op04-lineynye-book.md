## Подача

Канонический образец — `hesh/00-hesh-iznutri/01-mnozhestvo-i-slovar.html`
и `02-poisk-po-klyuchu.html`. После замечания пользователя первая глава
переработана под этот образец:

- Примеры — `figure.code` с сеансом Python REPL (`>>>`) и настоящим выводом.
- Оболочки схем, кнопки и проверки — общие `widget`, `btn`, `quiz`
  из `massivy/algo.css`; не переопределять их в локальном CSS. Массивы —
  `cells/cell`; связные списки — SVG с рамкой узла, полями `value/next`
  и стрелкой из `next` к следующему объекту. Переменные показаны отдельно.
- По просьбе пользователя схемы связных списков показывают работу кода:
  построение по трём строкам, обход с отдельными шагами печати и перехода,
  подсветкой выполненной строки и накопленным выводом. `head` остаётся
  на первом узле, `current` перемещается до `None`. Кнопки назад/вперёд/сброс.
  На узком экране схема вертикальная; код переносится без обрезания.
- Перед схемой — подводка, после — разбор показанных чисел и связей.
- Одна линия объяснения; без `gist`, `purpose`, `details.simple`, служебной
  карты ссылок и самостоятельного оформления общих компонентов.
- Готовые главы — ссылки, будущие — явно подписанный план без битых ссылок.
- Вставка в цепочку за O(1) — только если известен нужный предшественник;
  поиск позиции учитывается отдельно.
