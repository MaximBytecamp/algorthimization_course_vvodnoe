## Решения и границы

- Семь обязательных PNG: проект, условия первой задачи, отправленный результат, самопроверка/отзыв, завершение, условия задачи о карточке, условия задачи о проверках. Точные имена в `lesson_02/README.md`. Дополнительные кадры разрешены.
- Результат первой задачи соответствует уже опубликованному примеру: резерв 15 минут, три правила, два примера. Готовые постановки задач 2–3 не подменяют их самостоятельные результаты; сдача требует постановки, без результата завершать нельзя.
- Приватный портал не открывается ради Actions. Пять ссылок проверяются синтаксически; доступ к порталу и содержание снимков — вручную преподавателем.
- Actions не подтверждает качество требований. Пустой шаблон намеренно не проходит проверку до заполнения ссылок и загрузки снимков.
- Без внешних Python-зависимостей, секретов и `pull_request_target`; проверка на push/PR/manual, права contents read.
