## Ozon: что не подошло

Не найдено подтверждённой записи интервью Ozon именно с разворотом/слиянием
списков, скобками либо монотонным стеком. Это ограничение данного поиска,
а не утверждение об отсутствии таких интервью.

- https://www.youtube.com/watch?v=STxjmaoxENs — Roman Erdyakov,
  «Провалил тех.скрининг Ozon: разбор 3 задач», 12:53.
  Описание: data race counter (00:15), increment unique by (02:35), SQL (05:12).
  Не выдавать за интервью по спискам/стеку.
- https://www.youtube.com/watch?v=TXh6ociaJJ4 — «Golang Собеседование в OZON —
  Технический скрининг на 400к», 18:14. Описание: слайсы (0:00), горутины
  (5:30), интерфейсы (8:35), SQL (11:03). Не соответствует фокусу 21–24.
- https://www.youtube.com/watch?v=z2hdeFw6Q-U — «GOLANG СОБЕСЕДОВАНИЕ OZON НА 380К»,
  1:46:50. По описанию: конкурентность, in-memory кэш, перебор, БД и System Design.
  10:12–25:01 — кэш, RWMutex/sync.Map и шардирование; это не подтверждённая задача
  на LRU со связным списком. Можно рассматривать для темы хеширования,
  но не приписывать здесь применение связного списка.

## Предварительная методическая рекомендация

Для знакомства выбрать короткий разбор reverse → фрагмент интервью со скобками →
учебное видео монотонного стека. Не называть все три источника интервью.
Цель — распознать структуру и увидеть изменение состояния, не воспроизвести Java/Go.
Предлагаемые поля: таймкод, задача/действие, выбранная структура,
состояние на маленьком примере, причина выбора, проверенный крайний случай.
Фиксированных учебных таймкодов пока нет; не подменять их придуманными.
Отдельная практика и лист наблюдений ещё не созданы и не согласованы.
