## Срез hh.ru

`hh-vacancies-2026-11-23.json` — числа, заголовки, точные запросы, исходные
и конечные URL, время обращения. Источник — публичная поисковая выдача hh.ru,
23.11.2026, 00:58 MSK. Регион Россия (`area=113`), поиск в названии
(`search_field=name`), без ограничения опыта. API hh.ru в этом окружении
отклонил запрос; данные не представлены как статистика API.

Диаграмма §3 построена в HTML по этим шести числам, без внешней зависимости.
Ссылки на каждый поиск есть в диаграмме и JSON. Запросы имеют разную полноту,
могут пересекаться и содержать не-IT вакансии. Это иллюстрация поиска названий
профессий, не оценка всего рынка или доступности работы для начинающих.
