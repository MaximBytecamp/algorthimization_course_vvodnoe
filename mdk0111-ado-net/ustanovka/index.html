§1Что устанавливаем и зачем

На занятиях программа на C# подключается к базе данных PostgreSQL, отправляет ей SQL-запросы и получает строки. Для этого на компьютере нужны три вещи: средства для сборки и запуска программ на C#, редактор с поддержкой C# и сервер базы данных.

Базу не устанавливают на компьютер напрямую. Её запускают в контейнере Docker. Контейнер похож на арендованный кабинет с готовой мебелью: внутри уже установлен и настроен PostgreSQL, а после занятия кабинет можно освободить, и на компьютере ничего не останется. Всем студентам выдаётся одинаковый файл с описанием контейнера, поэтому база у всех одна и та же, с теми же таблицами и строками.

Что нужно для занятий

1 · .NET 10 SDKсобирает и запускает программы на C#, скачивает библиотеки§2
2 · C# Dev Kitподсветка, подсказки и ошибки C# в VS Code§3
3 · Docker Desktopзапускает контейнеры, в том числе PostgreSQL§4
4 · Проверкабаза в контейнере и программа, которая её читает§5

SDK (Software Development Kit) — набор для разработки. Он отличается от среды выполнения (Runtime): Runtime только запускает готовые программы, а SDK ещё и собирает их из исходного кода. Для занятий нужен SDK: Runtime входит в него.

§4Docker Desktop

Docker Desktop — программа, которая запускает контейнеры и показывает их в окне. В неё входят команды docker и docker compose. Вторая команда поднимает контейнеры по описанию из файла docker-compose.yml: какой образ взять, какие настройки передать, какой порт открыть.

В колонке STATUS написано Up — контейнер работает. В колонке PORTS запись 5433->5432 означает, что порт 5433 на вашем компьютере ведёт к порту 5432 внутри контейнера, на котором PostgreSQL принимает подключения. Порт 5433 выбран, чтобы контейнер не мешал PostgreSQL, если он уже установлен на компьютере и занимает стандартный порт 5432.
