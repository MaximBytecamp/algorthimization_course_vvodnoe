§0Как устроен справочник

Материал разбит на восемь модулей. Каждый модуль отвечает на один вопрос работы с API и состоит из глав. Глава читается за один присест: объяснение, примеры на настоящем учебном сервисе, кадры экрана, частые ошибки, вопросы для самопроверки и шпаргалка.

Все примеры выполняются на одном проекте — Service Desk API. Это учебный сервис регистрации обращений в службу поддержки: сотрудник сообщает о проблеме, специалист меняет статус обращения. Проект открыт: github.com/MaximBytecamp/api-standard-template, его документация опубликована по адресу maximbytecamp.github.io/api-standard-template.

Каждое правило в справочнике сопровождается источником: пунктом стандарта, страницей документации или файлом из репозитория крупной компании. Цитата приводится в оригинале, под ней — перевод. Если правило принято только внутри одной компании, это сказано прямо.

Как читать примеры

Блоки с тёмным фоном — то, что вы набираете или отправляете. Блоки со светлым фоном и пунктирной рамкой — то, что возвращает сервер или печатает инструмент. Все выводы в справочнике получены запуском, а не написаны от руки.
