7.4

Парсинг
и чужие базы данных

Сбор данных с чужих сайтов программой — обычная задача: цены конкурентов, вакансии, отзывы, контакты. Законность парсинга зависит от трёх вопросов: не нарушается ли право изготовителя базы данных, не собираются ли персональные данные без основания и не обходится ли защита сайта. В главе разобраны все три.

§1Право изготовителя базы данных

ГК РФ, часть четвёртаяст. 1334, п. 1ред. от 23.07.2025
1. Изготовителю базы данных, создание которой (включая обработку или представление соответствующих материалов) требует существенных финансовых, материальных, организационных или иных затрат, принадлежит исключительное право извлекать из базы данных материалы и осуществлять их последующее использование в любой форме и любым способом (исключительное право изготовителя базы данных). […] При отсутствии доказательств иного базой данных, создание которой требует существенных затрат, признается база данных, содержащая не менее десяти тысяч самостоятельных информационных элементов […].

Каталог маркетплейса, сайт объявлений, агрегатор вакансий — базы данных, в создание которых вложены существенные затраты. Право изготовителя действует 15 лет и возобновляется при каждом обновлении базы (ст. 1335), то есть для живых сайтов фактически бессрочно.

ГК РФ, часть четвёртаяст. 1335.1, п. 1, 3ред. от 23.07.2025
1. Лицо, правомерно пользующееся обнародованной базой данных, вправе без разрешения […] извлекать из базы данных материалы и осуществлять их последующее использование: […] в личных, научных, образовательных целях в объеме, оправданном указанными целями; в иных целях в объеме, составляющем несущественную часть базы данных. […]
3. Не допускается неоднократное извлечение или использование материалов, составляющих несущественную часть базы данных, если такие действия противоречат нормальному использованию базы данных и ущемляют необоснованным образом законные интересы изготовителя базы данных.
ДопустимоНесущественная часть
  • Цены на 50 товаров конкурента для сравнения
  • Выборка для учебного исследования
  • Данные, которые пользователь сайта видит в пределах своего договора с ним
РискСущественная часть или систематическое извлечение
  • Ежедневная копия всего каталога конкурента
  • Перенос всех объявлений на свой сайт
  • Много мелких выгрузок, в сумме равных копии базы (п. 3)

§2Персональные данные из открытых источников

Профиль в социальной сети, резюме на сайте вакансий, контакты в отзывах видны всем, но остаются персональными данными. Сбор их парсером — обработка, для которой нужно основание (глава 3.2).

152-ФЗ «О персональных данных»ст. 10.1, ч. 2ред. от 26.07.2026
2. В случае раскрытия персональных данных неопределенному кругу лиц самим субъектом персональных данных без предоставления оператору согласия, предусмотренного настоящей статьей, обязанность предоставить доказательства законности последующего распространения или иной обработки таких персональных данных лежит на каждом лице, осуществившем их распространение или иную обработку.

Парсер, собирающий телефоны и имена из объявлений для холодных звонков, нарушает сразу несколько норм: обработка без основания (ч. 1 ст. 13.11 КоАП), реклама по телефону без согласия (ст. 18 закона 38-ФЗ, глава 6.2). Если база продаётся или передаётся, а данные были получены незаконно, возможна ст. 272.1 УК.

§3Обход защиты

Если данные доступны только после входа в чужой аккаунт, парсер подбирает пароли, использует украденные сессии или ключи API, эксплуатирует уязвимость, чтобы выгрузить закрытые данные, это неправомерный доступ к охраняемой компьютерной информации (ст. 272 УК) при условии, что он повлёк копирование, изменение, блокирование или уничтожение информации.

scraper.py · вежливый сборщик открытых страниц
import time, urllib.robotparser, requests

robots = urllib.robotparser.RobotFileParser("https://example.ru/robots.txt"); robots.read()
UA = "ZayavkinPriceBot/1.0 (+https://zayavkin.example/bot)"   # представляемся и даём контакт

def fetch(url: str) -> str | None:
    if not robots.can_fetch(UA, url):
        return None                                   # владелец сайта запретил
    time.sleep(2)                                        # не больше одного запроса в 2 секунды
    return requests.get(url, headers={"User-Agent": UA}, timeout=10).text

§4Частые ошибки

«Данные открытые — значит свободные»Открытая база охраняется правом изготовителя; открытые профили — персональные данные.

Собирать телефоны для обзвонаОбработка без основания и реклама без согласия.
