§1Задание

Выберите объект аудита: свой учебный проект с формой регистрации или оплатой либо реальный сайт небольшого сервиса. Для реального сайта проверяется только то, что видно снаружи: страницы, формы, реклама, оферта, политика, способы входа, записи в открытых реестрах. Никаких попыток входа в чужие аккаунты, перебора паролей и сканирования — это нарушение из главы 9.1.

  1. Пройти чек-листПо каждому пункту: выполнено, не выполнено или не применимо, с доказательством — снимком экрана, ссылкой, фрагментом кода.
  2. Для каждого «не выполнено» найти нормуСтатья и часть профильного закона, статья КоАП или УК с санкцией; выписка из КонсультантПлюс с датой редакции.
  3. Оценить рискМаксимальная санкция для формы бизнеса проекта и гражданские последствия.
  4. Предложить исправлениеЧто поменять в коде, интерфейсе или документах; для кода — фрагмент или pull request.

§4Критерии оценки

№Критерий
1Все 68 пунктов проверены, у каждого есть результат
2У каждого результата «выполнено» есть доказательство
3Карта данных полная: формы, оплата, журналы, аналитика, резервные копии
4Для каждого нарушения указана норма с номером статьи и части
5Норма сверена с действующей редакцией, указана дата редакции
6Санкция указана для правильного субъекта: гражданин, ИП, организация
7Разобрана хотя бы одна бланкетная норма: обязанность и санкция в разных законах
8Учтены гражданские последствия: возвраты, компенсации
9Исправления конкретны: что поменять в коде, интерфейсе или документе
10Хотя бы одно исправление реализовано в коде проекта
11Приоритеты плана обоснованы размером риска
12Аудит чужого сайта выполнен без действий, нарушающих ст. 272 УК
