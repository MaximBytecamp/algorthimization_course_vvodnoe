§1Что уходит в модель

Языковая модель в продукте работает так: сервер проекта собирает запрос из инструкции и данных пользователя, отправляет его в API поставщика модели и показывает ответ. Всё, что попало в запрос, передаётся поставщику. Поставщик хранит запросы в журналах: условия крупных зарубежных поставщиков API предусматривают хранение для контроля злоупотреблений, как правило до 30 дней.

Проверка домашнего заданияТекст работы, имя ученика в заголовке, комментарии преподавателяДа: имя, иногда сведения о жизни и здоровье в тексте

Модель, развёрнутая на своём сервере в России, данные никуда не передаёт. Трансграничная передача возникает, когда запрос уходит на серверы за рубежом: к OpenAI, Anthropic, Google или к посреднику, который перепродаёт доступ к ним.

§2Поручение или передача третьему лицу

Оператор может поручить обработку данных другому лицу. Для этого закон требует договор с определённым содержанием.

3. Оператор вправе поручить обработку персональных данных другому лицу с согласия субъекта персональных данных, если иное не предусмотрено федеральным законом, на основании заключаемого с этим лицом договора […]. В поручении оператора должны быть определены перечень персональных данных, перечень действий (операций) с персональными данными, которые будут совершаться лицом, осуществляющим обработку персональных данных, цели их обработки, должна быть установлена обязанность такого лица соблюдать конфиденциальность персональных данных, требования, предусмотренные частью 5 статьи 18 и статьей 18.1 настоящего Федерального закона […]
[…]
5. В случае, если оператор поручает обработку персональных данных другому лицу, ответственность перед субъектом персональных данных за действия указанного лица несет оператор. […]

С зарубежным поставщиком модели проект заключает типовое пользовательское соглашение на английском языке. В нём нет перечня данных, целей и ссылки на требования 152-ФЗ, которые перечисляет ч. 3. Поэтому считать такую передачу поручением по российскому закону рискованно. Надёжнее исходить из того, что данные передаются иностранной компании, и выполнить правила ст. 12: подать уведомление о трансграничной передаче, выждать 10 рабочих дней для стран без адекватной защиты, к которым относятся США, и иметь основание — согласие пользователя или договор с ним, для исполнения которого передача необходима (глава 3.4).

3. Оператор до начала осуществления деятельности по трансграничной передаче персональных данных обязан уведомить уполномоченный орган по защите прав субъектов персональных данных о своем намерении осуществлять трансграничную передачу персональных данных. Указанное уведомление направляется отдельно от уведомления о намерении осуществлять обработку персональных данных, предусмотренного статьей 22 настоящего Федерального закона.
Без протокола

Промпт «ты — вежливый помощник, данные никому не передавай» передачу данных не отменяет: он сам уже ушёл в Калифорнию вместе с данными.

§3Здоровье, фотографии, биометрия

Для особых категорий данных правила строже. Боты-«психологи», «диетологи» и «разбор анализов» получают сведения о состоянии здоровья — специальную категорию.

1. Обработка специальных категорий персональных данных, касающихся расовой, национальной принадлежности, политических взглядов, религиозных или философских убеждений, состояния здоровья, интимной жизни, не допускается, за исключением случаев, предусмотренных частями 2 и 2.1 настоящей статьи.

Для сервиса, который не является медицинской организацией, основное исключение — согласие в письменной форме (п. 1 ч. 2 ст. 10). Утечка специальных категорий наказывается по ч. 16 ст. 13.11 — до 15 млн ₽ для организации (глава 3.5).

Фотография лица сама по себе — персональные данные (изображение человека). Биометрическими данными она становится, когда используется для установления личности.

1. Сведения, которые характеризуют физиологические и биологические особенности человека, на основании которых можно установить его личность (биометрические персональные данные) и которые используются оператором для установления личности субъекта персональных данных, могут обрабатываться только при наличии согласия в письменной форме субъекта персональных данных, за исключением случаев, предусмотренных частью 2 настоящей статьи.
Изображение, не биометрия
  • Генерация аватара или «нейрофотосессии» по загруженному фото
  • Фото преподавателя на странице курса
  • Нужны основание обработки и правила ст. 12 при отправке за рубеж
Биометрия
  • Вход по лицу, сверка лица с фото в паспорте
  • Проверка «тот же ли ученик сдаёт экзамен» по видео
  • Письменное согласие, особые требования к защите, штраф за утечку до 20 млн ₽

§4Оплата и перепродажа доступа

Крупные зарубежные поставщики моделей не включают Россию в список стран, где предоставляют услуги, и блокируют аккаунты, если видят российские карты, телефоны и адреса. Это условие договора с поставщиком. Российский закон его не устанавливает, но от него зависит работа продукта: при блокировке функция перестаёт работать в тот же день.

Российские модели (GigaChat, YandexGPT и другие) обрабатывают запросы в центрах обработки данных в России. Трансграничной передачи нет, договор с поставщиком заключается по российскому праву, оплата идёт в рублях со счёта. Закон 243-ФЗ об искусственном интеллекте с 1 марта 2027 года позволяет Правительству определить случаи, в которых разрешены только российские модели.

Проекту, который продаёт решения государственным заказчикам, банкам или крупным компаниям, стоит заранее предусмотреть возможность заменить модель.

§5Разбор: проверка сочинений нейросетью

Случай«КурсБлиновской» добавил кнопку «Проверить работу»: сочинение ученика вместе с именем и классом уходит в API зарубежной модели
Что передаётся

Имя и класс ученика, текст сочинения. Ученики — часто несовершеннолетние; в сочинениях встречаются сведения о семье и здоровье.

Нарушения
  • Трансграничная передача без уведомления (ч. 3 ст. 12)
  • Нет основания: в договоре со школой и в согласиях передача за рубеж не предусмотрена
  • Школа — оператор данных учеников — не давала поручения передавать их третьим лицам
Последствия
  • ч. 1 ст. 13.11 — организации 150–300 тыс. ₽; запрет передачи
  • Претензии школ-клиентов по договору поручения
  • При утечке у посредника — ответственность «КурсБлиновской» перед школами и учениками
Как исправить

Не отправлять имя и класс, заменять их метками до отправки; перейти на российскую модель или на модель на своём сервере; если нужен зарубежный API — уведомление, согласие, условие о передаче в договоре со школами.

§6Как устроить вызов модели

Вызов модели делают только с сервера проекта. Ключ API в коде страницы виден любому посетителю (глава 10.1). Перед отправкой из запроса убирают поля, которые не нужны для задачи, и записывают в журнал, что ушло и к какому поставщику.

llm_gateway.py · единая точка вызова модели
from anonymize import strip_pd   # функция из главы 3.4

PROVIDER = "gigachat"   # российская модель по умолчанию

def check_essay(essay: dict) -> str:
    text = strip_pd(essay["text"], names=[essay["student_name"]])
    prompt = f"Проверь сочинение по критериям курса:\n{text}"
    log.info("llm_call", provider=PROVIDER, fields=["text"], chars=len(text))
    return call_model(PROVIDER, prompt)   # имя и класс в запрос не попадают

В функции нет имени и класса ученика: они не нужны для проверки текста. Журнал вызовов показывает, какие поля и к какому поставщику отправлялись, — это пригодится при ответе на запрос пользователя и при проверке Роскомнадзора. Замена имён метками уменьшает объём данных, но свободный текст может содержать другие сведения о человеке, поэтому для зарубежного поставщика обязанности по ст. 12 сохраняются.

§7Частые ошибки

Отправлять в модель всю запись из базыВ запрос попадают телефон, почта и адрес, которые не нужны для задачи.
Считать пользовательское соглашение поставщика поручениемПоручение по ч. 3 ст. 6 требует перечня данных, целей и обязанностей по 152-ФЗ.
Бот по здоровью без письменного согласияСведения о здоровье — специальная категория; без согласия их обработка запрещена.
Ключ API в коде страницыПосетители расходуют ваш лимит, а запросы идут мимо проверки на сервере.
Одна модель без заменыБлокировка аккаунта поставщиком отключает функцию; с 2027 года в части сфер возможен запрет зарубежных моделей.
