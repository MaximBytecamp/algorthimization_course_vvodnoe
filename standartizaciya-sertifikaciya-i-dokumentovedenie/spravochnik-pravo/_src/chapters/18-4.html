§1Что такое обезличивание

9) обезличивание персональных данных - действия, в результате которых становится невозможным без использования дополнительной информации определить принадлежность персональных данных конкретному субъекту персональных данных;

Ключевые слова — «без использования дополнительной информации». Обезличенные данные можно связать с человеком обратно, если есть ключ: таблица соответствия, секрет, исходная база. Поэтому у оператора, который хранит ключ, обезличенные данные остаются персональными, и правила закона на них распространяются. Полностью анонимными считаются данные, которые нельзя связать с человеком никем и никак; для реальных записей о поведении людей этого добиться трудно.

Не обезличивание
  • Удалили имя, оставили телефон
  • Заменили телефон его хешем SHA-256: все российские номера перебираются за минуты
  • Оставили редкое сочетание: город, возраст, курс, дата покупки
Обезличивание
  • Идентификаторы заменены на коды, ключ хранится отдельно у ограниченного круга лиц
  • Данные агрегированы: «в Казани 120 учеников курса Python»
  • Редкие значения обобщены: возраст — диапазоном, город — регионом

§2Обязанность по требованию Минцифры

Статья 13.1 введена законом от 08.08.2024 № 233-ФЗ и действует с 1 сентября 2025 года. Минцифры в случаях, которые определяет Правительство, формирует составы обезличенных данных в государственной информационной системе и направляет операторам требования.

3. Оператор после получения требования, указанного в части 2 настоящей статьи, обязан обезличить обрабатываемые им персональные данные в соответствии с требованиями к обезличиванию персональных данных, методами обезличивания персональных данных и порядком обезличивания персональных данных, которые устанавливаются Правительством Российской Федерации […].
4. Оператор в соответствии с требованием, указанным в части 2 настоящей статьи, обязан предоставить персональные данные, полученные в результате обезличивания персональных данных, в государственную информационную систему уполномоченного органа в сфере регулирования информационных технологий. […]

Требование приходит конкретному оператору; всем операторам сразу передавать данные закон не обязывает. Проекту, получившему требование, нужно понять, какие данные запрошены, обезличить их методами, утверждёнными Правительством, и передать через установленный порядок взаимодействия. Самостоятельный «ручной» способ обезличивания для этой обязанности не подходит.

Без протокола

Требование обезличить базу по методике Правительства часто становится первым поводом посмотреть, что в ней на самом деле лежит.

§3Доступ разработчиков к составам данных

Составы данных нужны прежде всего для обучения и проверки моделей ИИ. Доступ к ним получают не все.

Работать с составами данных можно только внутри государственной системы: записывать, извлекать и передавать их наружу запрещено (ч. 10), а результаты обработки нельзя передавать иностранным лицам (ч. 12). Модель, обученную на таких данных, нельзя передать зарубежному заказчику без оценки этого запрета.

§4Обезличивание для своей аналитики

Для внутренних задач — аналитики, тестовых стендов, обучения своей модели, выгрузки в нейросеть — проект обезличивает данные сам. Закон не освобождает такие данные от правил полностью, но снижает риски: утечка обезличенной выгрузки без ключа не раскрывает людей, а в запрос к модели не попадают имена и телефоны (глава 10.2).

pseudonymize.py · замена идентификаторов с ключом, который хранится отдельно
import hmac, hashlib, os

KEY = os.environ["PSEUDO_KEY"].encode()   # ключ не хранится рядом с выгрузкой

def pid(value: str) -> str:
    return hmac.new(KEY, value.encode(), hashlib.sha256).hexdigest()[:16]

def row_out(r: dict) -> dict:
    return {
        "student": pid(r["phone"]),            # телефон → код
        "age_band": f"{r['age'] // 10 * 10}+",   # возраст → диапазон
        "region": r["region"],                # город → регион
        "course": r["course_id"],
    }

В отличие от простого хеша, HMAC с секретным ключом нельзя подобрать перебором номеров, если ключ не утёк. Возраст и место обобщаются, чтобы редкое сочетание не выдавало человека. Перед выгрузкой проверяют, нет ли групп из одного-двух человек, и объединяют их с соседними.

§5Частые ошибки

Считать хеш телефона обезличиваниемНомера перебираются; это те же персональные данные.
Хранить ключ рядом с выгрузкойОбезличивание снимается одной командой.
Оставлять редкие сочетания признаковЧеловек определяется без имени и телефона.
Игнорировать требование МинцифрыСт. 13.1 делает обезличивание и передачу обязанностью оператора.
Выгрузить государственный состав данных для обучения за рубежомВывод данных и передача результатов иностранцам запрещены.
