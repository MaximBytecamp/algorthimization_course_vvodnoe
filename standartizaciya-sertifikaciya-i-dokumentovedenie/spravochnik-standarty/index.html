Тема 3

Стандарты и сертификаты

17 глав
  1. 1Что такое стандарт и как его читатьВиды стандартов и кто их принимает, как читать обозначение ГОСТ, ISO и RFC, когда стандарт обязателен и как проверить, что он действует.
  2. 2ГОСТ 34 и ГОСТ 19: документы на систему и программуКомплексы ГОСТ 34 и ЕСПД, десять обязательных разделов технического задания по ГОСТ 34.602-2020, стадии создания системы, документы на программу по ГОСТ 19.
  3. 3ГОСТ Р 7.0.97-2016: оформление документовТридцать реквизитов организационно-распорядительного документа, образец приказа с разбором, поля листа, запись даты, заголовок и подпись.
  4. 4Стандарты интернета: HTTP, JSON, дата и текстДокументы RFC и кто их выпускает, методы и коды ответа HTTP по RFC 9110, JSON по RFC 8259, запись даты по ISO 8601, Юникод и UTF-8.
  5. 5PEP 8: оформление кода на PythonОтступы и перенос длинных строк, пустые строки, порядок импортов, пробелы, комментарии, имена, рекомендации по сравнениям и исключениям, проверка ruff и black — с парами примеров «так не надо / так надо».
  6. 6Документация в коде: PEP 257, 484 и 20Строки документации модуля, класса и функции по PEP 257, стиль Google для параметров, аннотации типов по PEP 484 и их проверка mypy, «Дзен Python» PEP 20.
  7. 7Версии, коммиты и журнал измененийSemantic Versioning с правилами сравнения версий, сообщения коммитов по Conventional Commits, журнал изменений по Keep a Changelog, обозначение лицензий по SPDX.
  8. 8OpenAPI и форматы данныхОписание HTTP API в OpenAPI 3.1 с полным примером, JSON Schema для проверки данных, описание ошибки по RFC 9457, CSV по RFC 4180, YAML и его ловушки.
  9. 9Коды стран, валют, языков и единицы величинISO 3166 для стран, ISO 4217 для валют, ISO 639 и BCP 47 для языков, E.164 для телефонов, SI и ГОСТ 8.417 для единиц, килобайт и кибибайт по IEC 80000-13.
  10. 10Доступность интерфейсов: WCAG и ГОСТ Р 52872Четыре принципа и три уровня WCAG 2.2, контраст 4,5:1, размер цели 24×24, подписи к изображениям и полям, проверка с клавиатуры, российский ГОСТ Р 52872-2019.
  11. 11Стандарты тестированияСерия ISO/IEC/IEEE 29119 и российские ГОСТ Р 56920–56922, уровни и виды тестирования, классы эквивалентности и граничные значения на примере, тестовый сценарий и отчёт о дефекте.
  12. 12Стандарты информационной безопасностиСемейство ISO/IEC 27000, ГОСТ Р 57580.1 для финансовых организаций, ГОСТ Р 56939 о безопасной разработке, PCI DSS, обозначения уязвимостей CVE, CVSS, CWE и OWASP Top 10.
  13. 13Криптография и сертификаты ключейРоссийские алгоритмы ГОСТ Р 34.10, 34.11 и 34.12 и их международные аналоги, сертификат X.509 по полям, цепочка доверия, TLS 1.3, устройство токена JWT.
  14. 14Стандарты качества и процессовЦикл постоянного улучшения, ISO 9001, восемь характеристик качества программы по ISO/IEC 25010, процессы жизненного цикла, управление услугами, доступность и уровни центров обработки данных.
  15. 15Электронные документы, форматы и архивВиды электронной подписи по закону 63-ФЗ, форматы документов ODF и OOXML, PDF/A для архивного хранения, требования к электронному документу и его хранению.
  16. 16Технические регламенты и знаки соответствияЧем технический регламент отличается от стандарта, регламенты ЕАЭС для электроники (ТР ТС 004, 020, ТР ЕАЭС 037), знаки EAC, CE, РСТ, FCC и что нужно, чтобы продать устройство.
  17. 17Сертификация и декларированиеФормы подтверждения соответствия по закону 184-ФЗ, сертификат и декларация, кто аккредитует и кто выдаёт, образец сертификата, проверка по реестрам Росаккредитации и ФСТЭК.
