Контракт, правила HTTP и OpenAPI

Как это устроено

  • 40 заданий по модулям 1–3 справочника «Стандартизация HTTP API»: контракт и проверка соответствия, ресурсы и адреса, учебный стенд Service Desk API, ограничения REST, методы и их свойства, коды ответов, параметры и форматы, машиночитаемое описание, разделы OpenAPI, сборка описания из кода FastAPI, Swagger UI и ReDoc.
  • Задания разных видов: сравнить два документа .md и выбрать оформленный по правилам, разобрать чужой запрос по частям, принять или вернуть на доработку чужой репозиторий, разложить карточки по группам, подставить карточку в пропуск, собрать адрес ресурса, убрать лишнее, отметить строки в коде и в описании, выбрать варианты, ввести число или код ответа. Часть заданий — по снимкам вывода терминала, панели проверок и интерфейса Swagger UI.
  • Документы скачиваются. В заданиях со сравнением нажмите «Скачать .md» у каждого файла: оба открываются в любом редакторе, и сравнивать их можно рядом с текстом задания.
  • Задания с настоящими проектами. В части заданий показана карточка репозитория с составом файлов и ссылкой на GitHub — Service Desk API и учебный pull request, описание API GitHub, правила Zalando, Spectral, oasdiff. Ссылка открывается в новой вкладке; ответить можно и не открывая её — всё нужное есть на странице.
  • Карточки перетаскиваются мышью или пальцем. Можно и без перетаскивания: нажмите карточку, затем место, куда её поставить.
  • 75 минут. Отсчёт начинается по кнопке «Начать» и не останавливается, если закрыть вкладку или перезагрузить страницу. Когда время выйдет, работа отправится сама с теми ответами, что успели дать.
  • Каждое задание — 1 балл. В заданиях из нескольких частей балл ставится, только если верны все части. Оценка: 34–40 → «5», 27–33 → «4», 19–26 → «3», меньше 19 → «2».
  • Пройти можно один раз. После отправки ответы не меняются, а повторное открытие ссылки покажет готовую оценку. Порядок заданий и карточек у каждого свой.
  • Уход со вкладки считается. Переключение на другое окно или вкладку записывается в код результата.
  • После отправки откроется разбор: по каждому заданию — ваш ответ, верный ответ и объяснение, в конце — главы справочника, которые стоит повторить, и код результата для преподавателя.
