| `mdk0101-razrabotka-modulei/` | МДК.01.01 «Разработка программных модулей», 2 курс: вводная презентация и КТП |

## Как устроена дисциплина внутри

```
op04-algoritmizaciya/
  index.html                          меню дисциплины: список занятий и материалов
  lessons/01-vvodnaya/                вводная презентация
  lessons/NN-tema/                    колода занятия: index.html, styles.css,
                                      app.js и LESSON_PLAN.md — методичка
  assets/                             логотипы компаний и фотографии
  starter-pack/                       шаблон репозитория для студента
  course-materials/                   что выдаётся по ходу занятий
  КТП_*.docx                          календарно-тематическое планирование
```

Презентации ссылаются на мемы как `../shared/memes/…`, поэтому папку
дисциплины нужно держать рядом с `shared/`.

## Новая дисциплина

Создать папку рядом, скопировать из соседней `index.html`, `styles.css`
и `script.js` как основу, дальше писать по правилам из `shared/`.
