Системное
программирование

Как программы работают с Windows изнутри: процессы и потоки, память, файлы, реестр, сеть, службы и устройства. Весь курс студенты пишут на C одну программу — агент, который следит за состоянием компьютера, — и на каждой паре добавляют в него новую проверку. Тревоги агента уходят в сервис автоматизации n8n, где модель ИИ пишет объяснение для человека.

C · WinAPI · MSVCSysinternals · x64dbg · Ghidran8n · Ollama · GigaChat13 проверок агенталекция + практика

Как устроен курс

Пара — одна страница. Вверху лекция из нескольких разделов, у каждого раздела интерактивная схема. Ниже практика: задания на странице и задание на своём компьютере, одна проверка на задание, баллы и разбор. В конце страница собирает отчёт report.md.

Каждая тема в три шага. Вызов функций WinAPI на C, сверка результата со служебной программой Microsoft, новая проверка в агенте.

Проверки накапливаются. В репозитории студента GitHub Actions после каждой пары запускает программу-нарушитель со всеми пройденными ситуациями. Агент должен заметить каждую.

01 Системное программирование: цели курса и проект
